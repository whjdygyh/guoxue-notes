八字精修 · Day 03 · 旺衰法（日主强弱判断）

核心一句话：看日主在八字里是强是弱，决定该「帮」还是该「治」。

旺衰法是取用神的前置操作。不明白旺衰，用神就是瞎猜。

一、旺衰三要素

判断日主强弱要看三个维度，缺一不可：

① 得令 — 月令旺衰（权重最大，约60%）

日主五行与月令（月支）的关系，是旺衰的第一判断标准。

五行四时旺衰表：

日主 旺于月 相于月 休于月 囚于月 死于月
木 寅卯（春） 亥子（冬） 巳午（夏） 辰戌丑未 申酉（秋）
火 巳午（夏） 寅卯（春） 辰戌丑未 申酉（秋） 亥子（冬）
土 辰戌丑未 巳午（夏） 申酉（秋） 亥子（冬） 寅卯（春）
金 申酉（秋） 辰戌丑未 亥子（冬） 寅卯（春） 巳午（夏）
水 亥子（冬） 申酉（秋） 寅卯（春） 巳午（夏） 辰戌丑未

简化记忆口诀（五行的「当令」）：

春木夏火秋金冬水，四季末月皆为土
当令者旺，生我者相，我生者休
克我者囚，我克者死
  • 旺：日主就是当令五行 → 得令 ✓
  • 相：月令生日主 → 得令 ✓（但次一等）
  • 休/囚/死：不得令 ✗

注：「相」是月令生的五行，如春月木旺、火相——日主为火者在寅卯月虽未当令，但受月令所生，也算有气。

② 得地 — 地支根气（权重约30%）

日主在地支中是否有根，决定其根基深浅。根分三等：

根的类型 定义 力量
主气根 地支主气藏干与日主相同 最强
中气根 地支中气藏干与日主相同 中等
余气根 地支余气藏干与日主相同 较弱，但有胜无

十干根气速查（十二长生状态）：

  • 临官（禄） = 最强根，如甲木见寅、丙火见巳
  • 帝旺（刃） = 最强根，如甲木见卯、丙火见午
  • 长生 = 有气之根，如丙火见寅、戊土见寅
  • 墓库 = 根很弱，如甲木见未、丙火见戌
  • 绝/胎/养 = 无根

根气口诀：

甲寅卯、乙卯寅、丙巳午、丁午巳
戊巳午、己午巳、庚申酉、辛酉申
壬亥子、癸子亥

上为临官（禄）位，下为帝旺（刃）位。

③ 得势 — 天干与地支藏干的同类数量（权重约10%）

四柱中除日主外，还有多少个同五行的天干和地支藏干（印星和比劫都算入日主势力）：

计分参考（非绝对，但可量化）：

  • 天干比劫 +1分/个，印星 +0.8分/个
  • 地支主气根 +1分，中气根 +0.5分，余气根 +0.3分
  • 得令 加 3 分基础分
  • 总分 ≥ 5 为身旺，3-5 为中和，< 3 为身弱

（不同流派评分标准略有差异，但方向一致）

二、实战案例：用户八字分析

八字：辛酉 庚寅 甲寅 辛未

年柱：辛酉
月柱：庚寅
日柱：甲寅
时柱：辛未

① 得令判断

要素 值 判定
日主 甲木 —
月令 寅 寅为春季第一月
木旺于春 ✓ 甲木当令 —— 得令 ✓

② 得地判断

地支 藏干 日主根气
年支酉 辛 甲木绝地 → 无根 ✗
月支寅 甲丙戊 甲木主气 → 临官（禄）强根 ✓✓
日支寅 甲丙戊 甲木主气 → 临官（禄）强根 ✓✓
时支未 己丁乙 乙木余气 → 轻微根 ✓

双寅禄根 + 未中乙木余气 → 得地 ✓✓（根气极强）

③ 得势判断

来源 内容 对日主的作用
年干辛 正官 克甲木 ✗
月干庚 七杀 克甲木 ✗
年支酉 辛金 克甲木 ✗
时干辛 正官 克甲木 ✗
三寅+未 甲木×2 + 乙木 比劫帮身 ✓✓

天干无比劫帮身，纯靠地支强根支撑。金势虽重（年、月、时三柱金），但甲木有双寅禄根稳如磐石。

综合结论

维度 结果
得令 ✅ 甲木当令于寅月
得地 ✅✅ 月日双寅禄根 + 未中乙木余气
得势 ⚖️ 天干无帮，全依地支，金重但不至于压倒

判定：身旺（偏旺）

这个八字甲木极其强壮——双寅禄根，春月当令，虽然天干三金环伺，但根深不怕风摇。

三、旺衰程度的六个档次

不只是简单的「旺/弱」，细分六个等级，用神取法不同：

等级 特征 用神策略
太旺 得令+遍地同类/印，克泄无效 顺势生扶（从旺、从强）
偏旺 得令+有根，克神力量不足 喜克泄耗（官杀/食伤/财）
中和 得令失地或得地失令，无极端 可扶可抑，看大运流向
偏弱 失令+孤根或无根 喜生扶（印、比劫）
太弱 失令无根，但未到从格 仍可扶，但效率低
从格 日主毫无根基，满盘异类 顺势而从，不可逆势扶

以四柱月令为参照，快速判断日主旺衰：

  月令→  寅卯  巳午  辰戌丑未  申酉  亥子
日主↓
甲/乙    得令   休   囚       死    相
丙/丁    相    得令  休       囚    死
戊/己    死    相   得令      休    囚
庚/辛    囚    死   相       得令  休
壬/癸    休    囚   死       相    得令

五、旺衰法的底层逻辑（必读）

旺衰的判断不能机械套表，要有整体思维：

核心原则

  1. 月令权重最高，但不是唯一
  2. 身弱得令仍偏弱（如寅月甲木、全局金水一片）

  3. 身旺失令仍偏旺（如申月丙火、地支四午）

  4. 根比干重要

  5. 一个天干比劫不如一个地支主气根

  6. 无根的「浮木」再多的天干帮身也帮不上

  7. 流年大运可以改变格局

  8. 身旺逢印比运 → 更旺甚至「亢龙有悔」

  9. 身弱逢官杀运 → 灾祸之年

  10. 中和最好，偏旺偏弱皆可，太旺太弱最险

与十神结合

日主旺衰直接影响十神的解读：

状态 官杀 食伤 财星 印星 比劫
身旺 喜——管得住 喜——泄秀 喜——能担 忌——增旺 忌——争强
身弱 忌——压不住 忌——耗身 忌——身弱不担财 喜——生扶 喜——帮扶

六、一句话记住

得令看季节，得地看禄根，得势看帮身。三个维度有两项占优即为身旺——把日主想象成一个人，月令(0.6分) + 根气(0.3分) + 帮手(0.1分)，总分过了0.5就是旺。
