八字精修 · Day 01 · 排四柱精讲 + 地支藏干

目标：彻底吃透排盘——年柱怎么分界、月柱怎么遁、日柱怎么算、时柱怎么定。加上地支藏干的全套口诀。

一、排四柱总纲

四柱 = 年柱 + 月柱 + 日柱 + 时柱，每柱一个天干一个地支，共八个字 → 八字。

柱位 信息来源 核心规则
年柱 出生年份 以立春为岁首分界，非农历正月初一
月柱 出生月份 以节气分月令，用五虎遁定天干
日柱 出生日期 公式计算或查万年历（必须精确到日）
时柱 出生时辰 用五鼠遁从日干推时干

二、年柱——立春是真正的岁首

很多人以为正月初一换年——错。八字用干支纪年，以立春为界。

  • 出生在立春之后 → 干支为当年
  • 出生在立春之前 → 干支为上年
  • 立春当日 → 需精确到时分，过了立春时刻就算新年

例题： 2026年腊月十八生 → 查万年历，若在2027年立春（2月4日）之前 → 年柱仍是丙午（2026年干支）。若在立春之后 → 年柱为丁未（2027年干支）。

记忆口诀： 干支纪年看立春，正月初一不管用。

三、月柱——节气月令 + 五虎遁

3.1 不是农历月份，是节气月令

一年12个月令，以节气为分界：

月令 节气区间 地支
寅月 立春 → 惊蛰 寅
卯月 惊蛰 → 清明 卯
辰月 清明 → 立夏 辰
巳月 立夏 → 芒种 巳
午月 芒种 → 小暑 午
未月 小暑 → 立秋 未
申月 立秋 → 白露 申
酉月 白露 → 寒露 酉
戌月 寒露 → 立冬 戌
亥月 立冬 → 大雪 亥
子月 大雪 → 小寒 子
丑月 小寒 → 立春 丑

注意：寅月是正月（立春开始），子月是十一月。不是从子月开始算。

月柱地支 = 节气月令对应的地支（查上表）。

3.2 五虎遁——定月干

口诀（从年干推月干）：

甲己之年丙作首，乙庚之岁戊为头。 丙辛之岁寻庚上，丁壬壬寅顺水流。 若问戊癸何处起，甲寅之上好追求。

解释：

年干 正月(寅月)天干 口诀
甲、己 丙寅 甲己之年丙作首
乙、庚 戊寅 乙庚之岁戊为头
丙、辛 庚寅 丙辛之岁寻庚上
丁、壬 壬寅 丁壬壬寅顺水流
戊、癸 甲寅 若问戊癸何处起，甲寅之上好追求

使用方法： 确定年干 → 找到正月天干 → 顺推至出生月的地支。

例题： 丙午年，出生在酉月 → 丙年正月庚寅 → 顺推：庚寅(1月)→辛卯(2)→壬辰(3)→癸巳(4)→甲午(5)→乙未(6)→丙申(7)→丁酉(8) → 月柱为丁酉。

四、日柱——最麻烦的一步

月柱用五虎遁、时柱用五鼠遁，都有口诀。但日柱只能查万年历或用公式计算。

4.1 查万年历法（推荐新手）

直接查万年历，输入公历日期得到干支日柱。最准、不会错。

4.2 公式计算法（脱表必备）

适用范围： 公历2000–2099年。

公式：

日干支基数 = (年尾两位数 + 7) × 5 + 15 + (年尾两位数 + 19) / 4
            取整数部分后 MOD 60

步骤： 1. 计算日干支基数（取整，mod60） 2. 计算当年1月1日到该日的总天数（含当日） 3. 日干支序数 = (基数 + 天数) MOD 60 4. 天干 = 序数 MOD 10（甲=0, 乙=1…） 5. 地支 = 序数 MOD 12（子=0, 丑=1…）

注意： 当年2月需判断闰年（能被4整除但不能被100整除，或能被400整除）。

例题： 2026年5月11日 - 年尾26 → (26+7)×5 + 15 + (26+19)/4 = 165 + 15 + 11 = 191 → 191 MOD 60 = 11 - 1月1日→5月11日天数：31+28+31+30+11 = 131天 - 日干支序数 = (11 + 131) MOD 60 = 142 MOD 60 = 22 - 天干：22 MOD 10 = 2 → 乙 - 地支：22 MOD 12 = 10 → 酉 - → 日柱 = 乙酉

五、时柱——五鼠遁

5.1 时辰对照

地支 时间段 现代时间
子时 夜半 23:00–01:00
丑时 鸡鸣 01:00–03:00
寅时 平旦 03:00–05:00
卯时 日出 05:00–07:00
辰时 食时 07:00–09:00
巳时 隅中 09:00–11:00
午时 日中 11:00–13:00
未时 日昳 13:00–15:00
申时 晡时 15:00–17:00
酉时 日入 17:00–19:00
戌时 黄昏 19:00–21:00
亥时 人定 21:00–23:00

注意：23:00–01:00为子时，现代人容易忽略这个跨日区间。

5.2 五鼠遁——定时干

口诀（从日干推时干，子时为起点）：

甲己还加甲，乙庚丙作初。 丙辛从戊起，丁壬庚子居。 戊癸何方发，壬子是真途。

日干 子时天干 口诀
甲、己 甲子 甲己还加甲
乙、庚 丙子 乙庚丙作初
丙、辛 戊子 丙辛从戊起
丁、壬 庚子 丁壬庚子居
戊、癸 壬子 戊癸何方发，壬子是真途

用法： 确定日干 → 找到子时天干 → 顺推至出生时辰的地支。

例题： 丙午年乙酉日，出生在未时 - 日干为乙 → 乙庚丙作初 → 子时丙子 - 顺推：丙子(子)→丁丑(丑)→戊寅(寅)→己卯(卯)→庚辰(辰)→辛巳(巳)→壬午(午)→癸未(未) - → 时柱 = 癸未

六、完整排盘流程

例题： 某人生于2026年5月11日14:30

第一步：年柱 2026年立春在2月4日 → 已过立春 → 年柱 = 丙午

第二步：月柱 5月11日在立夏(5月5日)之后、芒种之前 → 巳月 年干为丙 → 丙辛之岁寻庚上 → 正月庚寅 → 顺推至四月(巳月) 庚寅(1)→辛卯(2)→壬辰(3)→癸巳(4) → 月柱 = 癸巳

第三步：日柱 查万年历或公式计算 → 乙酉

第四步：时柱 14:30 = 未时 日干为乙 → 乙庚丙作初 → 子时丙子 顺推至未时 → 丙(子)→丁(丑)→戊(寅)→己(卯)→庚(辰)→辛(巳)→壬(午)→癸(未) → 时柱 = 癸未

完整八字： | 年 | 月 | 日 | 时 | |:-:|:-:|:-:|:-:| | 丙 | 癸 | 乙 | 癸 | | 午 | 巳 | 酉 | 未 |

七、地支藏干——八字断命的根基

每个地支内部藏着若干天干成分。这是八字学最容易被忽略的地基——没有藏干，旺衰法、格局法都是空谈。

7.1 地支藏干口诀

子宫癸水在其中，丑癸辛金己土同。 寅宫甲木兼丙戊，卯宫乙木独相逢。 辰藏乙戊三分癸，巳中庚金丙戊丛。 午宫丁火并己土，未宫乙己丁共宗。 申藏庚壬戊，酉中辛金独。 戌宫辛丁戊，亥藏壬甲终。

地支 主气(本气) 中气 余气 备注

丑 己土 癸水 辛金 土金水
寅 甲木 丙火 戊土 木火土
卯 乙木 — — 单藏乙木
辰 戊土 乙木 癸水 土木水

戌 戊土 辛金 丁火 土金火

7.3 三条规律帮记忆

  1. 四正地支（子午卯酉）藏干最简单——子癸、午丁己、卯乙、酉辛。午多一个己土（丁火生己土）。
  2. 四孟地支（寅申巳亥）藏干为：本气 + 五行长生之气 + 土——寅(甲丙戊)、申(庚壬戊)、巳(丙戊庚)、亥(壬甲)。
  3. 四墓地支（辰戌丑未）藏干为：土 + 上一五行之余气 + 下一五行之初气——辰(戊乙癸)、戌(戊辛丁)、丑(己癸辛)、未(己丁乙)。

7.4 为什么藏干重要

藏干决定了地支的实际成分，它直接关系到：

  • 通根：天干的十神在地支是否有根（比如甲木见寅=有强根，甲木见亥=有中气根）
  • 旺衰判断：看天干在地支有没有藏干支持
  • 格局判断：藏干透干算成格
  • 刑冲合会时看谁受伤：会合时藏干的变化决定吉凶

八、今日总结

项目 要点 熟练度
年柱 立春分界，非正月初一 ⬜
月柱 节气月令 + 五虎遁 ⬜
日柱 查万年历 or 公式计算 ⬜
时柱 五鼠遁从日干推 ⬜
地支藏干 口诀背熟，主中余气分清 ⬜

练手： 用当年（2026年）今天的时间，按完整流程排一次四柱。不会算日柱就找个万年历查。
