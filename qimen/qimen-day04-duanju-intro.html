国学天师 · 奇门遁甲自学笔记

第四天 · 断局入门：用神分析与旺衰判断

前言：断局的核心逻辑

排盘是"搭积木"，断局是"看积木形成了什么图案"。

断局四步法（定场口诀）：

一看用神在哪里，二看旺衰定吉凶 三看格局好与坏，四看克应自然通

"用神"这个概念： - 周易里，用神是你卜的那一爻 - 奇门里，用神是你要看的那个"符号"在九宫里的位置 - 问事业→找开门，问财运→找生门+戊，问婚姻→找六合+乙丙 - 找到用神在哪个宫 → 分析这个宫里的星门神组合 → 得出结论

一、用神大全（按场景分类）

1️⃣ 事业/工作/职场

用神 含义 优先级
开门 事业发展、工作环境 🥇 最重要
天心星 谋略、管理者、领导 🥈 次之
值符 贵人、直接上级 🥉 补充
日干 你自己（主方） 📍 定位你自己的宫位
时干 当下之事（客方） 📍 定位事情的宫位

断法： - 开门逢吉星（天辅天心天任）→ 事业顺遂 - 开门逢凶星（天芮天柱天蓬）→ 工作有阻力 - 开门+太阴 → 幕后工作、暗中的位置 - 开门+九天 → 公开的、上升的事业 - 日干在哪个宫？时干在哪个宫？两宫关系如何？ - 日干宫生时干宫 → 你推动事情 - 时干宫生日干宫 → 事情主动向你靠拢（好消息） - 日干与开门同宫 → 你和事业是同一件事

2️⃣ 财运/生意/投资

用神 含义 优先级
生门 财运、生意、利润 🥇 最重要
戊（天干） 钱财本身 🥇 和生门同等重要
天任星 实业、不动产 🥈
天英星 风险投资、金融 🥈
甲子戊 本金（戊在哪个宫就是钱在哪） 🥉

断法： - 生门+戊同宫 → 财运在那个方向 - 生门逢吉星（天心天辅）→ 赚钱顺利 - 生门逢白虎 → 财来财去、因财惹祸 - 生门+九地 → 守财、存钱、不动产赚钱 - 生门+九天 → 大钱在外地、适合走出去赚钱 - 生门临死门或空亡 → 财运空了，暂时别投

3️⃣ 婚姻/感情

用神 含义 优先级
六合 婚姻、中介、第三方 🥇 最重要
乙 女方（妻子、女友、女性求测者） 🥇
庚 男方（丈夫、男友） 🥇
丁 第三者（情人、偏桃花） ⚠️ 特殊

断法： - 乙庚同宫 → 夫妻一心，婚姻稳固 - 乙庚相克 → 感情不和 - 六合宫生乙宫 → 婚姻对女方有利 - 六合宫生庚宫 → 婚姻对男方有利 - 丁奇出现且与乙或庚相合 → 可能有第三者 - 六合宫逢腾蛇 → 感情虚妄不实 - 六合宫空亡 → 婚姻未定/同床异梦

4️⃣ 健康/疾病

用神 含义 优先级
天芮星 疾病 🥇 最重要
天心星 医生、治疗、药 🥇
死门 重病、绝症 🥈
生门 生机、康复 🥈
个人年命 求测者本人的年命干支 🥉

断法： - 天芮在哪个宫 → 病在哪个部位 - 坎1=肾泌尿 → 离9=心/眼 → 震3=肝胆 → 兑7=肺/口 → 坤2=脾胃 - 天芮逢吉门（休/生/开）→ 病能好 - 天芮逢凶门（死/惊/伤）→ 病重 - 天芮+天心同宫 → 有病就有医（找到医生了） - 天芮+死门同宫 → 重病危巽

5️⃣ 出行/迁移

用神 含义
开门+九天 出行吉、远行顺
马星（寅申巳亥） 动象
日干 自己
白虎 路上凶险

断法： - 开门在哪个宫 → 往那个方向走是好方向 - 马星动 → 事情很快启动 - 日干宫剋时干宫 → 出门受阻 - 白虎+惊门 → 出行防意外

二、旺衰判断（"这个宫气不气足"）

一看宫位本身的旺衰，二看星门神的旺衰。

宫位旺衰（月令定夺）

用神所在的宫位，看五行与当前季节的关系：

季节 旺宫 相宫 休宫 囚宫 死宫
春（木） 震/巽 离 坎 坤/艮 乾/兑
夏（火） 离 坤/艮 震/巽 乾/兑 坎
秋（金） 乾/兑 坎 坤/艮 震/巽 离
冬（水） 坎 震/巽 乾/兑 离 坤/艮
四季末 坤/艮 乾/兑 离 坎 震/巽

简单解释： - 春天 → 木旺 → 震3（木）和巽4（木）是旺宫，用神落在这里最好 - 冬天 → 水旺 → 坎1（水）是旺宫 - 用神落在旺/相宫 = 气足，吉事更吉，凶事减弱 - 用神落在死/囚宫 = 气弱，吉事打折扣，凶事更凶

举例： 现在是5月（夏季，火旺）。生门在离9宫（火）→ 火土相生，旺相之宫 → 财运好。生门在坎1宫（水）→ 水火相克，休囚 → 财运弱。

星门神旺衰

九星八门八神也会旺弱，但更多看是否被宫位生克。

星和宫的关系： - 星生宫 = 星被"利用"了，吉星更吉，凶星减弱 - 宫生星 = 星得到滋养，吉星大吉，凶星也变"有力" - 星克宫 = 星来捣乱，吉星打折，凶星加倍凶 - 宫克星 = 宫压住了星，凶星没那么凶，吉星也没那么吉

门和宫的关系： 同上。

神和宫的关系： 神的力量最强，受宫的影响较小，但也会被宫生克调节。

三、空亡与马星

空亡（事不实、人不在、无结果）

空亡 = 用神所在的宫位"空了"，代表： - 问人→人不在 - 问事→事未定/虚假 - 问物→东西丢了/找不到 - 问财→暂时没钱

怎么判断空亡？ 根据"旬"来定： - 甲子旬 → 戌亥空（乾6宫空） - 甲戌旬 → 申酉空（兑7宫空） - 甲申旬 → 午未空（离9+坤2空） - 甲午旬 → 辰巳空（巽4+震3空） - 甲辰旬 → 寅卯空（震3+艮8空） - 甲寅旬 → 子丑空（坎1+艮8空）

空亡的"死与活"： - 未出空（还没到空亡的地支时间）→ 事未成，悬着 - 出空（到了对应的时间）→ 事现，数字上 - 填空： 同宫有吉星吉门吉神 → 空亡但不凶，等时间就行

马星（动、变、快）

马星在哪，哪里就有"动静"： - 用神宫逢马星 → 此事会快速变化 - 空亡宫+马星 → 这事马上要动了（快填空了） - 马星对冲 → 变动方向

马星位置速查：

寅午戌年/日 → 马星在申（坤2） 巳酉丑 → 马星在亥（乾6） 申子辰 → 马星在寅（艮8） 亥卯未 → 马星在巳（巽4）

四、实战练习

场景： 现在（2026年5月10日辰时，阳遁7局），你是Hot，想看看事业如何发展。

第一步：找用神 - 开门（事业）在兑7宫 → 逢天任星+九地 - 日干（你）= 丙午年生 → 年命丙午 - 丙在离9宫 → 逢天心星+死门+白虎 - 时干（事）= 戊在坤2宫 → 逢天蓬星+惊门+玄武

第二步：分析 1. 开门在兑7：事业在西方方向 → 天任（踏实）+ 九地（稳定）→ 你的事业方向是稳扎稳打、做长期建设。不是快速崛起型，而是慢慢积累型。 2. 日干丙在离9：你的个人状态 → 天心（有智谋）+ 死门（停滞感）+ 白虎（压力大）→ 最近精神压力大、有束手束脚的感觉，虽然脑子聪明但施展不开。 3. 时干戊在坤2：事情状状态 → 天蓬（冒进）-惊门（口舌）+玄武（不透明）→ 当前要做的事情有不确定性，需要谨慎。

第三步：结论

现在不是大举前进的时候。你的方向是稳定的（天任+九地），所以继续积累知识和能力。等月令变化（秋季金旺时，开门在兑7金宫会得旺），事业会迎来转机。

📋 断局入门总结

场景 核心用神 判断方法
事业 开门 + 日干 + 时干 开门在哪个宫，那个方向就是事业方向
财运 生门 + 戊 生门落宫决定财路
婚姻 六合 + 乙 + 庚 乙庚关系定婚姻好坏
健康 天芮 + 天心 天芮在哪哪里病，天心在哪哪里医
出行 开门 + 九天 + 马星 开门在哪往哪走

一句心法：

找到用神→看星门神组合→判断吉凶→结合现实给建议
