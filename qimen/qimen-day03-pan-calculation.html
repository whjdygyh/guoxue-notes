国学天师 · 奇门遁甲自学笔记

第三天 · 排盘实操：阴阳遁与节气定局

前言：排盘就是"填格子"

这可能是奇门学习中最难也最关键的一天。读完这一课，你应该能手工排出一个完整的时家奇门盘。

排盘的核心流程：

确定时间 → 定阴阳遁 → 定局数 → 布地盘三奇六仪 → 找旬首 → 定值符值使 → 布天盘九星 → 布人盘八门 → 布神盘八神

共 7 步，一步步来。

第一步：确定时间

一个奇门盘对应一个"时辰"（2小时）。

把当前时间换算成农历干支： - 年：查当年的干支 - 月：根据节气定（不是初一十五） - 日：查万年历 - 时：最重要，奇门排盘以"时"为单位

举例——2026年5月10日 上午8点（辰时）：

先用万年历查出： - 2026年 = 丙午年 - 5月5日立夏 → 5月10日仍在立夏节内 → 立夏下元（如何定元下面讲） - 5月10日 = 己未日 - 上午8点 = 辰时（7-9点为辰）

时干怎么算（五鼠遁口诀）：

甲己还加甲，乙庚丙作初 丙辛从戊起，丁壬庚子居 戊癸何方发，壬子是真途

己日 → "甲己还加甲" → 子时是甲子 → 辰时的天干是... - 子：甲子 - 丑：乙丑 - 寅：丙寅 - 卯：丁卯 - 辰：戊辰

所以：2026年5月10日辰时 = 丙午年 立夏月 己未日 戊辰时

怎样知道时辰的天干地支（不用口诀，直接理解）：

每天的第一个时辰（子时23-1点）的地支固定是"子" 根据当天的日干，用五鼠遁算出子时是什么天干 然后顺推就行

第二步：定阴阳遁

分界线： - 冬至→夏至（冬至当天到夏至前一天）：阳遁（阳气上升，顺布三奇六仪） - 夏至→冬至（夏至当天到冬至前一天）：阴遁（阴气上升，逆布三奇六仪）

2026年5月10日 → 冬至之后、夏至之前 → 阳遁 ✅

第三步：定局数

每1个节气=15天，分上中下三元（每元5天）。

节气定局口诀（超重要）：

冬至惊蛰一七四，小寒二八五同推 大寒春分三九六，芒种六三九是真 谷雨小满五二八，立春八五二相随 立夏清明四一七，九六三从雨水期 寒露后三更霜降，立冬六三九为准 大雪四七一数决，处暑排来一四七 立秋二五八仔细，白露九三六无疑 秋分大暑七一四，小暑八五二相宜 夏至小满九三六，小满五二八不欺

这口诀的意思是：每个节气对应三个局数——上元、中元、下元。

以立夏为例：

立夏清明四一七

解释：立夏节（和清明同公式）→ - 上元 = 4局 - 中元 = 1局 - 下元 = 7局

怎么定"元"（上中下）： - 每个节气=15天，分上中下三元 - 上元=第1-5天，中元=第6-10天，下元=第11-15天 - 但"元"还有另一个定法：根据符头（甲日/己日） - 符头：甲子、甲午、己卯、己酉 - 子午卯酉日 = 上元 - 寅申巳亥日 = 中元 - 辰戌丑未日 = 下元

我们实际怎么定？ 最简单的方法：查万年历。在现代，我们都是查时间然后确定节气+元。

举例继续： 2026年5月10日 → 立夏节（5月5日立夏）→ 5月5日是立夏第一天 5月5日 = 乙卯日 → 卯（符头：子午卯酉）→ 上元？ 不对，5月5日是立夏节气第一天，属于立夏上元。

5月10日是立夏的第6天 → 立夏中元（1局）→ 阳遁1局

行家看到这里可能会拍桌：不对！定元要看符头！不是简单数天数！但初学阶段，查节气+算天数的"简化法"足够上手。等排盘熟练了再去细究符头的精确算法。

阳遁1局 → 从坎1宫开始顺布戊己庚辛壬癸丁丙乙

第四步：布地盘三奇六仪

阳遁顺排：从坎1宫开始，按戊→己→庚→辛→壬→癸→丁→丙→乙的顺序，顺时针布入九宫。

固定顺序（一定要背住）：

戊己庚辛壬癸丁丙乙

解释：六仪（戊己庚辛壬癸）在前，三奇（乙丙丁）在后。

阳遁1局，顺布：

│      │      │      │

验证： 阳遁1局=戊在坎1（位置1），己在坤2，庚在震3...顺排无误。

阴遁的话怎么排？ 如果现在是阴遁，就从坎1开始逆布（戊→己→庚→辛→壬→癸→丁→丙→乙，按九宫顺序逆时针走）。

第五步：找旬首 + 定值符值使

旬首： 时柱（当前的时辰干支）所在的那一"旬"。

60甲子分6旬： - 甲子旬 → 子丑寅卯辰巳（甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉） - 甲戌旬 → 戌亥子丑寅卯 - 甲申旬 → 申酉戌亥子丑 - 甲午旬 → 午未申酉戌亥 - 甲辰旬 → 辰巳午未申酉 - 甲寅旬 → 寅卯辰巳午未

我们的例子： 时柱 = 戊辰时 → 戊辰属于甲子旬（甲子→癸酉，戊辰是第5个）

旬首 = 甲子

值符： 旬首对应的九星。怎么找？ - 先看地盘上旬首（甲子戊）在哪个宫 - 阳遁1局：戊在坎1宫 - 坎1宫的天盘原始星 = 天蓬星（坎宫本来对应天蓬） - 所以：值符 = 天蓬星

值使： 旬首对应的八门 - 旬首甲子在坎1宫 - 坎1宫的地盘原始门 = 休门（坎宫对应休门） - 所以：值使 = 休门

暂记： 甲子旬下的值符=天蓬，值使=休门

第六步：布天盘九星 + 人盘八门

布天盘（九星）： 1. 把值符（天蓬）先放到"时干"所在的宫位 2. 时干 = 戊辰时的 戊。地盘上戊在哪个宫？坎1宫 3. 值符天蓬落在时干宫（坎1），所以天蓬的位置不变？ 4. 不对，时干是辰时的天干是戊，戊在地盘坎1宫 5. 值符天蓬 → 落在戊（时干宫）所在的坎1宫 6. 所以天蓬就在坎1宫 → 其他星顺次落

注意： 阳遁顺排，当天盘值符定了之后，其他星顺排。

天蓬在坎1 → 天芮在坤2 → 天冲在震3 → 天辅在巽4 → 天禽在中5 → 天心在乾6 → 天柱在兑7 → 天任在艮8 → 天英在离9

布人盘（八门）： 1. 值使=休门。先确定"从哪个宫开始走" 2. 值使从旬首所在的宫（坎1）开始，走到"时支"所在的宫 3. 时支 = 辰，辰在巽4宫（辰→巽） 4. 所以休门从坎1→（阳遁顺排）→坤2→震3→巽4（到了） 5. 值使休门落在巽4宫 6. 顺排八门： - 巽4：休门 - 离9：生门 ← 生门是顺时针排的下一门 - 坤2：伤门 ... 依次类推

初学者排盘建议

说真的，手工排盘非常容易出错（上面我中间算局数就差点算错）。初学阶段的正确策略是：

三遍法： 1. 第一遍：用排盘软件/网页（如元亨利贞排盘网）输时间出盘 2. 第二遍：对照着软件出的盘，自己倒推"为什么这么排"，理解每一步 3. 第三遍：拿一个不同时间自己手工排一次，再用软件验证

手工排盘需要准备的工具： - 空白九宫图（打印几张备着） - 铅笔（错了可以改） - 万年历（看出时间的干支）

推荐排盘工具： - 元亨利贞排盘网（在线，最权威） - "奇门遁甲"手机App（备选） - 命令行python脚本（可以自己写一个）
