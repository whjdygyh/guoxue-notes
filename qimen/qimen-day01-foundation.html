国学天师 · 奇门遁甲自学笔记

第一天 · 奇门地基：五行天干地支九宫

前言：为什么奇门是"山顶"？

周易六十四卦回答的是"吉还是凶"，奇门遁甲回答的是"何时、何地、如何行动"。

打个比方： - 周易 = 导航仪告诉你"这条路能不能走" - 奇门遁甲 = 导航仪告诉你"现在出发，走东南方向，30分钟后出发最顺"

奇门遁甲 = 时间 × 空间 × 人事的立体决策系统。被称为"帝王之学"——兵家的排兵布阵、帝王的择时择方，靠的都是奇门。

一、五行生克（奇门的最底层逻辑）

五行是奇门的"化学元素"，所有排盘和断局都建立在五行基础上。

五行： 木 🌳 火 🔥 土 🏔️ 金 ⚔️ 水 💧

相生（生我者为母，我生者为子）：

木生火 → 火生土 → 土生金 → 金生水 → 水生木

相克（克我者为官，我克者为财）：

木克土 → 土克水 → 水克火 → 火克金 → 金克木

记忆口诀： - 生：木材烧火（木→火），火烧成灰（火→土），土里挖矿（土→金），金属化水（金→水），水浇树木（水→木） - 克：木桩插土（木→土），土堤挡水（土→水），水能灭火（水→火），火能熔金（火→金），金能砍木（金→木）

五行旺相休囚死（和季节的关系）：

季节 旺 相（次旺） 休（退休） 囚（被囚） 死（被克死）
春 木 火 水 金 土
夏 火 土 木 水 金
四季末（每季后18天） 土 金 火 木 水
秋 金 水 土 火 木
冬 水 木 金 土 火

记忆： 轮到谁当令谁就是"旺"，我生的就是"相"，生我的就是"休"，克我的就是"囚"，我克的就是"死"。

二、十天干（奇门的主角）

十天干是奇门盘中最活跃的元素——三奇六仪就是天干。

天干序列： 甲、乙、丙、丁、戊、己、庚、辛、壬、癸

三奇六仪的秘密： - 三奇：乙、丙、丁 → 日、月、星三奇，大吉之物 - 六仪：戊、己、庚、辛、壬、癸 → 六支仪仗队 - 甲的奥秘：甲是元帅，但永远不露面——"奇门遁甲"的"遁甲"就是甲被藏起来了

为什么庚最凶？

庚是阳金（最锋利的刀），甲是阳木（元帅的命）。 金克木 → 庚克甲 → 庚是甲最大的敌人。 所以奇门中庚出现的地方，就是"凶"的地方。 三奇（乙丙丁）的作用就是"护甲"——丙丁火克庚金，乙木合庚金。

天干合化（奇门断局的重要概念）： - 甲己合土 | 乙庚合金 | 丙辛合水 | 丁壬合木 | 戊癸合火 - 记忆：天地之合，《五鼠遁》的基础

十二地支是奇门的时间刻度——年、月、日、时辰都用它。

四、二十四节气（奇门的时间框架）

奇门盘每"局"对应节气——阳遁阴遁的切换以节气为界。

二十四节气顺序：

立春 → 雨水 → 惊蛰 → 春分 → 清明 → 谷雨 → 立夏 → 小满 → 芒种 夏至 → 小暑 → 大暑 → 立秋 → 处暑 → 白露 → 秋分 → 寒露 → 霜降 立冬 → 小雪 → 大雪 → 冬至 → 小寒 → 大寒

关键分界： - 冬至（12月21-23日）→ 开始阳遁（阳气上升，顺排） - 夏至（6月21-22日）→ 开始阴遁（阴气上升，逆排）

每节气三候（共七十二候，每个节气分上元中元下元）：

一个节气=15天，分上中下三元 每元=5天，对应一局 一年=24节气 × 3元 = 72局 加上阴阳遁 → 阳遁9局 + 阴遁9局 = 18种基本局

六、奇门遁甲的核心逻辑（预先理解全貌）

在开始排盘之前，先理解奇门"到底在排什么"——

一个奇门盘有四层信息：

层 名称 内容 来源
1 地盘 九宫+后天八卦 固定不变
2 天盘 九星（天蓬→天英） 随时间流转
3 人盘 八门（休生伤杜景死惊开） 随时间流转
4 神盘 八神（值符→九天） 随时间流转

加上： - 三奇六仪（天干分布到九宫） - 值符、值使（当前时辰的"值班干部"）

所以奇门排盘的实质是：在固定的九宫地图上，根据当前时间，算出天上什么星、地上什么门、什么神在值班，再把天干分到各个宫里去。
