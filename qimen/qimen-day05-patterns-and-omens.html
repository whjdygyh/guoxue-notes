国学天师 · 奇门遁甲自学笔记

第五天 · 格局全解：吉格凶格与克应

前言：格局是什么

排好盘、找到用神后，还要看天干和天干、星和门之间的特殊组合——这叫"格局"。

格局就像"化学反应"：戊遇到丙 → 龙回首（吉），丙遇到乙 → 悖格（凶）。同样是火，遇到不同元素反应完全不同。

一、五大吉格（遇到就是好事）

1️⃣ 龙回首（戊+丙）

戊 + 丙（同宫即为龙回首）

含义： 龙回头看了一眼。 - 戊=钱/资本，丙=太阳之火 - 资本被阳光照亮 = 财运好、事业顺、贵人相助 - 见到龙回首，百事可为

使用场景： - 问事业：升职有望 - 问财运：投资能赚 - 问出行：一路顺风

2️⃣ 鸟跌穴（丙+戊）

丙 + 戊（同宫即为鸟跌穴）

含义： 鸟飞回了巢穴。 - 丙=太阳，回到戊（土）这个"巢穴" - 落袋为安、回归本源 = 事业回归正轨、投资回本、好事收尾

使用场景： - 问项目能否落地 → 能 - 问投资能否回本 → 能 - 问能否回家/归位 → 能

3️⃣ 三奇得使

三奇（乙/丙/丁）遇到"值使门"所在的宫位

含义： 三奇中的某一个正好落在值使门（当前值班的门）的宫里。

没那么玄乎： 排盘的时候，乙丙丁三奇落在特殊位置。具体算法较复杂，初学先记住——三奇得使 = 大吉，适合做任何大事。

4️⃣ 奇仪相合

天干合化关系（乙庚合、丁壬合、丙辛合、戊癸合、甲己合）

含义： 用神宫位里的天干正好是合化关系。 - 问婚姻 → 乙庚合 → 姻缘天成 - 问合作 → 甲己合 → 合伙顺利 - 天干相合 = 人际关系和谐、事情有助力

5️⃣ 遁格（天遁/地遁/人遁）

  • 天遁： 丙+丁+九天（天时）
  • 地遁： 乙+己+九地（地利）
  • 人遁： 丁+乙+太阴（人和）

含义： 天地人三才各得其位。 - 天遁 → 时机好，顺势而为 - 地遁 → 位置好，扎根发展 - 人遁 → 人和好，有人相助

记忆口诀：

回首跌穴大吉象，三奇得使贵人访 奇仪相合人事美，遁格三才天地人

二、五大凶格（遇到就要小心）

1️⃣ 悖格（丙+乙）

丙 + 乙（同宫即为悖格）

含义： 太阳（丙）碰上了藤蔓（乙）。 - 乙木生丙火（按理是好事） - 但藤蔓缠住了太阳 = 好事变坏事、事情反复、被耽误

使用场景： - 问投资：看起来不错但其实有问题 - 问官司：案情复杂纠缠不清 - 像是"一件看似好的事，办起来才发现处处卡"

2️⃣ 刑格（庚+己）

庚 + 己（同宫即为刑格）

含义： 庚金碰上己土。 - 金克土 = 争斗、刑伤、是非 - 己土是"阴土"，代表不干净的地基 - 最凶的格局之一

使用场景： - 问官司 → 背后有人搞鬼 - 问合作 → 不诚信，可能有法律纠纷 - 问出行 → 路上有障碍

庚+己 + 白虎 = 血光之灾（要特别小心）

3️⃣ 天网四张（癸+癸）

癸 + 癸（同宫即为天网四张）

含义： 天罗地网。 - 癸=水，水太多了 - 天网撒下来了 = 被困住、走不了、事情卡死

使用场景： - 问出行/搬家 → 一时半会动不了 - 问官司 → 被套进去了，难脱身 - 问阻塞问题 → 像陷在泥潭里

轻重要看位置： - 天网在坎1（水之本位）→ 最凶，无处可逃 - 天网在离9（火克水）→ 能破网

4️⃣ 伏吟

所有天干都落在本来的位置上（一动没动）

含义： 整个盘看起来像没动过——死气沉沉，动不了。

怎么判断： - 天盘和地盘的天干完全相同 - 九星落在本宫 - 八门落在本宫

使用场景： - 问事业 → 原地踏步，升不上去 - 问感情 → 没有进展 - 问财运 → 不动就赚不到钱 - 伏吟=停顿，需要等"冲"（反吟）才能动

5️⃣ 反吟

天干落在对冲的位置

含义： 全盘看起来都是相反——太动荡了，不稳定。

怎么判断： - 天盘和地盘的天干全是相反/对冲位置 - 九星跑到对面宫里 - 八门也到对面

使用场景： - 反吟利"动"而不利"静" - 问出行 → 能成，但过程折腾 - 问投资 → 大起大落，赚钱也赚得心惊胆战 - 问感情 → 反复无常，要分分合合

伏吟 vs 反吟的区别：

伏吟 = 死水一滩（动不了） 反吟 = 翻江倒海（太动荡） 两者都不是好格局，但反吟至少"还在动"，伏吟是完全卡死

三、特殊格局

五不遇时（时光悖逆）

时干克日干

什么叫五不遇时： 排出来的时辰天干，正好克日柱的天干。

口诀：

甲日庚时逢，乙日辛时重 丙日壬时遇，丁日癸时逢 戊日甲时临，己日乙时攻 庚日丙时起，辛日丁时中 壬日戊时见，癸日己时穷

实战应用： - 即使全局一片大好，遇到五不遇时也不要做重要决定 - 五不遇时=在错误的时间做正确的事，结果也是错 - 问事→"不是时候，改天再来"

三奇入墓

三奇（乙丙丁）落在以下宫位： - 乙入墓在坤2 → 乙木埋在土里，发挥不出 - 丙入墓在乾6 → 丙火埋在金下，被压制 - 丁入墓在艮8 → 丁火埋在山里，烧不起来

含义： 三奇被埋了——大吉变中平，好事被压住了。

荧入白（丙+庚）

丙 + 庚

含义： 火（丙）克金（庚）。 - 问官司 → 对方（庚）要败诉 - 问竞争 → 把对手压制住 - 对己方是吉，对对方是凶——适合进攻

白入荧（庚+丙）

庚 + 丙

含义： 金（庚）反克火（丙）。 - 最凶的反转格局 - 本来是你赢，结果被翻盘了 - 问官司 → 刚觉要赢结果输了 - 问谈判 → 被对方压住

四、克应（天意的提示）

克应是奇门中最"玄"的部分——排好盘之后，周围发生了什么事，就是天意给你的暗示。

克应的种类：

类型 例子 含义
声音 排盘时听到鸟叫 吉兆（天籁之声）
声音 排盘时听到哭声 凶兆
视觉 排盘时看到喜鹊 大吉
视觉 排盘时看到蜘蛛/蛇 要小心是非
触觉 排盘时身上发冷 阴气重、事不吉
动静 排盘时有人敲门 事情要有消息了
文字 排盘时看到横幅/广告 暗示

克应的核心哲学：

不是"巧合"，而是天地人三才感应。 当你把注意力放在奇门盘上的那一刻，你的意识已经和天地接通了。 外界发生的事情，就是天地对你这次卜问的回答。

实战中如何运用： 1. 排好盘后，慢慢看一遍九宫 2. 闭上眼睛，回忆排盘过程中有没有什么"特别"的事 3. 如果有——把它和用神所在的宫位结合起来看 4. 例如：排盘时你老婆喊你吃饭 → 六合（婚姻）宫看怎么样了

五、综合实战：断一局看看

局： 2026年5月10日辰时，阳遁7局 求测者： 我（Hot），想问"现在学奇门这件事对不对" 排盘结果（简版）：

      巽4    离9    坤2
      天柱   天心   天蓬
      景门   死门   惊门
      六合   白虎   玄武
      庚     丙     戊
       ───────────────
震3   天芮         天任   兑7
杜门   太阴        开门   九地
己      ───────── 癸
       ───────────────
艮8   天英         天辅   乾6
伤门   腾蛇        生门   值符
丁               乙

分析：

① 日干（我）= 年命丙午 → 丙在离9宫 - 天心（聪明、有谋略）+ 死门（停滞）+ 白虎（压力） - 学奇门这件事，起步是沉闷的（死门），压力大（白虎） - 但天心在这里 = 你是用脑子在学，方向对

② 时干（当前之事）= 戊在坤2宫 - 天蓬（大胆突破）+ 惊门（要有心理准备）+ 玄武（不透明） - 学习过程会有很多"原来如此"的恍然大悟（天蓬代表着智慧突破） - 惊门=学习过程中会遇到挫折感

③ 生门（结果）= 在乾6宫 - 天辅（学问）+ 值符（正神保佑） - 学成之后，你会靠"文化知识"吃饭（天辅）+ 堂堂正正（值符） - 乾为天、为终——到最终会通天

④ 格局检查： - 时干戊在坤2，天蓬+惊门→无特殊格局 - 生门在乾6，乙+天辅+值符→ 奇仪相合（乙庚有合？当前宫只有乙） - 无大凶格 → 学习这件事本身不会出问题

结论： ✅ 可以学。起步会有压力和沉闷感（死门+白虎），但最终会靠天辅+值符获得真知。奇门这条路带你走向的是"以学识立身"的方向。
