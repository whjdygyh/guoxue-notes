梅花进阶 · Day 04 · 万物类象 · 八卦的无穷世界

起卦实战Day04我们已经学过用数字起梅花卦。但梅花易数的真正灵魂不是起卦方法，而是类象——随便看到一物、一色、一声、一形，立刻知道它对应什么卦，从而断吉凶。

邵雍在《梅花易数》中最经典的一例：看到双雀争枝坠地→雀=离卦→离属火→有火性→第二天果然有邻居女儿被火烧伤。

不是猜的，是他看到雀（离象）坠地（坤象），火入土→应验在女孩（离为中女）身上。

这就是万物类象的力量。今天我们就系统地吃透它。

二、类象在实战中的用法

取象原则

  1. 直接取象：看到一匹马→乾卦（马为乾）
  2. 性质取象：看到圆的、金色的→乾卦
  3. 功能取象：闪闪发光的东西→离卦（光=火）
  4. 颜色取象：红色→离卦；黑色→坎卦；黄色→坤卦
  5. 声音取象：雷声→震卦；风声→巽卦

取象选择规则

同一事物可能对应多个八卦，怎么选？

规则：看最显著的特征。

比如"红色圆球"→ - 红色→离 - 圆形→乾 - 选哪个？看场景。 - 如果是装饰品在桌上 → 乾（形胜于色） - 如果是在炽热的光源下看到 → 离（光色胜于形） - 如果是抛出去的东西 → 取动为震（动胜于静）

三、梅花占卜实战：全取象法

案例一：路上走，看见一只猫追老鼠

取象： - 猫追老鼠 = 追逐、捕食 - 猫 = 虎类 → 艮卦（虎属艮） - 老鼠 → 坎卦（鼠属坎）

象断： 艮（止）+ 坎（险）→ 止险之象。艮在上、坎在下 → ䷦ 山水蹇

䷦ 蹇卦 = 跛足难行，险在前。

结论：最近不要冒险做投资，前面有坑。

案例二：下雨天，见闪电击中老树

取象： - 闪电 → 离卦（电属离） - 老树 → 乾卦（老木属乾，但高大树木属震）

这里犹豫老树是乾还是震： - 震=大树，因为动+青色 - 乾=老、刚

所以离火（闪电）+ 震木（老树）= ䷔ 火雷噬嗑

噬嗑 = 咬合、刑罚、障碍物。

结论：有阻碍，需要"咬碎"才能通过。近期要注意合同纠纷。

案例三：早上起床，你家楼下的大门锁卡住了

取象： - 门 → 艮卦（门为止） - 卡住不动的门 → 艮上加艮 = ䷳ 艮为山

䷳ 艮卦 = "艮其背，不获其身"，停在那里，进退两难。

象断：今天不宜推进大事，宜静守。

四、取象+体用 联合断法

万类取象不是孤立玩的，要跟体用生克结合：

取象 → 得上下卦 → 本卦
时间/数字 → 确定动爻 → 变卦
体卦（动爻所在卦）vs 用卦（另一卦）
体用生克 → 吉凶判断

完整示例：看到一只红鸟从西边飞过

取象： - 红鸟 → 离卦（红+鸟属雉类=离） - 西方 → 兑卦

起卦：上离下兑 = ䷰ 火泽睽...不对，上离下兑 = ䷥ 火泽睽。离(3) + 兑(2) = 5 → 动爻 = 5爻

䷥ 火泽睽 → 五爻动 → 变卦䷍ 火天大有

体用： - 睽卦：上离(火)下兑(金) - 动爻在上卦的第五爻 → 体卦=离火（动方），用卦=兑金（对方） - 火克金 → 体克用 → 我能制人，吉利

具体断： - 火泽睽 = 分歧、矛盾之象 → 最近在和某人处在对峙状态 - 但体克用 = 你能赢 - 变卦火天大有 = 大有收获 - 结论：当前的分歧最终你会占上风，事情会往好的方向发展。建议主动沟通（睽必须合，睽极必合），结果会是大丰收。

五、练习

练习1

你去朋友家做客，他刚买了一盆红色花的仙人掌放在客厅西边。用什么卦象来断？ - 取什么象？ - 得什么卦？ - 体用关系如何？ - 怎么断？

👆 先自己推 **取象**： - 红花的仙人掌：红色=离，有刺=兑（有刺植物属兑） → 上离下兑 = ䷥ 火泽睽 - 西方：兑卦位 → 确认用兑 **体用**：体=离（你看到的东西），用=兑（环境/朋友） 火克金 = 体克用 → 你能掌控局面 **断**：睽卦 = 分歧、差异。仙人掌有刺但开红花（外刚内柔）。 你朋友这个人最近可能表面强硬（刺）但内心热情（红花），体克用说明你能和他处得来，但要注意方式方法。 变爻没有给出，不确定。但仅就体用说：**对方看着有点扎手，但你搞得定**。

练习2

你晚上走路，看到一条黑狗蹲在一个圆形的石头上不动。

取象、得卦、断？用你刚才学的。

👆 推完再看 **取象**： - 黑狗 → 坎（黑=水、狗=艮...这里颜色优先还是动物优先？） 这里有点纠结。狗=艮（动物类），黑=坎（颜色类）。 要看哪个特征更突出：狗蹲着不动 → 静止的特征最明显 → 取艮 - 圆形石头 → 乾（圆形+石头，形取乾） 上艮下乾 = ䷙ 山天大畜 **翻译**：大畜 = 积蓄、养精蓄锐。 - 艮止在乾健之上 → 暂时停止前进，积蓄力量 - 大蓄积 → 准备大干一场 **体用**：艮(土) + 乾(金) → 土生金 → **体生用** 你（艮/止）生出了它（乾/健）→ 你在为某件事做积累/培养。 **结论**：你现在处在"积蓄力量"的阶段，虽然看起来什么都没干（蹲着不动），但其实是在憋大招。等蓄够了（大畜），就会一飞冲天。
