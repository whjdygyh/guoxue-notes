梅花进阶 · Day 05 · 外应取象 · 天地万物皆可断

邵雍走在花园里，见二雀争枝坠地→断明日有少女折花被伤——果然应验。

他不是"猜"的，是用了外应：雀（离☲火象）+ 坠地（坤☷土象）→ 火入土 → 离为中女 → 被伤在少女。

外应 = 天地万物给你的即时信号。你走到哪里，天机就在哪里。

一、什么是外应

外应 = 起卦时或问事时，周围发生的"巧合事件"。这些巧合不是偶然——它们就是你问的那个事的答案。

外应的核心原则

天机在动，不动不成卦。
有触必应，有应必验。
至诚之道，可以前知。

外应 vs 梅花常规起卦

对比 常规梅花起卦 外应取象
触发方式 主动取数字/时间 被动接收环境信号
特点 有规则可循（数学公式） 靠直觉+类象
难度 低→中 中→高
准确率 稳定 看修行
速度 几分钟 一念之间

二、十大类外应

1. 声音外应

突然听到的声音——敲门、鸟叫、车鸣、东西掉地。

断法： - 敲门声：几声 = 数 → 取卦。但更重要的是"突然"这个特征 - 急而促 → 急事，看方向（东=震/急、西=兑/说） - 缓而稳 → 不急 - 杯盘摔碎 → 破财之象（兑为缺） - 喜鹊叫 → 喜事（离为喜） - 乌鸦叫 → 凶信（坎为暗）

2. 视觉外应

路上看到的东西——动物、颜色、形状、文字。

断法： - 见红 → 好事（离火），但若见血则凶 - 见白 → 丧事（兑金）或纯洁（兑为白） - 见老人 → 乾象（卦中按乾断） - 见孕妇 → 离象（中女有孕？不，取坤象——坤为母，为生育）

3. 意外事件外应

走路绊了一下、东西掉了、突然停电。

断法： - 被绊 → 艮为阻，前面有障碍 - 东西掉地上 → 东西掉+地面敲击 → 出事在脚下的方位 - 突然停电 → 离火熄 → 智慧事业受阻

4. 文字数字外应

看到车牌号、门牌号、广告词。

断法： - 直接作为起卦数字（同Day04数字起卦法） - 文字含义： - "福"字倒贴 → 福到了？不，也可以解读为"倒"（巽为顺，倒则为不顺） - "开"字 → 开为启，震象 - "关"字 → 闭为塞，艮象

5. 时间外应

举例：你问"今天谈合同能成吗"，恰好钟表响了11下。

  • 11 ≡ 离数(3) → 离为文书合同
  • 但11在卦数为乾（1+1=2? 不对，11÷8余3=离）
  • 上离下离 → ䷝ 离为火
  • 离 = 附丽、依凭 → 合同要"附着"在一方 → 能签

6. 人物行为外应

看见别人在做的事——走路姿态、交谈神态。

断法： - 背对着你 → 艮为止、为背 → 对方没诚意 - 对着你笑 → 兑为悦 → 事情顺利 - 捧水喝 → 坎为止渴 → 有需求要被满足 - 翻包找东西 → 巽为入 → 在寻找什么

7. 气候外应

断法： - 问事业时突然下雨 → 坎水克离（离为事业）→ 暂时不顺 - 问感情时雨过天晴 → 坎水去离火复明 → 感情和解 - 起风 → 巽为入，为不定 → 变动之象 - 打雷 → 震惊，忽然而至的消息

8. 数字外应

突然看到/想到的数字。

断法： - 直接用数字起卦（上÷8、下÷8、动爻÷6） - 或直接按数字含义判： - 1=乾（始）、2=兑（说）、3=离（火）…… - "七上八下" → 7艮(止)上、8坤(顺)下 → 心不安

9. 梦境外应

断法： - 梦见火 → 离为名，近期有出名之事 - 梦见水 → 坎为险，但水大也可能为财（坎为水=财在壬学） 在梅花中水为坎险，不要说财 - 梦见坠落 → 巽风落下 → 事业有变 - 梦见亲人 → 看具体人物取卦

10. 器物破损外应

断法： - 手机突然坏了 → 离火受损 → 沟通中断 - 眼镜碎了 → 离火破 → 看不清方向 - 车胎爆了 → 乾为车，乾锡破损 → 事情暂停

三、外应实战：邵雍经典案例

案例一：梅花占（史上最经典）

邵雍在花园赏梅，见二雀争枝坠地。

取象： - 雀 = 离（雉类鸟属离） - 争枝 = 相斗相争 - 坠地 = 落于坤土

断：明晚有少女来折花，园丁不知，遂相惊吓，少女坠地伤股。 - 离为中女 → 少女 - 兑为缺→伤（离兑合） - 巽为股→大腿 - 坤为地→坠地

如何出巽为股？二雀争枝互搏，巽为细木为枝，上兑下离，互卦中见兑巽——实际上梅花易数的原案用到了时间和年支的运算，但核心是外应取象。

果然次日黄昏，一位少女来折花，被园丁惊吓，坠落在地伤了大腿。

案例二：西林寺牌额占

一天，邵雍经过西林寺，看见牌额上写着"西林寺"三个字，但"林"字没有两钩。

取象：寺 = 属阴（寺庙属阴）。林字无钩 → 木为阴 → 阴上加阴。

断：寺中必有阴人（女人）连续出事。

寺僧听后大惊，因为确实有连续妇女死在那里的奇事。请邵雍解法。

邵雍改：在牌额上把"林"字的两钩补上（加阳），从此无事。

外应不是只能"断"，还能"解"——用象去调整。

案例三：今日占

你坐在办公室，突然桌面上的杯子倒了，水洒了一桌。

外应：杯子（容器）= 坎，水（坎）= 坎上加坎 → ䷜ 坎卦。

坎 = 险陷。水洒出 = 坎水外泄。

断：今天要小心——可能有麻烦事暴露。 - 坎为险，水外泄 = 秘密被揭 - 但水洒了也能擦干 = 问题不大

如果有同事恰好打电话来 → 电话（离火）被水浇 → 电话沟通要小心。

四、外应口诀（实战精华）

《梅花易数》中的外应十法，我译成能直接用的口诀：

△震动艮阻坎为险  
△兑说坤顺乾刚健  
△离火为明巽风入  
△万物皆卦无须算  
△动则观其机，静则观其象  
△耳闻为声卦，目见为形卦  
△身感为触卦，心念为意卦  
△事有反常必为妖  
△墙倒众人推，独木不成林  
△物有先兆时有变，事有机缘人有心

分别对应：

  1. 动应：突然的动，看是哪种——响动（震）、鸣叫（兑）、流水（坎）
  2. 静应：看静态物象——不动的东西（艮为山、坤为地）
  3. 耳应：听声音——悦耳（兑吉），刺耳（震凶）
  4. 目应：看颜色形状——红离、黑坎、黄坤
  5. 触应：身体感觉——冷坎、热离、风巽
  6. 心应：心头忽然闪过的念头——信则有
  7. 反象：反常——平时不这样突然这样了，必有大事
  8. 独象：孤立——一只鸟、一棵树、一个人，注意它的信息
  9. 时象：时间点——几点发生会加重某个五行
  10. 机象：缘分的信号——刚好这时候你看到这个东西

五、外应取象的陷阱（非常重要）

陷阱1：过度解读

错误：看到一片叶子落下就断"血光之灾"。

正确：叶子落 → 巽木落地 → 巽为入 → 只是"进入新阶段"的信号。除非叶子带血、或落时砸中了你。有联动才成卦，单一偶发不要过度解读。

陷阱2：事后诸葛亮

错误：事情已经发生了，才回想"哦我当时看到XX但没注意"。

正确：凡是在问事前注意到的异常，才是外应。 事后的"想起来"都不算，因为你的大脑会自动选择性回忆。

陷阱3：问什么答什么

错误：看到窗外两个人吵架→直接断"你要和人吵架"。

正确：外应要跟问题挂钩。你问的是事业，看到两人吵架 → 兑为说、为争论 → 说明今天有业务洽谈，但可能产生分歧（兑说变争吵）。

六、练习

练习1

你问"今天要去机场接一个重要的客户，能顺利吗？"话音刚落，窗户突然被风吹开。

取什么外应？怎么断？

👆 先想再看 **外应**：风吹开窗 - 风 = 巽 ☴ - 窗 = 离（窗户属离/空明？不，窗为艮——因为窗是透光用的开口，但巽风入艮窗…这里取"窗户打开"为离火通明之象…其实更直接：风（巽）吹开（动=震） 综合：上巽下震 = ䷑ 风雷益？不对，上巽下震是䷩风雷益？等等让我数一下： ䷩ 风雷益 · 上巽☴下震☳ 益卦 = 有利、增益、顺利。 **断**：风雷益 = 利于前行，利于过河（利涉大川）。接客户顺利，可能还会额外获得好的合作机会。 注意方向——风从哪个方向来？ - 东风（震）→ 事物有新开始 - 南风（离）→ 带名气的客人 等等。 **结论**：顺利，而且可能超出预期。

练习2

问"最近项目款能不能回？"谈话间，你同事的茶杯忽然裂了。

取什么外应？怎么断？

外应分析要注意：茶杯裂了是内部裂开还是突然爆裂？声音大不大？

👆 推开再看 **外应取象**： - 茶杯 = 容器 = 坎（盛水器） - 裂开 = 兑（缺口、缺憾） 上兑下坎 = ䷻ 水泽节（上坎下兑）——让我重算：茶杯裂=兑为缺口，水在杯中=坎。 上坎☵下兑☱ = ䷻ **水泽节** 节卦 = 节制、有限、阶段性的。 **断**： - 坎水（钱/款）在兑口（缺口）→ 钱从缺口流走 → **回款不会全额，会有折损** - 但节卦本身不算凶卦 → 只是"分期到"、"有损耗" - 裂了但不是全碎 → 不会完全收不回，但会延期或有损耗 **建议**：跟对方谈分期，别指望一次性全额到账。
