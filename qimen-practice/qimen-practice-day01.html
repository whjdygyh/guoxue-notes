二、断局分析

1️⃣ 日干与时干分析（自己+当下之事）

日干己（自己）在坤2宫，时干己（当下之事）也在坤2宫

→ 日干时干同宫：自己全身心投入当下之事，事情与自己合为一体

坤2宫组合：天蓬(凶) + 开门(吉) + 值符(吉) + 地己 - 天蓬星：凶星，代表破耗、冒险、大胆行事。但也代表"敢打敢拼"的魄力 - 开门：吉门，事业通达，做事顺利。开门在这里对冲凶星天蓬 - 值符：最吉之神，有贵人相助，有领导气场 - 地己：己为阴土，代表地户、私事、筹谋

断： 事情本身虽带有一些风险/破耗属性（天蓬），但开了吉门（开门），又有贵人暗中扶持（值符），整体走向是好的。适合大胆做事，但要注意天蓬带来的"冲劲过猛"的问题。

2️⃣ 财运分析（生门+戊）

生门（财运）在巽4宫：天冲(吉) + 生门(吉) + 太阴(谋) + 地辛

戊（钱财本身）在坎1宫：天英(中) + 死门(凶) + 九天(远) + 地戊

生门与戊不同宫 → 钱不聚于一处，流动性强

巽4宫（东南）: 天冲吉星 + 生门吉门 + 太阴（暗中谋划） - 天冲主快速行动，生门主利润，太阴主暗财/谋划 - 今日财运在东南方向，适合暗中谋划的一笔收入

坎1宫（北）: 死门 + 九天 - 死门主结束、停滞，九天主远行、远方的钱财 - 北方的钱暂时不动（死门），但有远财（九天）在远处

断： 今天东南方有暗财机会（巽4生门+太阴），适合暗中洽谈或处理跟钱有关的文书。北方的钱暂时不宜动。戊在坎1被死门压着，不适合做大的财务决策。

三、今日总结与建议

综合结论

「天蓬开山，艮兑避之；东南有财，乘太阴守之。」

今天整体偏吉。虽然天蓬凶星在坤2宫（日干宫），但被开门吉门和值符吉神压制住了，属于凶中藏吉、险中求胜的格局。

核心建议： 1. 🅰️ 做事方向：往西南或东南走。如果今天有事要办，选这两个方向 2. 🅱️ 财运：东南方有暗财机会，适合暗中筹备而非公开张扬 3. 🅲 人际：坤2有值符贵人，适合见领导、求人办事 4. 🅳 今日不宜：北上（死门）、西行（死门+白虎）、东北（伤门+玄武—小心被骗）

四、实战心得

今天自己排盘的收获

1. 旬首算法踩坑 之前脚本写错了60甲子索引公式，tg_idx*6+dz_idx只对部分有效，正确算法是用中国剩余定理或遍历。己巳时在甲子旬不是甲午旬——这要是错了整个盘全错。

2. 值使门顺数逻辑 休门从坎1开始，顺数5步到乾6。这一步走的是"九宫编号顺排"而不是"顺时针方位顺排"——两者不一样。

3. 八神跳中5 八神只占八宫不含中5，跳过中5后各神重新定位到对应宫位。 值符神落坤2→腾蛇震3→太阴巽4→六合乾6→白虎兑7→玄武艮8→九地离9→九天坎1

4. 日干时干同宫的解读 己未日己巳时 → 日干己在坤2，时干己也在坤2。同宫意味着"你做之事即是你"，投入度高但变通性弱。

需要继续练习的

  • 手动排盘速度还不够快，目前靠脚本辅助 → 目标是徒手5分钟排一盘
  • 八门平移后的吉凶判断还需强化
  • 特殊格局（伏吟/反吟/天网/刑格）的识别要更熟练
