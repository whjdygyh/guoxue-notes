案例一：六爻为主 · 问感情复合

背景

2026年5月11日午时，老公帮朋友问：跟女朋友分手两个月了，想复合还有希望吗？

摇钱结果：

次 结果 数字 爻
1 两字一背 6 ⚋ 少阴
2 三背 9 ⚊→⚋ 老阳动
3 两背一字 7 ⚊ 少阳
4 两字一背 6 ⚋ 少阴
5 两字一背 6 ⚋ 少阴
6 两背一字 7 ⚊ 少阳

起卦：本卦 = 上巽☴下震☳ = ䷩ 风雷益 动爻：二爻动（老阳变阴） 变卦：二爻动 → 下震☳变兑☱ = 上巽下兑 = ䷼ 风泽中孚

第一步：装卦

䷩ 风雷益（巽宫三世卦）→ 世在三爻，应在上爻

本卦：

辛卯 —  上九 木 → 兄弟 ☜ 应爻
辛巳 —  九五 火 → 子孙
辛未 --  六四 土 → 妻财
庚辰 --  六三 土 → 妻财 ☜ 世爻
庚寅 --  六二 木 → 兄弟 → **动爻**老阳变阴
庚子 —  初九 水 → 父母

变卦䷼ 风泽中孚（艮宫游魂卦）：

辛卯 —  上九 木 → 兄弟
辛巳 —  九五 火 → 子孙
辛未 --  六四 土 → 妻财
丁丑 --  六三 土 → 兄弟（世）
丁卯 —  九二 木 → 官鬼
丁巳 —  初九 火 → 父母

第二步：找用神

问感情复合 → 男占女 = 用神妻财

用神=妻财： - 六四辛未土 → 妻财（在应爻位置附近） - 六三庚辰土 → 妻财（世爻本身）

用神分析： - 辰土（世）：你自己的状态——月建辰土 → 临月建，极旺！ - 未土（四爻）：对方的位置——也在土位

日月： - 月建辰 → 土旺（辰月） - 日建甲子 → 子水（土克水，但辰月土旺，无大碍） - 空亡：甲子旬 → 戌亥空

第三步：关键爻分析

动爻：六二兄弟（木）动 → 兄弟动 = 中间有阻碍

第六感：兄弟动变官鬼（变卦九二丁卯 = 官鬼木）→ 阻碍变成了"新的关系"？

用神旺衰：辰土临月建 → 极旺 ✅ 忌神：克妻财的是木（木克土）→ 兄弟寅卯木 = 忌神 动态：忌神六二木动 → 但变为了变卦九二官鬼（木依然是木，但官鬼=新的男人）

第四步：世应关系

  • 世爻（六三妻财）→ 你，临月建极旺
  • 应爻（上九兄弟）→ 对方，兄弟临应 → 她现在是"独身/朋友"状态

第五步：综合结论

✅ 用神妻财临月建 → 极旺，感情基础在
⚠️ 动爻在二爻兄弟（忌神）→ 有人或有事从中阻隔
⚠️ 变卦中孚 = "中孚，豚鱼吉" → 诚心能感天
❌ 但注意：中孚是游魂卦 = 心不安定

结论：有希望，但不会很快。
阻力在"兄弟"——可能是你们之间的其他人说了什么，
或者你哥们儿中间有人搅和。

第六步：建议

  1. 中孚卦 = 需要真诚沟通 → 写一封真诚的信/消息，别通过中间人传话
  2. 时间：中孚 = 半年左右（农历八月酉月 = 辰酉合 → 感情合回来）
  3. 忌神木动 → 农历九月（戌月土旺克木）→ 阻力会减弱

案例二：梅花为主 · 问出行吉凶

背景

老公想去南方出差谈项目，问问此去吉凶。没说具体时间，就是现在问。

起卦：用当下时间——辰时（8:28，取8为兑，28为离...取数更自然：5月11日辰时）

其实更简单——用他的问题字数："去南方出差" = 5个字 → 上卦5=巽 "吉凶如何" = 4个字 → 下卦4=震 动爻：(5+4) ÷ 6 = 1余3

本卦：上巽下震 = ䷩ 风雷益（咦跟案例一主卦一样） 动爻：三爻动 变卦：三爻动 → 六三变九三 → 下震变离 → 上巽下离 = ䷤ 风火家人

互卦：益卦二三四=阴阴阳→艮☶ 三四五=阳阴阴→坤☷ → 上坤下艮 = ䷎ 地山谦

体用生克

动爻在三爻（下卦） → 体卦下震☳（木） 用卦上巽☴（木）

体用同木 → 比和 → 吉

体用比和 = 事情与你自己合拍，一路顺风。

类象解读

益卦䷩："利有攸往，利涉大川" → 宜出行，宜过河（出行大吉卦）

卦辞直接说了：适合出行、适合远行（涉大川）。

家人卦䷤：出差结果是"跟家人一样"——合作会变成长期伙伴。

谦卦䷎：中间要谦虚低调，不要张扬。

方位线索

南方 → 离卦（☲, 火） - 巽（木）+ 震（木）→ 体用比和 → 南方是"火"位 → 木生火 → 你的能量流向南方 → 出差能带动南方的市场/资源

结论

✅ 益卦"利涉大川" = 果断出行
✅ 体用比和 = 顺利无碍
✅ 变卦家人 = 出差后会建立长期合作关系
✅ 方向对——木去生南火
⚠️ 互卦谦 = 到了别太张扬，谦虚为好

案例三：奇门为主 · 问投资合作

背景

老公问：有个朋友拉我合伙开个餐饮店，在西北方向。2026年5月11日午时。

第一步：排奇门盘

2026年5月11日甲子日庚午时，立夏后阳4局。

（排盘参考Day07的排法）

关键信息提取：
- 开门在乾6宫（西北）→ 事业方向就是西北，好兆头
- 生门在艮8宫（东北）→ 财源不在合作方向
- 日干戊在4宫（杜门）→ 你有杜门阻隔，自己有些犹豫
- 时干庚在6宫（开门）→ 合作这件事本身就是"开"的

但等等——时干庚落开门 → 事情是正向的。

再看合作方：年命盘...

简化处理关键信息：

日干（你）：甲子旬，戊落4宫 → 杜门+天辅 → 你在考虑，但杜门有疑虑

时干（事）：庚落6宫 → 开门+天蓬 → 事情是"开门"的（能做成），但天蓬代表投资有风险

合作方：六合在...三宫（震·伤门）→ 合作带伤门 → 合伙可能有内耗

方位：西北（乾6宫·开门）→ 方向是对的

第二步：补梅花卦更细

主题就一句话："投资合伙开餐饮"

拆分数字：投(8画)、资(10画)...不好，用现代理解更好。

直接用时间起卦做第二验证：

5月11日午时 → 上挂5(巽) 下卦11÷8=3(离) 动(5+11+7=23÷6=5)五爻动

䷤ 风火家人（跟案例一的主卦一样！） 五爻动 → 上巽变艮 → 上艮下离 = ䷕ 山火贲

体用：动在上卦 → 体巽☴（你）用离☲（事） 巽木生离火 → 体生用 → 你要为此付出

主卦家人䷤ → 就像一家人一起做事 变卦贲䷕ → 修饰、外包、重包装不重实质

第三步：交叉验证

维度 奇门 梅花 一致
合作性质 开门+六合 家人卦（家人合作） ✅
财务 天蓬（有风险） 体生用（你花钱） ✅
方向 西北（开门） 家人南向（？） —
实质 杜门阻隔 贲卦仅修饰 ✅ 风险不小

第四步：综合结论

✅ 方向对（西北·开门）
❌ 投资有风险（天蓬+体生用=出钱）
⚠️ 贲卦=包装漂亮，实质不足
⚠️ 合作有内耗风险（伤门+家人卦的"内部矛盾"）

结论：项目方向可行（西北餐饮），
但不要一开始投太多，因为"贲"就是外面好看内里虚。
而且体生用=你出钱多，天蓬=风险不小。

建议：先试水，投少一些，等三个月观察。
若期间合作方表现出不靠谱，及时撤。
