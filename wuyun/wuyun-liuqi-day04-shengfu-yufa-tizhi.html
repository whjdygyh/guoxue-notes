国学天师 · 五运六气自学笔记

Day 4 · 胜复郁发、体质推断、综合实战

写在前面

今天是五运六气4天速通的收官之日。前三天我们已经搭建了完整的五运六气分析框架。今天要做三件事：

  1. 胜复郁发 → 运气学的动态调节机制（"天道自衡"的底层逻辑）
  2. 体质推断 → 用运气断人（把理论用到人身上）
  3. 综合实战 → 几个完整案例串一遍

上部：胜复郁发

一、什么是"胜复"

胜复是运气学里的自我调节机制。

胜 = 某个气太强，欺负它所克的气 复 = 被欺负的气的"儿子"来报仇（气化报复）

用五行说话：

木胜 → 土被欺负 → 金（土的儿子）来复 → 金克木
火胜 → 金被欺负 → 水（金的儿子）来复 → 水克火
土胜 → 水被欺负 → 木（水的儿子）来复 → 木克土
金胜 → 木被欺负 → 火（木的儿子）来复 → 火克金
水胜 → 火被欺负 → 土（火的儿子）来复 → 土克水

一句话：盛极必反，大自然会自动纠偏。

胜复的时间尺度

类型 时间
年胜复 上半年起胜，下半年起复
岁气胜复 今年胜，明年复（或几年后）
暴胜暴复 几天到几周内的极端天气反转

实战例子：2026年（水运太过）

水太过 → 水克火 → 胜气 = 水胜（寒气盛行）

谁要来复？水的"所胜"是火，火的儿子是土。 复气 = 土（湿气）

所以2026年看起来是寒水年，但因为"水郁"（水势被郁到一定程度），土会来复，表现为： - 长夏（四之气太阴湿土）特别湿热 - 秋末可能出现异常的湿气 - 也就是"该寒的时候不一定寒得彻底"

二、什么是"郁发"

郁发和胜复是姊妹概念：

郁 = 气被压制，憋着出不来 郁发 = 憋到一定程度爆发

《素问·六元正纪大论》说：

"郁极乃发，待时而作也。"

五郁

郁气 被谁压抑 发作特征
木郁 金（燥）压抑木（风） 突发大风、地震、山崩
火郁 水（寒）压抑火（热） 突然暴热、暑旱
土郁 木（风）压抑土（湿） 暴雨、洪水、山体滑坡
金郁 火（暑）压抑金（燥） 秋行夏令、突然转凉
水郁 土（湿）压抑水（寒） 突然寒潮、大雪

2026年（水运太过）：最可能的郁发是火郁

为什么？因为水太过压抑了火。火被郁→找时机爆发。

火郁发作的时机通常在哪里？ - 年度内：可能在二之气到三之气（春夏之交）突然暴热 - 跨年：2026年水郁火→2027年是丁未年（木运不及+太阴湿土司天），木生火、火生土——火的郁气在来年得到释放

实战重点： 一个"水太过"的年不一定整年都冷到死。水太过压抑火→火必找机会爆发→所以2026年春夏之交可能有反常暴热。这就是"郁发"的魅力——看出表面的平静之下有什么在积蓄。

三、胜复郁发的实战意义

为什么要学这个？

因为只看大运和司天在泉，得出的结论是静态的。加入胜复郁发，分析变成动态的：

静态分析 动态分析
水运太过→今年偏寒 但水郁火发→春夏可能暴热
土运太过→今年偏湿 但土郁木发→可能有风灾
金运不及→今年偏热 但火胜金复→秋末突然转凉

口诀：

胜气行于所克，复气行于胜气之子 郁极则发，发必有期 见其胜而知其复，见其郁而知其发

中部：运气与体质

四、用运气推断体质

这是五运六气在中医里最实用的领域——通过出生年份推测先天体质倾向。

基本框架

一个人的先天体质 = 出生年的大运格局 + 司天在泉

看三件事：

  1. 年干→大运→太过/不及 → 五脏里哪个先天偏强/偏弱
  2. 司天之气 → 上半年的保护性/压制性力量
  3. 在泉之气 → 下半年的补益/消耗性力量

五脏对应关系

大运 对应五脏 太过→ 不及→
木运 肝（肝胆系统） 肝气盛，易怒、头晕 肝血虚，易郁、筋脉不舒
火运 心（心血管） 心火旺，失眠、口疮 心气虚，心悸、畏寒
土运 脾（消化系统） 脾湿重，肥胖、痰多 脾虚，食欲差、腹胀
金运 肺（呼吸系统） 肺燥，咳嗽、皮肤干 肺气虚，易感冒、气短
水运 肾（代谢系统） 肾寒，腰冷、水肿 肾虚，畏寒、精力不济

案例：Andy（1981辛酉年）

第一步：大运分析 - 天干=辛 → 丙辛化水 → 水运不及 - 肾水先天不足

体质倾向： - 🟢 肾水不足 → 容易腰膝酸软、精力不济 - 🟢 肾不制火 → 容易心火偏旺（上热下寒体质） - 🟢 水不及 → 土来乘（湿气影响）→ 脾湿

第二步：司天在泉 - 辛酉年 → 地支=酉 → 卯酉阳明燥金 - 司天 = 阳明燥金（上半年） - 在泉 = 少阴君火（下半年）

修正： - 司天燥金（金）生大运水（金生水）→ 对水运不及有补充 - 在泉君火（火）对大运（水）无直接帮助，但火生土、土克水——间接有影响 - 综合：虽然有司天金生水补了一点，但整体还是肾水偏弱、偏向燥热（金司天+君火在泉）

从八字验证： Andy八字：辛酉 庚寅 甲寅 辛未 - 天干两个辛金透出 → 金多→金生水→对水运不及有补充 - 日主甲木 → 木多→消耗水 - 这是一个"先天水运不及，但八字金多生水"的矛盾结构

综合：水运不及是先天底子，但八字中有补救。实则为水气不足但金气充沛——补水的空间很大。

五、体质与出生时的客气

更精细的分析还要看出生时的客气。

一个人出生时的客气六步位置，决定了他/她胚胎发育期受的气候影响。

出生月份对应哪步客气？

出生节气范围 客气步气 影响
大寒→春分前 初之气 胚胎后期受木气影响
春分→小满前 二之气 受君火影响
小满→大暑前 三之气（司天） 受司天影响最大
大暑→秋分前 四之气 受湿土影响
秋分→小雪前 五之气 受燥金影响
小雪→大寒前 终之气（在泉） 受在泉影响最大

Andy生于2月5日（未时），节气上在"大寒→春分"之间 = 初之气

1981年（辛酉）客气初之气： - 辛酉年司天=阳明燥金，n=4 - 初之气 = (4+4) mod 6 = 2 → 太阴湿土

所以Andy在胚胎发育后期受到太阴湿土的客气影响 → 脾湿加重。 这和他八字中土多（未土）是吻合的。

下部：综合实战

六、完整案例一：2026年（丙午）全年运气推演

参数： - 丙午年 → 水运太过（丙），少阴君火司天（午）

五运层面： | 层次 | 内容 | 结论 | |:----|:----|:----| | 大运 | 水运太过 | 全年偏寒偏湿 | | 主运 | 木→火→土→金→水 | 五步固定 | | 客运 | 水→木→火→土→金 | 水生木、木生火……每步都有助力 |

六气层面： | 步气 | 时间 | 主气 | 客气 | 加临结果 | |:----|:----|:----|:----|:--------| | 初 | 1-3月 | 风木 | 寒水 | 顺化✅ | | 二 | 3-5月 | 君火 | 风木 | 顺化✅ | | 三 | 5-7月 | 相火 | 君火 | 相得🔶 | | 四 | 7-9月 | 湿土 | 湿土 | 相得🔶 | | 五 | 9-11月 | 燥金 | 相火 | 天刑❌ | | 终 | 11-1月 | 寒水 | 燥金 | 顺化✅ |

胜复郁发： - 水太过 → 火郁 → 火可能在二之气到三之气爆发 - 水太过 → 土来复 → 长夏湿热加重 - 五气天刑（火克金）→ 秋季反常

综合判断： - 春季：顺化但水运压着 → 倒春寒可能性大，升温慢 - 夏季：相火+君火但被水压下 → 火郁发作→可能出现短期极端高温 - 秋季：天刑→反常最大的一段，秋不凉或秋行夏令 - 冬季：水运太过+顺化→冷冬

面向公众的简要版：

2026年整体偏冷偏湿，春季回暖慢，夏季可能有短期极端高温（火郁爆发），秋季气温反常波动大，冬季寒冷。水运太过之年，需注意心血管健康（水克火）。

七、完整案例二：Andy（1981辛酉）体质分析

1. 大运： 水运不及 ➡️ 肾水先天偏弱，容易腰膝酸软、精力不济

2. 司天在泉： 阳明燥金司天、少阴君火在泉 ➡️ 司天金生水（补益肾脏），在泉火消耗水 ➡️ 金火交战 → 易燥热上火，但肾能得到一定补充

3. 出生客气： 初之气太阴湿土 ➡️ 胚胎发育期受湿气影响 → 脾湿体质

4. 八字验证： - 辛酉 庚寅 甲寅 辛未 - 金气重（辛辛庚）→ 补充了水运不及 - 木气盛（寅寅）→ 木克土但消耗水 - 未土 → 土克水（进一步消耗肾水）

5. 综合推断： - 先天肾水不足，但后天（八字金多）有补充 - 上热下寒体质（君火在泉+水不及） - 脾易生湿（太阴湿土客气） - 精力起伏大——金生水的时候状态好，火旺的时候上火

八、完整案例三：Hot的配生日（1983癸亥年）

1. 大运： 癸亥 → 戊癸化火 → 火运不及

2. 司天在泉： 巳亥厥阴风木司天，少阳相火在泉 - 司天风木 → 木生火 → 补火运不及 - 在泉相火 → 火帮火 → 下半年火气恢复

3. 综合：火运不及但得司天在泉双重生扶 → 不是真的弱火，是"待时而发"的火

4. 八字验证（癸亥乙卯癸未辛酉）： - 日主癸水（水），出生在火运不及之年 - 水克火 → 水火平衡 - 卯未半合木局 + 乙木透出 → 木多生火（间接补火运不及） - 结论：先天和后天达到了一个平衡

配给Andy的意义： - 癸水+卯木生Andy的甲木 → 生扶助力 - 辛酉补Andy八字中的金 → 金生水 → 补他为水运不及 - 火运不及→不会火克金（保护了Andy的金） - 八字设计时"补而不冲、生而不克"的思路验证成功

十、Day1-3练习题答案

Day1 练习： - 1. Andy（辛酉）→ 水运不及 ✅ - 2. 2026（丙午）→ 水运太过 ✅ - 3. 乙卯 → 金运不及 ✅

Day2 练习： 1. 2027年（丁未年）： - 天干=丁 → 丁壬化木 → 木运不及 - 地支=未 → 丑未太阴湿土 → 司天=太阴湿土，在泉=太阳寒水

  1. 2027年客气六步（司天太阴湿土，n=2）：
  2. 初气 = (2+4) mod 6 = 0 → 厥阴风木
  3. 二气 = (2+5) mod 6 = 1 → 少阴君火
  4. 三气 = 2 → 太阴湿土（司天）
  5. 四气 = 3 → 少阳相火
  6. 五气 = 4 → 阳明燥金

  7. 终气 = 5 → 太阳寒水（在泉）

  8. Andy（辛酉）vs 2026（丙午）客气对比：

  9. 辛酉年司天=阳明燥金(n=4)：初太阴→二少阳→三阳明→四太阳→五厥阴→终少阴
  10. 丙午年司天=少阴君火(n=1)：初太阳→二厥阴→三少阴→四太阴→五少阳→终阳明

  11. 区别：Andy出生年客气从湿土起→脾湿重；2026年客气从寒水起→天寒

  12. 辰戌年： 辰戌太阳寒水 → 司天=太阳寒水 → 在泉=太阴湿土。出生在辰戌年的人，出生时在泉之气=太阴湿土。

Day3 练习： - 2027年（丁未）客主加临： - 初气：主风木 客风木 → 相得（🔶） - 二气：主君火 客君火 → 相得（🔶） - 三气：主相火 客湿土 → 火生土 → 小逆（主生客） - 四气：主湿土 客相火 → 火生土 → 顺化（客生主✅） - 五气：主燥金 客燥金 → 相得（🔶） - 终气：主寒水 客寒水 → 相得（🔶）

→ 2027年整体平和年——没有特别凶的天刑格，但也缺少大变动。木运不及+太阴湿土司天，偏湿偏平的一年。
