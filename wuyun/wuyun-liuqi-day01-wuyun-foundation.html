国学天师 · 五运六气自学笔记

Day 1 · 五运基础：天干化运、大运主运客运

前置：五运六气是什么？

五运六气出自 《黄帝内经·素问》 的七篇大论（天元纪大论、五运行大论、六微旨大论、气交变大论、五常政大论、六元正纪大论、至真要大论），是中国古代时间医学的巅峰体系。

简单理解：

维度 内容 类比
五运 木火土金水五行在年际尺度的波动 每年的"宏观经济"
六气 风寒暑湿燥火在季节尺度的流转 每年的"天气预报"

五运讲"年" → 今年整体能量什么调性？ 六气讲"季" → 上半年下半年什么气候？每一步气什么特点？

这个体系的核心假设：天干地支不只是纪年工具，它们直接决定了天地之气的运行方式。 年干定五运，年支定六气。

一、天干化运（五运的加密规则）

不是"甲乙属木丙丁属火"那种简单的天干五行。天干化运有另一套规则：

甲己化土　乙庚化金　丙辛化水　丁壬化木　戊癸化火

这是五运六气最基础的口诀，必须背熟。

记忆法

按顺序记比硬背容易：

甲己 → 土
乙庚 → 金
丙辛 → 水
丁壬 → 木
戊癸 → 火

规律：每两个天干一组，相差5位（甲→己差5，乙→庚差5……），合化为一个五行。五行顺序为 土金水木火（不是常见的木火土金水）。

这个排列其实暗合五音建运体系：

五音 五行 天干
宫 土 甲己
商 金 乙庚
角 木 丁壬
徵 火 戊癸
羽 水 丙辛

为什么是这个对应？"正月建寅"说

《素问·五运行大论》解释：天地之道，始于土。 土居中央，统率四方。

一个流传最广的解释来自运气学祖师王冰： - 天地开辟之初，土先成（甲己） - 土生金（乙庚） - 金生水（丙辛） - 水生木（丁壬） - 木生火（戊癸）

按五行相生排下来的。

实用记忆法：甲己土、乙庚金、丙辛水、丁壬木、戊癸火——把前两个天干（甲乙）分别连上后两个（己庚），记住"甲乙是土金"就不容易乱。

二、大运（岁运）——决定一年的基调

大运也叫岁运、中运，是五运六气里"五运"的核心。它管的是这一整年的五行能量。

怎么定大运？

看年干 → 天干化运 → 得出大运的五行 → 判断太过不及

例子： - 2026年 = 丙午年。年干为丙。 - 丙辛化水 → 水运 - 丙为阳干 → 太过

所以2026年是 "水运太过之年"。

太过 vs 不及

这是五运最重要的概念之一。

阳年 阴年
年干 甲丙戊庚壬 乙丁己辛癸
大运 太过 不及
特征 能量过剩，可能亢害 能量不足，可能被欺

太过（阳年）：该五行的力量过强 - 比如水运太过 → 寒气流行、雨水过多 - 《素问·气交变大论》："岁水太过，寒气流行，邪害心火"

不及（阴年）：该五行的力量不足 - 比如水运不及 → 湿气大行（土来乘水） - 《素问·气交变大论》："岁水不及，湿乃大行"

实战口诀：

阳年大运太过，亢则害物；阴年大运不及，所胜妄行。

用Andy的出生年练手

Andy生于1981年（辛酉年）。 - 年干：辛 - 辛化水（丙辛化水） - 辛为阴干 → 水运不及之年 - 《素问》："岁水不及，湿乃大行……"

1981出生的人，先天体质偏向肾水不足、脾土受湿。（后面学到Day4我们会结合八字细看）

三、主运——五个季节的固定能量流

主运是固定的，不管哪一年都一样。就像春夏秋冬一样规律。

五分法

一年不是四季，是五运季（或者说五季），因为五行是五个：

主运 五行 季节 时间段（从大寒起算）
初运 木（角） 春 大寒→春分后13日（约73天）
二运 火（徵） 夏 春分后13日→芒种后10日（约73天）
三运 土（宫） 长夏 芒种后10日→处暑后7日（约73天）
四运 金（商） 秋 处暑后7日→立冬后4日（约73天）
五运 水（羽） 冬 立冬后4日→大寒（约73天）

每运73日5刻，五运合计365日25刻（取整一年）。

规律：五行相生顺序——木→火→土→金→水

为什么从大寒起？ 大寒是二十四节气的最后一个，阴极阳生，万物开始萌动。古人认为天地之气从大寒开始新一轮流转。

主运的太少相生

这里有一个细节：每运的太过不及是交替的。

从五音角度理解：

  • 初运木：太角（太过）或少角（不及）——每年不同
  • 二运火：以五行相生关系依次确定太少

但实战中，主运的太少主要用于精细推算五音和五运的"太过与否"，初学者先记住：主运是固定的五步五行能量流，每年都一样。 客运部分才是年际变动的核心。

主运一句话：五季的固定节奏，五行相生，年年如此。

四、客运——每年变动的叠加能量

客运是五运体系中最有"技术含量"的部分。它像在一首固定的旋律（主运）上叠加一个变奏，形成每年的独特调性。

怎么定客运？

以当年的年干化运（大运的五行）为初运，按五行相生顺序排下去。

例子：2026年（丙午年）= 水运太过

客运五步： 1. 初运水（以当年大运为初运） 2. 二运木（水生木） 3. 三运火（木生火） 4. 四运土（火生土） 5. 五运金（土生金）

再例：Andy的出生年1981年（辛酉年）= 水运不及 1. 初运水（大运为水运） 2. 二运木（水生木） 3. 三运火（木生火） 4. 四运土（火生土） 5. 五运金（土生金）

咦？跟2026年客运一样？因为1981和2026都是丙辛年（水运），所以客运顺序是一样的。

再试一个不同的：2025年（乙巳年）= 金运不及

客运五步： 1. 初运金（乙庚化金，大运为金运） 2. 二运水（金生水） 3. 三运木（水生木） 4. 四运火（木生火） 5. 五运土（火生土）

感知区别：同样是五步，但2026年初运水（寒），2025年初运金（燥）——每年春季的基调截然不同。

主客运叠加分析

季节 主运（固定） 2026客运（水运） 叠加效果
春（初运） 木 水 水生木→春季木气更强
夏（二运） 火 木 木生火→夏季更炎热
长夏（三运） 土 火 火生土→长夏湿热更重
秋（四运） 金 土 土生金→秋季燥气被土中和
冬（五运） 水 金 金生水→冬季更寒冷

结论：2026年各季能量得到客运的"生扶"，整体是能量偏强的一年。再加上大运本身就是水运太过——一整年偏寒偏湿，尤其是冬季。

五、核心公式汇总

五运系统 = 大运（年） + 主运（季节固定） + 客运（季节变动）

大运 = 年干化运（甲己土 乙庚金 丙辛水 丁壬木 戊癸火）+ 太过/不及
  阳年（甲丙戊庚壬）= 太过
  阴年（乙丁己辛癸）= 不及

主运 = 初木→二次→三土→四金→五水（固定，每年相同）
  每运73天，从大寒起算

客运 = 初运→以当年大运的五行起
  次运→按相生顺序往下排

六、实战练习

练习1：计算自己出生年份的五运

以Andy为例： - 1981年（辛酉），年干=辛 - 丙辛化水 → 水运 - 辛为阴干 → 不及 - 所以：1981年 = 水运不及之年

先天体质提示：肾水不足，易受湿气影响。长夏（三运土）时脾土会反侮肾水，需要特别注意脾胃和肾脏保养。

练习2：计算2026年（丙午）的五运

  • 年干=丙，丙辛化水 → 水运太过
  • 阳年 → 太过
  • 客运五步：初水 → 二木 → 三火 → 四土 → 五金

练习3：乙卯年的五运

  • 天干=乙，乙庚化金 → 金运
  • 乙为阴干 → 不及
  • 金运不及之年

金运不及 → 火来乘金（火克金）→ 当年偏热。这也是为什么Hot配的八字是癸亥年乙卯月癸未日辛酉时——乙卯年的金运不及，被我八字里的辛酉（金）补上了。

天干化运 甲己土、乙庚金、丙辛水、丁壬木、戊癸火
大运 年干的化运结果 = 今年的五行基调
太过/不及 阳年=太过，阴年=不及
主运 五季固定：木火土金水，年年如此
