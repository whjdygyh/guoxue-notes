国学天师 · 五运六气自学笔记

Day 3 · 客主加临与运气相合

前情提要

前两天学了…… 今天做什么
Day1：五运（年干→大运+主运+客运） 把五运和六气合并分析
Day2：六气（年支→司天在泉+主气+客气） 看主气客气是否相得/相失

一句话：Day1+Day2 = 原材料 → Day3 = 烹饪方法。

一、客主加临——主气与客气的"化学反应"

什么是"加临"？

加临就是"客气叠加在主气上面"。

客气 = 今年的变奏（每年不同）
主气 = 固定的季节节奏（年年一样）
加临 = 客气 加在 主气 上 → 产生实际气候

类似于：

主气是"春天该有的样子"→ 回暖、春风 客气是"今年春天额外加的东西"→ 加寒水→倒春寒；加君火→早热

加临的四种结果

客主加临的吉凶判断，主要是看客气是否克/生主气：

结果 条件 解释
顺化（吉） 客气生主气 天助我也，气候温和正常
天刑（凶） 客气克主气 气候反常，灾害多
小逆（次吉） 主气生客气 虽不顺，但无害
不和（次凶） 主气克客气 气候不调，疾病多
相得（吉） 主客气相同 一气独盛，但尚可接受

完整口诀：

客生主 → 顺化（吉） 客克主 → 天刑（大凶） 主生客 → 小逆（平） 主克客 → 不和（次凶） 相同 → 相得（平中带偏）

重要：天刑（客克主）是所有结果中最凶的，代表天地之气不和，容易出现极端气候和瘟疫。

为什么客生主是吉、客克主是凶？

这是中医"天人相应"的观念： - 客气代表外来之气（天的力量） - 主气代表本时之气（地的力量，本该如此） - 客气来帮主气（生）→ 天地和谐 - 客气来打压主气（克）→ 天地交战

二、实战：2026年（丙午）客主加临分析

我们把Day2算好的客气和主气放一起看：

步气 时间 主气 2026客气 相生相克 结果
初 1-3月 厥阴风木(木) 太阳寒水(水) 水生木✅ 顺化（吉）
二 3-5月 少阴君火(火) 厥阴风木(木) 木生火✅ 顺化（吉）
三 5-7月 少阳相火(火) 少阴君火(火) 相同 相得（平）
四 7-9月 太阴湿土(土) 太阴湿土(土) 相同 相得（平）
五 9-11月 阳明燥金(金) 少阳相火(火) 火克金❌ 天刑（凶）
终 11-1月 太阳寒水(水) 阳明燥金(金) 金生水✅ 顺化（吉）

2026年分析结论：

  • 初春到初夏（初气→二气）：顺化，气候温和宜人。但别忘了大运是水运太过，水克火，春末夏初的升温可能会被大运的寒气压制。
  • 盛夏到长夏（三气→四气）：相得，两火的夏天+两土的湿季，正常。
  • 秋季（五气）：大问题！ 相火（火）克燥金（金）→ 天刑。再加上2026大运是水运太过（水克火），五气这里火被水运克着，又去反克金——秋天会很乱，可能秋不凉、气温反常、燥气不降。
  • 冬季（终气）：顺化，金生水→冬寒。水运太过+终气顺化 = 今年冬天会特别冷。

三、运气相合——大运+客主加临的联合分析

上面只是六气层面的客主加临。完整的分析要五运和六气一起看。

四个组合类型

大运 + 六气 特征 案例
同化 大运五行 = 司天/在泉五行 比如水运太过 + 太阳寒水司天
异化 两者不同但相生 水运太过 + 少阴君火司天
不和 大运克司天/在泉 水运太过 + 少阴君火司天（水克火）
天刑 司天/在泉克大运 阳明燥金司天 + 木运不及（金克木）

核心关系：

大运是"老板"——管全年基调 司天在泉是"部门经理"——管半年的具体执行 两者合作不利→天气反常；合作顺利→风调雨顺

2026年完整运气分析

层次 内容 含义
大运 水运太过（丙年） 全年偏寒偏湿
司天 少阴君火 上半年偏热
在泉 阳明燥金 下半年偏燥
五气结果 天刑（火克金） 秋季反常

关键矛盾：水运太过（大寒）vs 少阴君火司天（上半年应热） - 大运的水克司天的火 → 不和 - 上半年寒气与热气交战，气候波动大 - 水太过，勉强压制住司天的火——但也会导致郁发（Day4讲）

综合判断： - 春季：水克火，但初气顺化 → 春温被寒气压，有倒春寒 - 夏季：两火相加但水运压着 → 该热但不一定极端热 - 秋季：天刑 → 最大的异常期，气候波动 - 冬季：顺化+水运太过 → 冷冬

四、天符、岁会、太乙天符——特殊运气格局

古人把运气组合中特别强的几种情况起了名字：

名称 条件 力量
天符 大运五行 = 司天五行 天地同气，力量极强
岁会 大运五行 = 年支五行 运气集中于一年
同天符 太过之年 + 大运与在泉同 下半年力量加倍
同岁会 不及之年 + 大运与在泉同 下半年力量加倍
太乙天符 天符 + 岁会 同时满足 天地人三合，能量最强

实战例子： - 2024年甲辰：甲己化土，土运太过；辰戌太阳寒水司天——不对应。 - 但如果是丁壬年（木运）遇上巳亥年（厥阴风木司天），就是天符（木运+风木司天，都是木）。

太乙天符的例子： - 戊午年：戊癸化火（火运太过）+ 子午少阴君火司天 + 午本身就是火 → 天符(火运=司天火) + 岁会(火运=年支午火) = 太乙天符 - 辛亥年？辛为水运不及，亥为厥阴风木——不对。

太乙天符年通常气候极端、灾害多——能量太强了，物极必反。

实战速记：不用死记天符/岁会的所有规则，记住"同气为盛，盛极必反"就可以了。真正断局的时候，重点是看大运和司天的生克关系以及客主加临。

五、如何用运气做实际推测

核心方法是三步走：

第一步：定大运（年干）

看年干→化运→太过/不及→全年基调

第二步：定司天在泉（年支）

看年支→化气→司天（上半年）→在泉（下半年）

第三步：做客主加临

排客气六步→比对主气→看每步的顺化/天刑/小逆/不和/相得

三分钟速查表

步骤 查什么 口诀/规则
1 年干化运 甲己土、乙庚金、丙辛水、丁壬木、戊癸火
2 太过/不及 阳干=太过，阴干=不及
3 年支化气 子午君火、丑未湿土、寅申相火、卯酉燥金、辰戌寒水、巳亥风木
4 司天 =年支化气
5 在泉 =司天的对面（少阴⇄阳明、太阴⇄太阳、少阳⇄厥阴）
6 客主加临 客气生主气=顺化吉，客气克主气=天刑凶
7 运气相合 大运生扶/克制司天？司天生扶/克制大运？

案例：Hot配的生日（1983年3月6日）

癸亥年乙卯月癸未日。先看年：

  • 癸亥年
  • 年干=癸 → 戊癸化火 → 火运不及
  • 癸为阴干 → 不及
  • 年支=亥 → 巳亥厥阴风木 → 司天=厥阴风木，在泉=少阳相火

分析： - 大运：火运不及 → 心火不足 - 司天：厥阴风木 → 木生火（司天补大运）→ 对火运不及有补充 - 在泉：少阳相火 → 下半年火气有所恢复 - 结论：虽然出生在火运不及之年，但司天风木生火、在泉相火帮忙——先天心火并非真的不足，是"后天能补"的格局。 - 而且我八字日主为癸水，水克火——火运不及遇上水日主，水火平衡了。这是巧合还是设计？设计时有考虑到这个。

六、运气的"化"与"制"

运气学不只是看谁克谁，还要看气化的动态过程：

关系 描述 现实含义
亢则害 五运太过，必然伤其所胜 水太过→害心火（心血管病多）
承乃制 被克的一方反过来约束克方 水太过→土来承制（湿气制寒）
制则生化 相克关系平衡后才能化生万物 有寒有热才能交替生长

所以光看"什么年运"不够，还要看"是否有制约"。

比如说2026年水运太过，看起来全是寒。但司天是少阴君火——火就是水的"承制"力量，上半年有火撑着不会太极端。关键是下半年，在泉是阳明燥金（金生水），助长了水势——所以秋冬才是真正的寒潮期。

核心洞察：运气的解读不是单线的"甲年=土"这么简单，而是看整个生克制化网络。
