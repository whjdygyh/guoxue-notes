国学天师 · 五运六气自学笔记

Day 2 · 六气基础：地支化气、司天在泉、主气客气

前言：五运 vs 六气

五运 六气
尺度 年（全年能量基调） 季节/月份（具体气候分布）
对应 天干 地支
核心 木火土金水 风寒暑湿燥火（君火相火）
节奏 五步（每步73天） 六步（每步60天87刻半）

五运看"今年整体怎么样"，六气看"今年每个时段怎么样"。

一、六气是什么

六气是 风、寒、暑、湿、燥、火 六种气候能量。

但中医把"火"分成两种：

六气 五行 三阴三阳 特征
风 木 厥阴（一阴） 条达、动摇
热（君火） 火 少阴（二阴） 温热、光明
火（相火） 火 少阳（一阳） 炎烈、蒸腾
湿 土 太阴（三阴） 濡润、重浊
燥 金 阳明（二阳） 清肃、干燥
寒 水 太阳（三阳） 寒冷、凝滞

注意！是六气不是五气，因为火被拆成"君火"和"相火"： - 君火∼热：温和的热量，如春末夏初的暖意 - 相火∼火：炽热炎烈，如盛夏的酷暑

口诀记忆：

厥阴风木　少阴君火　少阳相火 太阴湿土　阳明燥金　太阳寒水 → 这就是六气的标准配对

二、地支化气——六气版本的"天干化运"

这是六气最核心的口诀，必须背到像呼吸一样自然：

子午少阴君火　丑未太阴湿土 寅申少阳相火　卯酉阳明燥金 辰戌太阳寒水　巳亥厥阴风木

规律

每两个地支一组，相差6位（子→午差6，丑→未差6……），合化为一气。

三阴三阳的排列逻辑（从少阴开始，按"一二三倒着来"的螺旋）：

少阴（二阴）→ 太阴（三阴）→ 少阳（一阳）→ 阳明（二阳）→ 太阳（三阳）→ 厥阴（一阴）
子午　　　　　丑未　　　　　寅申　　　　　卯酉　　　　　辰戌　　　　　巳亥

为什么不从厥阴开始？这涉及"正化对化"的理论，简单说：少阴君火为尊，是万物的起始。

记忆法

容易记忆的方法是按顺序记感受：

地支组 化气 联想
子午 少阴君火 子（冬→阴极阳生）+午（夏→阳极）→ 火的源头和顶峰
丑未 太阴湿土 丑（土月）+未（土月）→ 湿土
寅申 少阳相火 寅（正月生发）+申（七月转凉但余热）→ 过渡的火
卯酉 阳明燥金 卯（春分）+酉（秋分）→ 春秋分，燥金肃杀
辰戌 太阳寒水 辰（水库）+戌（火库）→ 但配寒水，成"寒"
巳亥 厥阴风木 巳（四月风起）+亥（十月风藏）→ 风木

另一个角度：按三阴三阳的配对记

从少阴开始，一阴一阳交替： - 阴：少阴（君火）→ 太阴（湿土）→ 厥阴（风木） - 阳：少阳（相火）→ 阳明（燥金）→ 太阳（寒水）

但配对不是阴对阳，而是： - 少阴君火（子午）← 对面 → 少阳相火（寅申） - 太阴湿土（丑未）← → 阳明燥金（卯酉） - 厥阴风木（巳亥）← → 太阳寒水（辰戌）

这个对面关系就是后面要学的司天在泉。

三、司天在泉——上半年的boss和下半年的boss

概念

位置 管什么 对应什么气
司天 主上半年（大寒→小暑，约前半年） 第三步气（三之气）
在泉 主下半年（大暑→小寒，约后半年） 第六步气（终之气）

司天在泉是一对——上下相对。

三阴三阳的位置关系：

司天（在上）
  ↑
左右间气
  ↓
在泉（在下）

怎么定司天在泉

看年支 → 地支化气 → 司天 = 该气；在泉 = 对面

年支 司天 在泉
子午 少阴君火 阳明燥金
丑未 太阴湿土 太阳寒水
寅申 少阳相火 厥阴风木
卯酉 阳明燥金 少阴君火
辰戌 太阳寒水 太阴湿土
巳亥 厥阴风木 少阳相火

规律：司天和在泉永远是"一对相反的"：

司天 在泉
少阴君火 阳明燥金
太阴湿土 太阳寒水
少阳相火 厥阴风木

反过来也一样——阳明燥金司天 → 少阴君火在泉。

记忆法：少阴（火）↔ 阳明（金）——火克金 太阴（土）↔ 太阳（水）——土克水 少阳（火·相）↔ 厥阴（木）——木生火

后者是相生，前两个是相克——不是很整齐，不建议强行找规律，多算几次就记住了。

实战：2026年（丙午年）

  • 年支 = 午
  • 子午少阴君火 → 司天 = 少阴君火
  • 司天少阴 → 在泉为对面 → 在泉 = 阳明燥金

结论： - 2026年上半年：少阴君火司天 → 偏温热（但水运太过，寒热交战） - 2026年下半年：阳明燥金在泉 → 偏干燥

再例：Andy的1981年（辛酉年） - 年支 = 酉 - 卯酉阳明燥金 → 司天 = 阳明燥金 - 在泉 = 少阴君火

Andy出生那年的运气： - 大运：水运不及（肾水不足） - 上半年：燥金司天（金生水→对水运不及有补充） - 下半年：少阴君火在泉（火克金→下半年燥金受制）

四、主气——固定的六步节奏

跟主运一样，主气也是固定不变的，年年如此。

步数 节气范围 主气 五行
初之气 大寒→春分前 厥阴风木 木
二之气 春分→小满前 少阴君火 火(君)
三之气 小满→大暑前 少阳相火 火(相)
四之气 大暑→秋分前 太阴湿土 土
五之气 秋分→小雪前 阳明燥金 金
终之气 小雪→大寒前 太阳寒水 水

每步60天87刻半，六步合计365天25刻。

与主运的区别： - 主运是5步（木火土金水），每步73天 - 主气是6步（木→君火→相火→土→金→水），每步60天多

多出来的一步是因为火被拆成了君火和相火。

记忆法：按节气想清楚

大寒→春分   厥阴风木（春风开始吹了）
春分→小满   少阴君火（天气转暖了）
小满→大暑   少阳相火（真正热起来了）
大暑→秋分   太阴湿土（又湿又闷的伏天）
秋分→小雪   阳明燥金（秋高气爽）
小雪→大寒   太阳寒水（冬天最冷的时候）

五、客气——每年变动的六步

客气跟客运一样，是变动的。

怎么定客气？

第一步：司天 = 三之气 第二步：在泉 = 终之气 第三步：其余各气按三阴三阳顺序排

三阴三阳的顺序：

一阴 厥阴风木
二阴 少阴君火
三阴 太阴湿土
一阳 少阳相火
二阳 阳明燥金
三阳 太阳寒水

这个顺序叫阴阳进退之序——从一阴到三阴再到一阳到三阳。

实战：2026年（丙午年）司天=少阴君火

  1. 先定三之气（司天） = 少阴君火
  2. 再定终之气（在泉） = 阳明燥金
  3. 按顺序排其他气：
客气步骤 三阴三阳 对应气
初之气 太阳寒水（三阳） 寒水
二之气 厥阴风木（一阴） 风木
三之气 少阴君火（二阴） 君火 ← 司天
四之气 太阴湿土（三阴） 湿土
五之气 少阳相火（一阳） 相火
终之气 阳明燥金（二阳） 燥金 ← 在泉

怎么排出来的？ 先定三之气=少阴（二阴），按序列往回数：二阴之前是一阳（少阳）？不对。

等等，重新说清楚。

客气的排法规则：以司天为三之气，然后按三阴三阳的顺序往上推初之气，往下推四、五、终之气。

三阴三阳的固定顺序： 厥阴（一阴）→ 少阴（二阴）→ 太阴（三阴）→ 少阳（一阳）→ 阳明（二阳）→ 太阳（三阳）

这是一个循环。司天在哪一格，那一格就是三之气。

2026年司天=少阴君火=二阴。

在排列中，二阴是第二个位置：

厥阴(一阴) → 少阴(二阴) → 太阴(三阴) → 少阳(一阳) → 阳明(二阳) → 太阳(三阳)

把少阴定为三之气后，往前倒推初气、二气；往后顺推四气、五气、终气：

实际上这个排法有标准步骤：

标准客气排法： 1. 司天（三之气）= 年支化气 2. 在泉（终之气）= 司天的对面 3. 初之气 = 在泉的"前面两位"（在阴阳序中，倒退两个位置）

让我用实际数字来排。三阴三阳按顺序编号：

序号 气
0 厥阴（一阴）
1 少阴（二阴）
2 太阴（三阴）
3 少阳（一阳）
4 阳明（二阳）
5 太阳（三阳）

规则： 司天（三之气）在位置n，则： - 初之气 = 位置 (n+4) mod 6 - 二之气 = 位置 (n+5) mod 6
- 三之气 = 位置 n（司天） - 四之气 = 位置 (n+1) mod 6 - 五之气 = 位置 (n+2) mod 6 - 终之气 = 位置 (n+3) mod 6（在泉）

验证2026年：n=1（少阴） - 初气 = (1+4) mod 6 = 5 → 太阳寒水 ✅ - 二气 = (1+5) mod 6 = 0 → 厥阴风木 ✅ - 三气 = 1 → 少阴君火 ✅（司天） - 四气 = 2 → 太阴湿土 ✅ - 五气 = 3 → 少阳相火 ✅ - 终气 = 4 → 阳明燥金 ✅（在泉）

验证Andy出生年1981（辛酉）= 司天阳明燥金 = n=4 - 初气 = (4+4) mod 6 = 2 → 太阴湿土 - 二气 = (4+5) mod 6 = 3 → 少阳相火 - 三气 = 4 → 阳明燥金（司天） - 四气 = 5 → 太阳寒水 - 五气 = 0 → 厥阴风木 - 终气 = 1 → 少阴君火（在泉）

实战验证口诀：如果你算出来在泉恰好是"司天的对面"，说明排对了。

少阴（二阴）的对面是阳明（二阳）→ n=1对面n=4 → 在泉=4=阳明燥金 ✅ 阳明（二阳）的对面是少阴（二阴）→ n=4对面n=1 → 在泉=1=少阴君火 ✅

六、主气+客气叠加分析

跟五运一样，主气是动次打次的固定节奏，客气是变奏。两者叠加才是一年的实际气候。

2026年（丙午）主气+客气叠加：

步气 主气 2026客气 叠加效果
初（1-3月） 厥阴风木 太阳寒水 水克火/水生木？→ 初春偏寒
二（3-5月） 少阴君火 厥阴风木 木生火→春末升温快
三（5-7月） 少阳相火 少阴君火 两火🔥→盛夏酷热（但水运太过压着）
四（7-9月） 太阴湿土 太阴湿土 两土→长夏湿气极重
五（9-11月） 阳明燥金 少阳相火 火克金→秋燥被压制
终（11-1月） 太阳寒水 阳明燥金 金生水→冬季格外寒冷

这个叠加分析就是客主加临——明天Day3会深入讲。

七、Day2 口诀复习卡

地支化气（必须背）：

子午少阴君火　丑未太阴湿土 寅申少阳相火　卯酉阳明燥金 辰戌太阳寒水　巳亥厥阴风木

司天＝当年年支化气　在泉＝司天对面

司天在泉配对：

少阴(火) ← → 阳明(金) 太阴(土) ← → 太阳(水) 少阳(火相) ← → 厥阴(木)

主气六步（固定）：

厥阴风木(1-3月) → 少阴君火(3-5月) → 少阳相火(5-7月) → 太阴湿土(7-9月) → 阳明燥金(9-11月) → 太阳寒水(11-1月)

客气排法（以司天为三气，按序推）：

司天＝位置n → 初气(n+4)、二气(n+5)、三气n、四气(n+1)、五气(n+2)、终气(n+3)
