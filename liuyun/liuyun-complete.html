八字流年推运全解：太岁·十神·神煞·合冲刑害

流年推运，是八字命理中最实用也最上头的技术——每个人都会问"今年怎么样"。

本篇是流年推运的系统教程，涵盖：太岁基础、干支应期、十神流年法、神煞流年法、合冲刑害入流，以及针对你的八字（辛酉 庚寅 甲寅 辛未）的实战分析。

一、什么是流年

流年，就是每一年的干支。

  • 2026年是丙午年 → 流年干支 = 丙午
  • 2027年是丁未年 → 流年干支 = 丁未
  • 以此类推，六十甲子转一圈六十年

每一年有一个天干、一个地支，这两个字就是那一年的"气候"。看流年，就是看这一年的气候对你的八字（原局+大运）产生什么影响。

核心概念：流年是客，你的八字原局是主。客人来了，能不能合得来？是对你有利还是有害？

二、太岁

2.1 值年太岁

太岁就是你出生年份的地支对应的那个星神，道教民间有"当年太岁"、"本命太岁"的说法。

但八字中说的"太岁"，核心是指：

流年的地支 = 值年太岁

比如2026丙午年，太岁就在午。午对应正南方向，今年南方就不宜动土（风水上）。

2.2 太岁关系表

关系 含义
流年地支=年支 值太岁 — 本命年，变动大
流年地支冲年支 冲太岁 — 动荡、变化、搬家、换工作
流年地支刑年支 刑太岁 — 是非、口舌、纠纷
流年地支害年支 害太岁 — 小人、暗算、背后捅刀
流年地支合年支 合太岁 — 合作、人缘、贵人

但要注意——不是冲太岁就一定不好。比如八字身旺官杀重，遇到冲太岁反而把官杀冲开，反而升官。要看具体八字，不能迷信俗说。

三、流年干支断法

流年有两个字：天干 + 地支。

3.1 天干看外象

天干代表这一年发生什么——看得见的事。 - 丙/午（火）→ 文化、传播、互联网、火灾、心血、眼目 - 庚/辛（金）→ 金融、金属、手术、刀伤、法律 - 甲/乙（木）→ 教育、文书、树木、肝胆 - 壬/癸（水）→ 运输、贸易、血液、肾、流动 - 戊/己（土）→ 房产、土地、脾胃、建筑

3.2 地支看内因

地支代表这一年深层的原因和最终结果。

天干看表，地支看里。面上发生什么看天干，为什么发生看地支。

四、流年与原局的四种互动

4.1 引动

原局的某个字，被流年的同种五行引出来，力量就"活了"。

4.2 合

流年和原局产生六合、三合、半合。合到——好事/坏事被吸引来。

4.3 冲

流年和原局产生六冲——子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。冲意味着打破、变动、加速。

4.4 刑害破

  • 三刑：寅巳申、丑未戌、子卯、辰酉、午午、亥亥
  • 六害：子未、丑午、寅巳、卯辰、申亥、酉戌
  • 破：子酉、寅亥、辰丑、午卯、申巳、戌未

负面关系，意味着麻烦但不一定致命。

五、三层结构：原局→大运→流年

原局（先天命盘）
   ↓
大运（十年运势背景）
   ↓
流年（当年具体）

原局是根，大运是枝，流年是花和果。

重要法则

法一：先看大运再流年 大运好，流年差也只是小不顺。大运差，流年好也只是回光返照。

法二：流年应期看合冲 合到——被吸引来；冲到——被加速来。

法三：应期三要素 1. 原局出信息 2. 大运出舞台 3. 流年点触发

就像"剧本已写好 → 剧组已到位 → 灯光一打，开演"

六、流年吉凶速查

流年十神 大致含义
正官/七杀年 事业变化、压力、升迁、是非、官司
正印/偏印年 学习、考试、证书、贵人、房产
正财/偏财年 财运、收入、投资、消费、感情
比肩/劫财年 社交、竞争、朋友、破财、合作
食神/伤官年 创意、表达、娱乐、孩子、口舌

注意：同样官杀年，身旺是压力也是机会，身弱纯粹是倒霉。看八字喜忌。

七、十神流年法·详解

以日干为「我」，看流年天干与日干的生克关系确定十神，再看流年地支与原局地支的刑冲合害。

7.1 比肩·劫财（同我者）

关键词： 竞争、朋友、花费、固执、合伙、钱留不住

吉： 身弱逢比劫 → 得助、朋友帮忙、合伙顺利 凶： 身旺逢比劫 → 竞争大、破财、朋友借钱；劫财不利正财

口诀： 比劫重重必争财，身旺之年是非来；身弱得助人缘好，合伙生财也快哉。

7.2 食神·伤官（我生者）

关键词： 才华、表达、投资、情绪、变动、疾病

食神（吉）： 口福、享受、创意好、技术精进；食神生财格大吉 伤官（凶）： 锋芒毕露、口舌是非、折腾；注意官非；女命不利感情

口诀： 食神流年福禄来，心想事成笑颜开；伤官流年是非多，才华横溢也惹祸。

7.3 正财·偏财（我克者）

关键词： 财运、感情、投资、得利、花费

正财： 工资稳定、正常开销、置产 偏财： 意外之财、投资获利、社交活跃；来得快去得也快

口诀： 正财临位财稳来，量入为出不乱歪；偏财一现机遇广，投资社交通四海。

7.4 正官·七杀（克我者）

关键词： 事业、压力、升职、权威、责任、是非

正官（吉）： 升职、加薪、名声好；女命正缘 七杀（凶）： 压力大、被针对、小人、官司、手术；身弱多灾

口诀： 正官流年贵人来，事业顺利登台阶；七杀当道压力重，身弱需防意外灾。

7.5 正印·偏印（生我者）

关键词： 学习、长辈、学历、帮助、房产、记忆

正印（吉）： 学业有成、贵人相助、买房置产 偏印/枭神（凶）： 心思重、孤独；适合研究冷门学问；见食神则夺食

口诀： 正印流年福星照，学业房产都可靠；偏印临位心思沉，冷门学问能成真。

7.6 十神组合进阶

天干 地支 组合效应
官杀 印星 压力来→有化解，坏事变好事
财星 官杀 因财得权，也可能因财招事
食伤 财星 靠才华赚钱，食神生财格的大年
比劫 财星 争财破财年，不宜投资合伙
印星 食伤 用脑子赚钱，考试运极好
七杀 劫财 最凶组合之一——小心被坑、打架、破财

八、神煞流年法

十神法看"事"——升官发财还是破财伤身； 神煞法看"色彩"——这一年的氛围、际遇、偶然性。

核心原则：以年支和日支为主，结合流年地支查神煞。

8.1 常用神煞速览

神煞 性质 主事
天乙贵人 大吉 贵人相助、逢凶化吉
桃花（咸池） 中性偏吉 异性缘、社交活跃、艺术灵感
驿马 中性 奔波、变动、出差、搬家
华盖 中性偏孤 孤独、玄学、修行、艺术天赋
孤辰寡宿 凶 孤独、分离、独居、感情冷淡

8.2 各神煞流年详解

天乙贵人 — 大吉神，第一贵人星。遇贵人提携、办事顺利、逢凶化吉。

断： 天乙入流年，贵人到门前；办事遇通途，化凶为吉田。

桃花（咸池） — 中性偏吉。异性缘旺、社交活跃、艺术灵感强。已婚须防烂桃花。

断： 子午卯酉桃花位，流年一见春风吹；单身正是好时机，已婚须防烦恼随。

驿马 — 中性。出差、搬家、工作变动。驿马+冲=变动骤然而来。

断： 驿马流年动不停，奔波劳碌四处行；若是冲合并出现，变动来得更分明。

华盖 — 中性偏孤。喜欢独处、玄学缘分加深、艺术创作能力高。

断： 华盖当运艺文通，玄学佛道缘分浓；独处反比群居好，心灵深处有真功。

孤辰寡宿 — 凶。感情冷淡、社交疏离、内心孤独。同时出现则大凶。

断： 孤辰寡宿命中留，流年相遇更添愁；独坐灯前无人问，冷暖自知度春秋。

九、合冲刑害入流

9.1 六合流年应事

六合 应事
子丑合土 化解矛盾、合作达成；合化后看化神喜忌
寅亥合木 合作、文书、合同；木旺者利事业
卯戌合火 合作中有利可图，但火旺需留意
辰酉合金 合作求财、技术合作
巳申合水 因变动获利，巳申为驿马合——动中得财
午未合土 贵人合作、名誉提升

9.2 三合流年应事

三合局 应事
亥卯未木局 人脉拓展、团队壮大
寅午戌火局 名气提升、才华爆发
巳酉丑金局 财务问题、投资机会
申子辰水局 智慧提升、流动性

9.3 六冲流年应事

六冲 应事
子午冲 水火交战——情绪极端、心律问题、旅游变动
丑未冲 土冲——房产变动、脾胃问题
寅申冲 金木交战——车祸风险、手术、决策矛盾
卯酉冲 金木克——感情冲突、身体受伤
辰戌冲 土冲——家宅不宁、工作地变动
巳亥冲 水火冲——奔波劳碌、小人作祟

9.4 六害流年应事

六害 应事
子未害 凡事不顺、合作易散
丑午害 内部矛盾、与领导不睦
寅巳害 口舌是非、文书错误
卯辰害 破财、挑拨离间
申亥害 奔波中出事、劳而无功
酉戌害 感情纠纷、背后是非

9.5 三刑流年应事

三刑 应事
寅巳申三刑 最凶——官非、意外、手术、车祸
丑未戌三刑 家庭矛盾、房产纠纷、脾胃重病
子卯刑 无礼之刑——感情纠纷、晚辈叛逆
辰午酉亥自刑 自我折腾、抑郁倾向

9.6 合冲刑害综合断法

看流年应事，先看合，再看冲，再看刑害。

  1. 有合先论合 — 合能解冲、能缓解矛盾
  2. 无合再论冲 — 冲则动，动的性质看十神
  3. 刑害最后看 — 刑害是负面但程度轻

十、实战案例：2026丙午年你的八字全盘

你的八字： 辛酉 庚寅 甲寅 辛未 日主： 甲木（身旺，生于寅月） 原局特点： 金重官杀混杂，八字无水 2026年： 丙午

10.1 十神分析

天干丙=食神 → 食神泄秀，好年 - 有表达欲、创作欲、精气神旺 - 食神制杀（丙克庚七杀）→ 压力减轻 - 但正官辛金仍在——既想放得开又得守规矩

地支午火 → 午中藏丁火（伤官）+ 己土（正财） - 伤官生财 → 靠输出才华获利 - 午火助旺原局火势（原局无水灭火） - 注意：火太旺 → 急躁冒进、上火失眠

10.2 神煞分析

年支酉见午： - 午为桃花 → 2026桃花运旺，社交活跃 - 天乙贵人 → 辛年干见午为天乙，大吉！今年有贵人在关键时刻出现

综合： 贵人+桃花的组合 → 社交场合发光，有人赏识提携

10.3 合冲刑害分析

午火对原局： - 午未合 → 合了未土（正财），财被合旺 - 寅午半合火局 → 增强了丙午的火力 - 重点： 午与年支酉没有直接刑冲（酉午并非六冲或六害关系），稳定的根基没被动摇

10.4 结论

  • ✅ 大方向好年：食神泄秀，才华舒展，压力减轻
  • ✅ 适合推进：写作、创作、学习、表达类事务
  • ✅ 贵人在旁：天乙贵人临位，关键时刻有人提携
  • ⚠️ 要注意：火旺无抑→急躁冒进；辛金正官仍在→规矩不能破；注意上火失眠
  • 💡 建议：趁食神年多做输出、整理成果、阶段性收官
