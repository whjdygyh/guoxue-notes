八字流年 · Day 01 · 流年基础：太岁·干支·应期

流年推运，是八字命理中最实用、最上头的技术——每个人都会问"今年怎么样"。

学完今天，你就能看懂任意一年的流年干支怎么来的，什么叫"值年太岁"，什么叫"应期"，流年和原局怎么互动。

一、什么是流年

流年，就是每一年的干支。

  • 2026年是丙午年 → 流年干支 = 丙午
  • 2027年是丁未年 → 流年干支 = 丁未
  • 以此类推，六十甲子转一圈六十年

每一年有一个天干、一个地支，这两个字就是那一年的"气候"。看流年，就是看这一年的气候对你的八字（原局+大运）产生什么影响。

核心概念：流年是客，你的八字原局是主。客人来了，能不能合得来？是对你有利还是有害？

二、太岁是什么

2.1 值年太岁

太岁就是你出生年份的地支对应的那个星神，道教民间有"当年太岁"、"本命太岁"的说法。

但八字中说的"太岁"，核心是指：

流年的地支 = 值年太岁

比如今年是2026丙午年，太岁就在午。午是什么方位？正南。流年太岁在正南，这一年南方就不宜动土、不宜大兴土木（风水上）。

2.2 太岁三合六合

太岁跟日主地支的关系很关键：

关系 含义
流年地支=年支 值太岁 — 本命年，变动大
流年地支冲年支 冲太岁 — 动荡、变化、搬家、换工作
流年地支刑年支 刑太岁 — 是非、口舌、纠纷
流年地支害年支 害太岁 — 小人、暗算、背后捅刀
流年地支合年支 合太岁 — 合作、人缘、贵人

但你要注意——不是冲太岁就一定不好。比如你八字身旺官杀重，遇到冲太岁反而把官杀冲开，反而升官。要看具体八字，不能迷信"冲太岁不好"这种俗说。

三、流年干支怎么断

流年有两个字：天干 + 地支。

断流年的两条线：

3.1 天干看外象

天干代表这一年发生什么——看得见的事。 - 丙/午（火）→ 与火相关：文化、传播、互联网、火灾、心血、眼目 - 庚/辛（金）→ 与金相关：金融、金属、手术、刀伤、法律 - 甲/乙（木）→ 与木相关：教育、文书、树木、肝胆 - 壬/癸（水）→ 与水相关：运输、贸易、血液、肾、流动 - 戊/己（土）→ 与土相关：房产、土地、脾胃、建筑

3.2 地支看内因

地支代表这一年深层的原因和最终结果。

这十年大运走到了哪个地支，流年地支和它一互动，结果就出来了。

天干看表，地支看里。面上发生什么看天干，为什么发生看地支。

四、流年与原局的互动方式

流年进入八字，有四种互动模式：

4.1 引动

原局的某个字，被流年的同种五行引出来，这个字的力量就"活了"。

示例：你原局地支有申（金），流年遇到申→申被引动，合、冲、刑、害都跟着来了。

4.2 合

流年和原局产生六合、三合、半合。

示例： - 原局有丑，流年是子 → 子丑合土（合了就把丑土化了） - 原局有亥卯，流年是未 → 亥卯未三合木（木的力量大增）

4.3 冲

流年和原局产生六冲——子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

冲，意味着打破、变动、加速。

4.4 刑害破

  • 三刑：寅巳申三刑、丑未戌三刑、子卯刑、辰酉自刑、午午自刑、亥亥自刑
  • 六害：子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害
  • 破：子酉破、寅亥破、辰丑破、午卯破、申巳破、戌未破

这种负面关系往往意味着麻烦但不一定致命。

五、流年 + 大运 + 原局三层结构

断流年不是只看这一年的干支，而是看三层叠加：

原局（先天命盘）
   ↓
大运（十年运势背景）
   ↓
流年（当年具体）

原局是根，大运是枝，流年是花和果。

  • 原局决定了你的上限和下限
  • 大运决定了你这十年的基调
  • 流年决定了这一年开什么花、结什么果

重要法则

法一：先看大运再流年

大运如果是好运（帮扶日主），流年差一点也不要紧，顶多小不顺。 大运如果是差运（打击日主），流年好也只是一时，像回光返照。

法二：流年应期看合冲

  • 合到——好事/坏事被吸引来
  • 冲到——好事/坏事被加速来

比如原局有某件事的伏笔，一直没发生，等到流年跟这个伏笔产生合或冲的时候，事件就"应"了。

法三：应期三要素

  1. 原局出信息（比如财被比劫克，这是信息）
  2. 大运出舞台（比劫大运，这是舞台）
  3. 流年点触发（流年再出现比劫，这就爆发了）

这就像"剧本已写好 → 剧组已到位 → 灯光一打，开演"

六、简单的流年吉凶判断

当你会排盘之后，第一步判断：

流年十神 大致含义
正官/七杀年 事业变化、压力、升迁、是非、官司
正印/偏印年 学习、考试、证书、贵人、房产
正财/偏财年 财运、收入、投资、消费、感情
比肩/劫财年 社交、竞争、朋友、破财、合作
食神/伤官年 创意、表达、娱乐、孩子、口舌

要注意：同样都是官杀年，身旺的官杀是压力也是机会，身弱的官杀纯粹是倒霉。要看八字喜忌。

七、实战口诀

流年一入八字来，合冲刑害看上台。
天干发用接地支，大运为主流年配。
原局若是身强日，官杀一来反得财。
原局若是身弱日，比劫一来是帮台。
财官印食为吉用，枭杀伤劫为凶灾。
但要看官是何物，吉神被冲反成害。

八、你的八字复习

既然要学流年，先重新认熟自己的八字：

公历生日：1981年2月5日（农历正月初一）
八字：辛酉 庚寅 甲寅 辛未
日主：甲木
大运：己丑 戊子 丁亥 丙戌 乙酉 甲申 癸未 壬午

今日小结

  • ✅ 流年 = 每一年的干支
  • ✅ 太岁 = 流年地支，关键看六合三合六冲六害三刑
  • ✅ 天干看外象（发生了啥），地支看内因（为啥发生）
  • ✅ 三层结构：原局→大运→流年，大运为主
  • ✅ 应期 = 原局信息 + 大运舞台 + 流年触发
  • ✅ 吉凶看十神 + 八字喜忌
