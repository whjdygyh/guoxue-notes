八字流年 · Day 02 · 十神流年：官杀·印·财·比劫·食伤的年度应事

昨天讲了流年基础——太岁、干支、应期。但光有框架还不够，真正能看一年的关键是十神在流年里的角色转换。

同样一个丙午年，对身旺官杀重的你和对身弱财旺的人，意义完全不同。区别就在十神。

一、流年十神法·核心逻辑

八字原局里，每个天干地支都对应一个十神。流年干支来了之后，它会以十神的身份与原局发生互动。

基本规则：

  • 流年天干：主外、主事件性质、主名声运势
  • 流年地支：主内、主根基深浅、主实质影响

判断方法：

以日干为「我」，看流年天干与日干的生克关系确定十神； 再看流年地支与原局地支的刑冲合害，综合断应事。

二、十神流年应事表

1. 比肩·劫财（同我者）

关键词： 竞争、朋友、花费、固执、合伙、钱留不住

吉的一面： - 身弱逢比劫流年 → 得助、有朋友帮忙、合伙顺利 - 适合拓展人脉、组团队

凶的一面： - 身旺逢比劫流年 → 竞争大、破财、兄弟朋友来借钱 - 劫财尤其不利正财（劫财=夺财）、配偶关系紧张 - 比劫多现 → 容易因为朋友/合作破财

断法口诀： 比劫重重必争财，身旺之年是非来；身弱得助人缘好，合伙生财也快哉。

2. 食神·伤官（我生者）

关键词： 才华、表达、投资、情绪、变动、疾病

食神（吉神）： - 食神流年 → 口福、享受、创意好、技术精进 - 利于学习、讲课、创作 - 见财则生财（食神生财格大吉） - 投资眼光好

伤官（凶神）： - 伤官流年 → 锋芒毕露、口舌是非、折腾 - 利于考试/考试运好（伤官佩印） - 不利感情（伤官克官，女命尤其注意） - 注意意外受伤 - 伤官见官 → 官司、被领导训、离职

断法口诀： 食神流年福禄来，心想事成笑颜开；伤官流年是非多，才华横溢也惹祸。

3. 正财·偏财（我克者）

关键词： 财运、感情、投资、得利、花费

正财（稳定财）： - 正财流年 → 工资收入稳定、正常开销、置产 - 男命正财年 → 感情稳定、易有正经恋情 - 不贪不赌则顺

偏财（大财意外财）： - 偏财流年 → 意外之财、投资获利、偏门生意 - 人也大方、社交活跃 - 注意：来得快去得也快 - 男命偏财年 → 异性缘好、可能有露水情缘

断法口诀： 正财临位财稳来，量入为出不乱歪；偏财一现机遇广，投资社交通四海。

4. 正官·七杀（克我者）

关键词： 事业、压力、升职、权威、责任、是非

正官（吉神）： - 正官流年 → 升职、加薪、名声好、守规矩 - 女命正官年 → 正缘、感情稳定 - 利于求职、考试、签约

七杀（凶神）： - 七杀流年 → 压力大、被针对、竞争激烈 - 小人、官司、受伤、手术 - 身旺尚可撑住，身弱则多灾 - 七杀+财 → 因财惹祸 - 七杀+劫财 → 被人暗算

断法口诀： 正官流年贵人来，事业顺利登台阶；七杀当道压力重，身弱需防意外灾。

5. 正印·偏印（生我者）

关键词： 学习、长辈、学历、帮助、房产、记忆

正印（吉神）： - 正印流年 → 学业有成、贵人相助、父母健康好 - 买房置产、文书顺利 - 懒散但运气好——躺着也能成事

偏印（枭神，凶神）： - 偏印流年 → 心思重、想得多、孤独 - 适合研究、写作、冷门学问 - 见食神 → 夺食——影响事业、子女运 - 利偏门（玄学、灵修）

断法口诀： 正印流年福星照，学业房产都可靠；偏印临位心思沉，冷门学问能成真。

三、十神组合流年·进阶

流年不止一个十神——天干一个、地支一个。天干+地支的组合效应才是关键。

常见组合

天干 地支 组合效应
官杀 印星 压力来→有化解（印化杀），坏事变好事
财星 官杀 因财得权（花钱买官/升级），也可能因财招事
食伤 财星 靠才华赚钱，食神生财格的大年
比劫 财星 争财破财年，不宜投资合伙
印星 食伤 用脑子赚钱，考试运极好
七杀 劫财 最凶组合之一——小心被人坑、打架、破财

例：你的八字（辛酉庚寅甲寅辛未）看丙午年天干十神

日干=甲木

  • 丙火 = 甲木生丙火，阴阳相同 → 食神
  • 食神流年：甲木生丙火，你输出才华、想法、作品
  • 食神本身主吉——创意好、享受生活、技术精进

但天干丙+地支午构成食神+午火伤官暗藏，加上你原局辛辛重金克甲木，实际上是你用力扛压力时还能舒展才华的一年。

四、实战案例：你的丙午年（2026）初断

日主甲木，生于寅月（月令），身非常旺。

原局特点：金重官杀混杂（庚辛透干），八字无水。

丙午年分析：

  1. 天干丙=食神 → 食神泄秀，好年
  2. 让你有表达欲、创作欲、精气神旺
  3. 食神制杀（丙火克庚金七杀）→ 压力减轻，局势明朗

  4. 但正官辛金仍在→矛盾：既想放得开，又得守规矩

  5. 地支午火 → 午中藏丁火（伤官）+ 己土（正财）

  6. 伤官生财 → 靠输出才华获利
  7. 午火助长了原局的火势（原局无水灭火）

  8. 注意：火太旺而八字无水→容易燥、急于求成、上火

  9. 午VS原局

  10. 午火是甲木的伤官之位（午为甲之死地，注意）
  11. 原局酉午有破（自刑关系？实际上酉午没有特殊刑冲）
  12. 午火加强了寅午半合火局→食伤更旺

结论（初断）： - ✅ 大方向好年：食神泄秀，才华舒展，压力减轻 - ✅ 适合推进：写作、创作、学习、表达类事务 - ⚠️ 要注意： - 火旺无抑→容易急躁冒进 - 天干辛金正官仍然在→该守的规矩不能破 - 注意上火、失眠、皮肤问题（火旺无水） - 💡 建议：趁食神年多做输出、整理成果、阶段性收官
