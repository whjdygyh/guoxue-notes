起卦实战 · Day 01 · 金钱卦起卦法

一、为什么要学金钱卦？

之前我们精读了64卦，但那就像看菜谱背菜名——知道"麻婆豆腐"是什么，但真让你做你下不了手。

金钱卦是从古至今最主流、最正统的起卦法。从汉代京房创制到今天，三枚铜钱一摇，就是通天的信号。

和梅花易数的区别：

方法 原理 适用场景
金钱卦 三枚铜钱摇6次，每一爻通过概率决定阴阳 问具体的事、需要安静环境、追求严谨
梅花易数 用数字/声音/颜色等外部触发直接得卦 随时随地、快速出结果、追求灵活

建议： 先用金钱卦打好基础，再学梅花易数。金钱卦是"正道"——你以后给人算，传统上都是用铜钱摇的。

二、道具准备

只需要三枚一样的硬币。

铜钱最好（乾隆通宝最佳），但普通硬币也完全没问题。关键是三枚一致——方便区分正反面。

正反面规则：

硬币 定阴阳
有字的一面（乾隆通宝/1元/国徽） 背面 / 无字面（阴）
无字的一面（满文图案/菊花） 正面 / 有画面（阳）

⚠️ 注意： 关于阴阳的定法，不同流派有分歧。有人用"背为阳"（因为乾为天圆），有人用"字为阳"（因为文字代表人文）。最关键是统一标准，你习惯哪种就一直用哪种，不要换来换去。

我采用主流京房易的定法：背（无字面）为阳，字（有字面）为阴。因为背面向天，圆圆的天象象征乾卦——阳。

三、摇卦步骤

第一步：准备

找一个安静的环境，坐下来。三枚硬币放在手心，双手合拢（留出空间让硬币摇动）。

第二步：默念

心里默念你要问的事，要具体。 比如：

  • ❌ "我今年运气怎么样"（太宽泛）
  • ❌ "她喜不喜欢我"（指向不明）
  • ✅ "我和李明的这个合作项目，今年8月签合同的话，结果如何？"
  • ✅ "我想知道下周去面试的那家公司，对我未来发展如何？"

越具体越好。 八卦是感应系统，模糊的问题只能得到模糊的答案。

第三步：摇

摇动手中的硬币，让它们在手里翻转几次。然后撒在桌上或地上。

记录这一爻的结果。一共摇6次，从下往上记录——初爻最先摇，上爻最后摇。

四、如何记录每一爻

一次摇三枚硬币，结果有四种可能：

组合 名称 阴阳 符号 数字 备注
三枚全是背面（无字面） 老阳 阳爻变阴 ○ 或 —→-- 9 ⚠️ 动爻，会变
两背一字 少阳 阳爻不变 — 7
两字一背 少阴 阴爻不变 -- 6
三枚全是字面 老阴 阴爻变阳 × 或 --→— 8 ⚠️ 动爻，会变

📌 记忆口诀

三个背 = 老阳（9画〇），要变阴 两个背 = 少阳（7画—） 一个背 = 少阴（6画--） 没有背 = 老阴（8画×），要变阳

或者更简短的版本：

3背〇 = 老阳 → 变 2背— = 少阳 1背-- = 少阴 0背× = 老阴 → 变

注意：

  • 少阳和少阴是"静爻"——就是稳定的、不变的
  • 老阳和老阴是"动爻"——这一爻是"动"的，会发生变化，而且动爻是解卦的核心信息

五、从摇卦到成卦

摇完6次，从下往上写，得到本卦。

例子

假设我摇6次，结果如下（从第一摇到第六摇）：

第1次（初爻）：两字一背 → 少阴（--）
第2次（二爻）：两背一字 → 少阳（—）
第3次（三爻）：两背一字 → 少阳（—）
第4次（四爻）：三背老阳（○）→ 阳变阴
第5次（五爻）：两背一字 → 少阳（—）
第6次（上爻）：两字一背 → 少阴（--）

先画本卦（从下往上）：

上爻 ------------------- -- (少阴)
五爻 ------------------- — (少阳)
四爻 ------------------- ○ 老阳变阴 → --- (阳变阴)
三爻 ------------------- — (少阳)
二爻 ------------------- — (少阳)
初爻 ------------------- -- (少阴)

从下往上读符号：-- — — ○ — --

底下三爻（初、二、三）= 下卦 = -- — — = 震 ☳（一阳在下，二阴在上） 上面三爻（四、五、上）= 上卦 = ○ — -- = 但四爻是动爻要变……

等等，先不要变。 本卦就是：

下卦：-- — — → 震☳ 上卦：○ — -- → 第四个是老阳（阳爻），但五爻上爻分别是少阳和少阴。上卦是 — — -- → 离☲（外阳内阴）

所以本卦是：䷾ 雷火丰（上离下震）

然后画变卦：

把动爻（第四爻老阳○）从阳爻变成阴爻：

原四爻：— (阳) → 变成 → -- (阴)

变卦的上卦就变成了：-- — -- → 震☳

所以变卦是：䷏ 雷地豫（上震下震？不对，上卦变成震，下卦不变是震）

下卦：-- — — = 震 上卦（变后）：-- — -- = 震

上下都是震 = ䷲ 震为雷

本卦：䷾ 雷火丰 → 变卦：䷲ 震为雷 动爻：第四爻（九四）

六、本卦、变卦、互卦、错卦、综卦

起出一卦后，咱们得到了本卦。但这只是开始。一个完整的解卦要看五重关系：

① 本卦（主卦）

就是你第一次画出来的卦。代表当前的状态、问题的本质。

② 变卦（之卦）

把动爻变了之后得到的新卦。代表未来的发展、变化的结果。

如果没有动爻（全部少阳少阴）→ 只有本卦，没有变卦 → 卦辞是全部信息。

如果全部都是动爻（六爻全变）→ 乾坤两卦看"用九"和"用六"，其他卦看变卦。

③ 互卦

把本卦的二、三、四爻组成下互卦，三、四、五爻组成上互卦。

互卦代表事情发展的过程、中间状态。

例子：䷾ 雷火丰

— -- (上爻)
— — (五爻)
○ -- (四爻)   ← 三、四、五爻 = — ○ -- = 巽 ☴
— — (三爻)   ← 
— — (二爻)   ← 二、三、四爻 = — — ○ = 兑 ☱
-- -- (初爻)
  • 下互卦（二三四爻）：— — ○ = 兑 ☱
  • 上互卦（三四五爻）：○ — -- = 巽 ☴
  • 互卦：䷼ 风泽中孚

④ 错卦（旁通卦）

把本卦的每一爻阴阳全反过来。代表对立面、另一种可能性。

雷火丰䷾ → 阴阳全反 → ䷆ 地水师

⑤ 综卦（反卦/覆卦）

把本卦上下颠倒。代表换个角度看同一件事。

雷火丰䷾ → 上下颠倒 → ䷷ 旅卦

总结：解卦用什么？

类型 解读 优先级
本卦 当下的状态 ⭐⭐⭐⭐⭐
动爻 核心信息，最关键的线索 ⭐⭐⭐⭐⭐
变卦 未来的结果 ⭐⭐⭐⭐
互卦 中间的过程 ⭐⭐⭐
错卦 反面/另一种可能性 ⭐⭐
综卦 换个角度 ⭐⭐

咱们来练一个真实的例子。

问："这个周末和朋友一起策划的聚餐，氛围会怎么样？"

摇6次结果如下：

次数 结果 爻
1 两字一背 少阴 --
2 两背一字 少阳 —
3 两字一背 少阴 --
4 两字一背 少阴 --
5 三枚全是背面 老阳 ○（动爻）
5 两背一字 少阳 —

答案在本节末尾——建议先自己画一遍再对照。

👆 先自己试！答案在下面 **本卦爻象（从下到上）：** 
上爻 ---------- — (少阳)
五爻 ---------- ○ 老阳（要变）

**下卦（初、二、三爻）：** `-- — --` = **离 ☲** **上卦（四、五、上爻）：** `-- ○ —` = 五爻是动爻，但上卦在变之前看原状：`-- — —`（四爻少阴、五爻老阳当阳、上爻少阳）= 等等，上卦其实是 `-- — —` = 离☲？不对。 让我重新看清楚： 四爻是少阴 `--` 五爻是老阳 ○（暂时按阳看） 上爻是少阳 `—` 所以上卦 = `-- — —` = 上爻阳、五爻阳、四爻阴 → **一阴在下的阳卦** = 其实是两个阳爻一个阴爻在下的组合。 等一下，八卦的组成： 三画卦，从下到上： - 初爻（下面第一爻） - 二爻（中间） - 三爻（上面） 上卦的三爻是：四爻=初、五爻=二、上爻=三 所以上卦 = 四爻(--) 五爻(—) 上爻(—) = 少阴+少阳+少阳 = 底阴上两阳 = 震☳ 下卦 = 初爻(--) 二爻(—) 三爻(--) = 少阴+少阳+少阴 = 上下阴中间阳 = 离☲ **本卦 = 上震下离 = ䷔ 雷火噬嗑** **动爻：** 第五爻（老阳○），变阴 **变卦：** 五爻从阳变阴后，上卦变成 `-- -- —` = 上卦=坤☷，下卦不变=离☲ **变卦 = ䷣ 地火明夷** **互卦：** - 下互（二、三、四爻）= 二爻(—)、三爻(--)、四爻(--) = 阳+阴+阴 = 艮☶ - 上互（三、四、五爻）= 三爻(--)、四爻(--)、五爻(○当阳看) = 阴+阴+阳 = 艮☶ **互卦 = ䷳ 艮为山** **完整卦象：** - 本卦：䷔ 雷火噬嗑（当下的氛围） - 变卦：䷣ 地火明夷（发展的结果） - 互卦：䷳ 艮为山（过程） - 动爻：第五爻 这个卦很有意思：噬嗑卦是"咬合"的意思，卦象是口中含物要咬碎——说明聚餐的氛围需要"磨合"，一开始可能有些生疏或尴尬（噬嗑的卦象就是嘴中有物隔阂），但变卦地火明夷是"黎明前的黑暗"——说明结果还是光明的。互卦艮为山，过程有点"停滞/稳重"的感觉。

八、练习

练习1： 找三枚硬币，问一个你真正关心的问题（越具体越好），按步骤摇6次，记录下每一爻的结果。

练习2： 用记录的6个爻，画出本卦和变卦。查出卦名（用手机App或者之前精读的笔记查）。

练习3： 找到动爻。观察动爻的数量： - 没有动爻：就读卦辞 - 1个动爻：以该爻的爻辞为主 - 2个动爻：以上方的动爻为主 - 3个动爻：读本卦和变卦的卦辞 - 4个动爻：读变卦的下方的静爻 - 5个动爻：读变卦的静爻 - 6个动爻：乾坤用九/用六，其他读变卦

不用死记，用的时候查就行。
