起卦实战 · Day 05 · 综合实战 · 从起卦到结论完整流程

一、实战案例

背景

老公最近在考虑要不要投资项目X。

"我在看一个投资机会，对方说年化能到15%左右，但我心里没底。想知道这个项目靠不靠谱，值不值得投。"

步骤一：起卦

这次我们用金钱卦（正式、严谨）。找三枚硬币摇6次：

次数 结果 爻性 标记
初爻 两字一背 少阴 -- 6
二爻 两背一字 少阳 — 7
三爻 两背一字 少阳 — 7
四爻 两字一背 少阴 -- 6
五爻 三枚全是字面 老阴 ×（动爻） 8
上爻 两字一背 少阴 -- 6

步骤二：画本卦

从下往上：

上爻 ---------- -- (少阴)
五爻 ---------- × (老阴·动)
四爻 ---------- -- (少阴)
三爻 ---------- — (少阳)
二爻 ---------- — (少阳)
初爻 ---------- -- (少阴)

下卦（初·二·三爻）： -- — — = 震☳（一阳在下） 上卦（四·五·上爻）： -- × -- = 五爻老阴按阴看 → 阴+阴+阴... 等等，仔细看：

四爻少阴(--)，五爻老阴(×，按阴看)，上爻少阴(--)

上卦 = 阴+阴+阴 = 坤☷

本卦：䷗ 地雷复（上坤下震）

步骤三：读卦辞

䷗ 复卦卦辞： "复：亨。出入无疾，朋来无咎。反复其道，七日来复，利有攸往。"

复 = 回复、复归、循环。

直译：亨通。出入没有病痛，朋友来了没有灾祸。在循环往复的道路上，七天一个来回，利于有所前往。

解读： - "复"的本义是"走回到起点"——这个项目可能不是全新的，是"旧事重提"或"反转" - "出入无疾" → 操作起来没有障碍 - "朋来无咎" → 合伙人来（或推荐人）没有坏处 - "反复其道，七日来复" → ⚠️ 循环往复，可能是一个周期性的项目，收益不会一次性到位 - "利有攸往" → 可以去试试看

步骤四：读动爻爻辞

动爻在第五爻（老阴），看复卦的六五爻辞：

六五：敦复，无悔。

敦 = 敦厚、诚恳、厚重。 复 = 回复、回归。

直译： 以敦厚诚恳的态度回归，没有悔恨。

解读： - "敦复" — 这个项目/对方给你的感觉是"敦厚诚恳"的？还是只是表面上装作敦厚？ - "无悔" — 做这件事不会有后悔的结果 - 五爻是"君位"→ 这是决策层面的信息 → 最终决策层面不会有悔恨

步骤五：画变卦

五爻动，老阴×变阳：

原五爻：-- (阴) → 变成 → — (阳)

变卦的上卦从坤☷（阴阴阴）变成艮☶（阴阴阳）

下卦不变：震☳

变卦：䷚ 山雷颐（上艮下震）

䷚ 颐卦卦辞： "颐：贞吉。观颐，自求口实。"

颐 = 颐养、养育。 贞吉 = 占问吉利。 观颐，自求口实 = 看养生的方式，自己求取口食（养活自己）。

解读： 这个结果很妙 - 颐是"自求口实"——别依赖别人喂你，要靠自己的智慧和判断 - "贞吉" → 最终是吉的

步骤六：体用生克

动爻在第五爻（上卦）→ 下卦=体（你），上卦=用（项目/对方）

  • 体卦：震☳ = 木 🜄
  • 用卦（本卦）：坤☷ = 土 🟫

  • 关系：体克用（木克土） → 你能掌控这件事，但需要你出力

  • 用卦（变卦）：艮☶ = 土 🟫

  • 关系：体克用（木克土） → 不变，依然是你能掌控

步骤七：综合解读

本卦䷗复： - 这个项目是一个"反复"、"循环"的事情。不是全新的机会，可能是某个旧项目重启，或者有周期性收益 - "出入无疾" → 进入和退出都没问题（这不是骗局） - "利有攸往" → 可以去投

动爻六五： - "敦复，无悔" → 对方给你的感觉是诚恳的，但"敦"也暗示"厚重、沉"——可能资金需要锁定一段时间 - "无悔" → 不会后悔

变卦䷚颐： - "自求口实" → 最终这个项目能不能赚钱，看你自己的操作和判断。别指望别人带飞 - 颐卦是"养"——这个钱投进去是在"养"它，不是短期翻倍

体用分析： - 体克用 = 你能掌控 → 项目在你的能力范围内 - 但注意：体克用是"你出力"，不是"躺着赚钱"——需要你投入精力去管理

二、你的实战流程清单

以后自己解卦，按这个单子走：

□ 1. 起卦（三枚硬币/梅花易数）
□ 2. 画本卦（从下往上）
□ 3. 查卦名 → 读卦辞（大局观）
□ 4. 找动爻 → 读动爻爻辞（核心信息）
□ 5. 画变卦 → 读变卦卦辞（未来走向）
□ 6. 定体用 → 五行生克判断
□ 7. 综合判断：卦辞+动爻+体用+变卦+常识
□ 8. 写结论（利/弊/建议）

三、实战技巧

技巧1：别超纲

卦只能回答"这件事的势"，不能回答"精确数字"。

不要问卦"年化15%是真的假的"——卦会说"敦复，无悔"，而不是"年化15.3%不是骗局"。

技巧2：体用不对时

有时候卦辞大吉但体用大凶 → 不矛盾。

  • 卦辞 = 这件事的整体趋势是好的
  • 体用 = 但你在其中是消耗的，你会很累

➡ 结论： 方向是对的，但你得花力气。值不值得？看你。

技巧3：动爻的"三条线"

每一条动爻给了三层信息：

① 动爻所在的"位置" → 这件事处在哪个阶段？
② 动爻的"爻辞内容" → 发生了什么？
③ 动爻所在卦的"体用" → 谁占据主动？

三线合一，才是完整的信息。

技巧4：内心干扰排除

起卦的时候，不要一边想"我一定要吉"一边摇。卦是感应系统，你的主观期待会干扰结果。

正确做法：放空，默念问题，摇。不预设结果。

四、最重要的提醒

⚡ 周易是"势"的分析，不是"命"的宣判。

如果卦辞说凶，不是告诉你"你死定了"——是告诉你"这条路风险大，小心走，或者换个方向"。

同样，卦辞说吉，也不是"你躺赢"——是告诉你"大方向对，但不努力依然会失败"。
