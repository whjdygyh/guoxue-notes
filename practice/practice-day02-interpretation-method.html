起卦实战 · Day 02 · 解卦方法论 · 卦辞、爻辞、动爻

一、拿到一个卦，从哪看起？

很多人学会了起卦，但面对一个卦就懵了——"这几十条爻辞我怎么读？哪条才是我的？"

标准解卦流程（五步法）：

① 定动爻 → ② 读卦辞（大局） → ③ 读动爻爻辞（核心） → ④ 看变卦（结果） → ⑤ 综合判断

二、第一步：定动爻

动爻=整条信息的核心钥匙。

之前讲过：摇三枚铜钱，出现老阳（三背）或老阴（三字）就是动爻。

  • 老阳○（9）：阳爻，但会变成阴
  • 老阴×（8）：阴爻，但会变成阳

动爻的数量决定了解读的重心：

动爻数 解读方法
0 没有动爻 → 只读本卦卦辞（整体告诉你这件事的大方向）
1 最好解的情况 → 以动爻的爻辞为主，卦辞为辅
2 以上方动爻的爻辞为主（取"主变"之位）
3 读本卦+变卦的卦辞，结合中间动爻
4 读变卦的下方静爻
5 读变卦的静爻（唯一的静爻）
6 乾坤两卦看"用九""用六"，其他卦直接读变卦卦辞

初学建议： 先从"1个动爻"的情况练起，这是最简单的。我刚学的时候，一卦多动爻解读难度是指数级上升的。

三、第二步：读卦辞——大局观

卦辞是整卦的"标题"，告诉你这件事的基本性质。

比如䷂ 水雷屯的卦辞是：

屯：元亨利贞。勿用有攸往。利建侯。

直译：屯卦，大通顺，利于占问。不宜远行。利于建立诸侯（或：适合开创事业）。

但这样读太干巴巴了。我们要读出背后的意象：

  • 屯 = 幼苗破土（上坎水、下震雷，雷雨交加）
  • 意味着万事开头难——这件事刚开始"卡"住了
  • 元亨 → 但底子是好的，有潜力
  • 勿用有攸往 → 现在不要急着行动，不要急着往前冲
  • 利建侯 → 适合稳扎稳打打基础

✅ 一句话还原： "这事正在起步阶段，有前途但别急，先把基础打牢。"

四、第三步：读动爻爻辞——核心信息

这整条的解卦，动爻的爻辞是最关键的一行字。

动爻的位置含义

每一爻的位置不同，代表的时空阶段也不同：

爻位 象征 解读方向
初爻 起步/基础/底层 事情刚开始、根基、初心
二爻 基层执行/民间 具体操作、实干阶段、现状
三爻 中层管理/过渡 关键节点、转折、需要谨慎
四爻 高层/近君之位 接近决策层、机会来了但要小心
五爻 君位/最高决策 核心人物、决定走向、最吉之位
上爻 顶点/退休/终局 事情快结束了、过犹不及

例子

我们继续用䷂ 水雷屯卦，动爻在六二：

卜到这一爻，爻辞是：

六二：屯如邅如，乘马班如。匪寇婚媾。女子贞不字，十年乃字。

直译：艰难回旋的样子，骑马盘旋不进。不是强盗，是来求婚的。女子占问不嫁，十年后才嫁。

解读： - "屯如邅如" — 你现在的处境就像在泥泞中打转，走不动 - "乘马班如" — 明明有马（有资源有能力），却一圈圈绕着不走 - "匪寇婚媾" — 别误会，来的人不是坏蛋（这件事本身没恶意） - "女子贞不字，十年乃字" — 现在不是时候，要等——"十年"不是具体十年，而是"需要一段长时间"

✅ 一句话： "这事现在卡住了，但别急，对方没有恶意，只是时机不到。耐心等。"

五、第四步：看变卦——未来走向

变卦告诉你这事最终会发展成什么样。

示例

继续用䷂ 水雷屯，动爻六二变阴为阳→下卦从震☳变成兑☱→上卦坎䷜不变

变卦 = ䷄ 水天需

䷄水天需的卦辞： "需：有孚，光亨，贞吉。利涉大川。"

需 = 等待

解读： 这个结果卦也是"等待"——说明最终这件事就是要等的。但"有孚"（有诚信）、"光亨"（光明通达）、"贞吉"（占问吉利）——等到的结果会是好的。

✅ 本卦+变卦联合解读："一开始很艰难（屯），但坚持下去、等待时机，最终能成（需·光亨）。"

六、第五步：综合判断——五因素交叉

一个完整的解卦，要看五重信息互相印证：

┌─────────────────────────────────────────────┐
│ ①卦辞 → 这件事的整体性质                    │
│   屯 = 万事开头难，有潜力但别躁进         │
│                                             │
│ ②动爻爻辞 → 核心线索                       │
│   六二 = 现在走不动，不是坏事，需要等    │
│                                             │
│ ③变卦 → 最终结果                          │
│   需 = 等待是值得的，结果是光明的        │
│                                             │
│ ④互卦 → 中间过程                          │
│   ䷖剥 = 中间得经历"剥落"——放弃一些东西 │
│                                             │
│ ⑤体用生克（进阶）→ 谁对我有利            │
│   体=你，用=事/对方                       │
│   体生用=你付出，用生体=对方/事情帮你   │
└─────────────────────────────────────────────┘

七、三大学派速览

解卦的方法论，历史上形成了三大学派：

1️⃣ 王弼派（义理派）——"得意忘象"

卦是"符号"，不要死抠表面，抓核心"理"。

方法： 看卦辞+爻辞，读出这个道理 → 应用到你的问题上。 适合： 人生哲学、自我反思、大方向判断。 代表： 程颐《伊川易传》。

例子： 屯卦六二 → "这是告诉你——现在机会没成熟，先沉住气。"

2️⃣ 朱熹派（义理+象数折中）——"易本卜筮之书"

朱熹认为易经本来就是算命书，用占筮的方法读最准确。

方法： 以动爻为核心，结合爻位关系，参考体用生克。 适合： 务实占卜，问具体事。 代表： 朱熹《周易本义》。

例子： 屯卦六二 → 爻辞说"十年乃字"→ 根据动爻位置（二爻：基层执行阶段），知道这是一条"现在不宜行动"的指示。

3️⃣ 京房虞翻派（象数派）——"一卦含万象"

每卦能拆出10+个象来，纳甲、爻辰、互体、卦变、旁通……极度精准但极难学。

方法： 拆象。每一爻对应五行生克、天文地理、身体部位…… 适合： 高水平专业人士。 代表： 京房《京氏易传》、虞翻《周易注》。

初学建议

先用"王弼+朱熹混合法"：

  1. 读卦辞/爻辞的"道理"（王弼的"得意"）
  2. 用动爻锁定信息（朱熹的"动爻核心"）
  3. 再看变卦的趋向
  4. 最后用自己的常识判断——易经不能替代你的脑子

⚠️ 最重要的一句话： 卦辞告诉你的是一种趋势，不是命中注定。周易的核心哲学是"变易"——一切都可以通过人的行动改变。爻辞说凶，不一定是死路，是告诉你"这条路风险大，慎行"。

八、完整解卦实例

来一个完整的案例，把所有步骤走一遍。

背景

小张刚毕业，有两个offer： - A公司：大厂，薪资高但996 - B公司：创业公司，薪资一般但工作灵活 他问"我去哪个更好？"

起卦结果

他摇出6次（用之前学的金钱卦法）：

次 结果 爻性
1 两背一字 少阳 —
2 两字一背 少阴 --
3 两字一背 少阴 --
4 三背老阳 老阳 ○ → 动
5 两字一背 少阴 --
6 两背一字 少阳 —

第一步：画本卦

上爻 ---------- — (少阳)
五爻 ---------- -- (少阴)
四爻 ---------- ○ (老阳·动爻)
三爻 ---------- -- (少阴)    
二爻 ---------- -- (少阴)
初爻 ---------- — (少阳)

下卦： 初爻— 二爻-- 三爻-- → 阳+阴+阴 = 震☳

上卦： 四爻○ 五爻-- 上爻— → 动爻先按阳看 → 阳+阴+阳 = 离☲

本卦：䷾ 雷火丰

卦辞："丰：亨。王假之，勿忧，宜日中。"

丰是盛大的意思。亨通。王亲自到达，不用忧虑，适合在正午（最盛之时）行动。

第二步：动爻在第四爻

九四爻辞： "丰其蔀，日中见斗，遇其夷主，吉。"

直译：丰盛之时却遇上遮蔽（蔀=草席遮光），正午却见到了北斗星（黑天黑地），但遇到了与自己对等的人（夷主），吉。

第三步：画变卦

四爻老阳○变阴：

变卦上卦从离☲变成震☳，下卦不变还是震☳

变卦：䷲ 震为雷

卦辞："震：亨。震来虩虩，笑言哑哑。震惊百里，不丧匕鬯。"

震是雷震、震动。亨通。雷来了让人心惊胆战，之后又谈笑自如。震惊百里，连勺子里的酒都不会洒（内心稳得住）。

第四步：解读

本卦䷾丰： 这件事本身是"盛大"的——两个offer都不错，机会好 ✅

动爻九四： "丰其蔀，日中见斗"——大白天黑得像半夜，说明表面看起来光鲜（大厂、高薪），但实际有"遮蔽"（996、内卷、天花板）。"遇其夷主"——遇到与自己对等的人，也就是B公司那个创始人（小公司里老板和你平起平坐）。爻辞给的是"吉"。

变卦䷲震： 最终结果是"震动"——选哪条路都会有变化和冲击。但卦辞说"震来虩虩，笑言哑哑"——先怕再笑。还特别强调"不丧匕鬯"——核心的东西（你的能力、价值）不会丢。

结论

这个卦给的建议非常有意思： - 本卦丰 → 两个选择都是好的，但"勿忧，宜日中"→ 不要急着在"正午"（最强势的时候）做决定 - 九四动爻 → 表面最光鲜的可能有"遮蔽"，反而是那个"夷主"（对等关系）更好 - 变卦震 → 无论选哪条路，结果是你自己的能力不会丢失

⚠️ 但你发现了吗？这个卦没有直接告诉你选A还是选B。

真正的易经不替你做选择——它告诉你的是每种选择背后的势。最终决定，在你自己的脑子。
