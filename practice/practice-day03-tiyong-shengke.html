起卦实战 · Day 03 · 体用生克 · 你在卦中的位置

一、先问一个问题

你起了一个卦，读懂了卦辞爻辞，然后呢——

这个卦说的"我"在哪？哪个爻代表"我"？哪个代表"对方"？

这就引出了周易实战最重要（也是最容易被忽略）的一个概念：体用生克。

二、什么是体用

体卦 = 代表你自己、问卦的人、主体。 用卦 = 代表你所问的事、对方、客体。

怎么分体用？

方法： 看动爻。动爻在哪个卦里，那个卦就是用卦，另一个就是体卦。

情况 体卦 用卦
动爻在上卦 下卦是体 上卦是用
动爻在下卦 上卦是体 下卦是用
没有动爻 暂缺（读卦辞为主） 暂缺
多个动爻 看哪个卦的动爻最多 另一个

例1：䷂ 水雷屯，动爻在六二（下卦第二爻）

  • 动爻在下卦 → 上卦是体，下卦是用
  • 体卦 = 坎 ☵ （上卦=坎为水）
  • 用卦 = 震 ☳ （下卦=震为雷）
  • 体克用 = 坎水🜄克震木🜂 → 你能掌控这件事，但需要花力气

例2：䷾ 雷火丰，动爻在九四（上卦第四爻）

  • 动爻在上卦 → 下卦是体，上卦是用
  • 体卦 = 震 ☳ （下卦=震为雷）
  • 用卦 = 离 ☲ （上卦=离为火）
  • 用生体 = 离火🜂生震木🜄 → 这件事对你有利，结果对你有帮助

三、五行生克

体用确定后，看五行关系：

五行相生（相生=有利）

木 🜄 → 火 🜂 → 土 🟫 → 金 🔲 → 水 🜇 → 木

木生火、火生土、土生金、金生水、水生木

五行相克（相克=不利）

木 🜄 → 土 🟫 → 水 🜇 → 火 🜂 → 金 🔲 → 木

木克土、土克水、水克火、火克金、金克木

八卦五行归属

卦 五行 卦 五行
乾☰ 金🔲 坤☷ 土🟫
震☳ 木🜄 巽☴ 木🜄
坎☵ 水🜇 离☲ 火🜂
艮☶ 土🟫 兑☱ 金🔲

四、体用生克的结果解读

关系 含义 吉凶
用生体 对方/这件事对你好，能助你 ⭐⭐⭐⭐⭐ 大吉
体克用 你能掌控这件事，但你要出力 ⭐⭐⭐⭐ 吉
体用比和 体卦用卦同一五行，彼此相合 ⭐⭐⭐⭐ 吉
用克体 对方/这件事压着你 ⭐⭐ 凶
体生用 你付出给这件事，消耗自己 ⭐ 凶（耗）

📌 记忆口诀

用生体 → 躺着赚钱 体克用 → 我要管它 比和 → 一起使劲 用克体 → 它压着我 体生用 → 我在养它

五、但体用不是万能的

⚠️ 重点：体用生克是辅助工具，不是绝对标准。

为什么？

  1. 如果卦辞爻辞都是吉，但体用是"凶" → 以卦辞爻辞为主，体用表示这件事会"有点累"但不是不吉
  2. 如果卦辞大凶，体用却吉 → 以卦辞爻辞为主，体用表示"你在其中能自保"但不代表整体是好
  3. 没有动爻时 → 没有体用，纯读卦辞

正确姿势： 卦辞爻辞是"核心"，体用生克是"辅助分析"。先读卦辞爻辞，再用体用分析双方的力量对比。

六、综合实战：完整解一个卦

把你学会的东西串起来。用之前小张选offer的例子——学完体用之后，我们能读出更多信息。

回顾

本卦：䷾ 雷火丰（上离下震） 变卦：䷲ 震为雷 动爻：九四（上卦第四爻）

体用分析

动爻在上卦 → 下卦震☳ = 体（小张自己），上卦离☲ = 用（工作/公司）

  • 体卦震☳ = 木 🜄
  • 用卦离☲ = 火 🜂
  • 用生体（火生木）= 这件事对你有利 ✅ 大吉

变卦后，体用都变成震：比和关系 ✅ 吉

再读爻辞

九四爻辞："丰其蔀，日中见斗，遇其夷主，吉。"

结合体用： - "丰其蔀"（表面光鲜被遮蔽）→ 用卦离火被遮蔽，意味着"表面看起来好的那个公司"有问题 - "遇其夷主" → 体卦震木的"夷主"（对等之人）= 那个创业公司的老板 - 用生体 → 这个选择最终对你有利

再读变卦

䷲ 震为雷，体用比和 → 最终你选的路上，你和对方是"一起使劲"的关系

完整的解读

比之前的单一爻辞解读多了这一层：

"大厂那个看起来光鲜（丰），但内部有遮蔽（蔀），你进去了可能会很憋屈。反而是创业公司那个（夷主），你和老板是对等关系，你们能一起使劲（比和），而且对你个人成长有利（用生体）。"

七、练习

自己起一个卦（随便问什么事都可以），然后：

  1. 画本卦和变卦
  2. 找出动爻
  3. 确定体卦和用卦
  4. 判断五行生克关系
  5. 综合读卦辞/爻辞+体用

知识点 掌握程度
