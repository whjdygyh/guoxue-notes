六爻纳甲 · Day 03 · 断法实战 · 日月建、空亡、六冲六合

前两天的"装卦+六亲"相当于把地图画好。今天是真正的判读——用日月建、空亡、六冲六合这些工具，判断每爻的旺衰吉凶。

学完今天，你就可以独立完成一套完整的六爻占卜了。

一、日月建（判断旺衰的核心）

六爻占卜必须在特定的年月日时进行。这个时间决定了各爻的"状态"——是旺还是衰。

月建（当前月份的地支）

月建 = 起卦当月的地支（农历）。

月份 月建 节气
正月 寅 立春~惊蛰
二月 卯 惊蛰~清明
三月 辰 清明~立夏
四月 巳 立夏~芒种
五月 午 芒种~小暑
六月 未 小暑~立秋
七月 申 立秋~白露
八月 酉 白露~寒露
九月 戌 寒露~立冬
十月 亥 立冬~大雪
十一月 子 大雪~小寒
十二月 丑 小寒~立春

旺衰的十二状态

每个爻的地支，根据月建所在，有12种状态：

状态 含义 旺衰
临月建 与月建同地支 最旺
合月建 与月建六合（后面讲） 旺
生月建 月建来生该爻的地支 旺
克月建 月建来克该爻的地支 衰
冲月建 与月建六冲 凶
月破 正被月建冲 极衰

简化版（实战够用）： 1. 爻的五行与月建五行相同 → 旺（临月建） 2. 月建五行生爻的五行 → 旺 3. 月建五行克爻的五行 → 衰 4. 爻五行生月建五行 → 泄气（稍衰） 5. 爻五行克月建五行 → 耗力（中平）

日建（起卦当天的地支）

日建的影响类似月建，但更"即时"。

  • 临日建 → 该爻得日令之助，极旺（哪怕月建不利也暂旺一天）
  • 日建生 → 旺
  • 日建克 → 衰

月建管整体大环境，日建管当下瞬间。 月建=大趋势，日建=当前状态。

旺衰等级速判

等级 条件 断辞
🔥 极旺 临月建 + 临日建 + 元神生 "一冲就发，势如破竹"
✅ 旺 临月建或日建，或有生助 "成事顺利，时机成熟"
⚠️ 平 无生无克，自持本身五行 "待时而行，不宜急躁"
❌ 衰 被月日建克，或耗泄 "事倍功半，须防反复"
💀 极衰 被月建克 + 被日建克 + 月破+空亡 "休囚败绝，不宜妄动"

记忆口诀

月建管月，日建管天；
同我为旺，生我为喜；
克我为衰，冲我为破；
临月最盛，临日更坚；
冲破空亡，诸事难全。

二、空亡

空亡 = 当天日柱的地支与爻的地支"对不上"。简单说：这爻"不在状态"。

六十甲子空亡表

每旬有两个地支为空亡：

旬 空亡地支
甲子旬 戌、亥
甲戌旬 申、酉
甲申旬 午、未
甲午旬 辰、巳
甲辰旬 寅、卯
甲寅旬 子、丑

查法：先找当天日柱属于哪一旬，该旬的后两个地支就是空亡。

比如今天是庚午日→ 庚午属于甲子旬 → 空亡 = 戌、亥。 如果卦中某爻的地支是戌或亥，这爻就空亡了。

空亡的断法

状态 含义
用神空亡 事情落空，希望渺茫
世爻空亡 问卦人心中没底，信心不足
应爻空亡 对方不可靠，答应的事可能变卦
元神空亡 好事没助力，办不成
忌神空亡 坏事不落实，反为好事

空亡分真假： - 真空：该爻在月日都衰，空了就真没了 - 假空：该爻临月建或不衰 → 等出空（下一旬）就能成事

实战口诀： 空亡有真假，旺不为空； 动不为空，越空越凶； 用神空则凶，忌神空则吉。

三、六冲六合

六冲（地支相冲）

六冲 = 直接对冲，结果通常是"散、破、变"。

冲 子午冲 丑未冲 寅申冲 卯酉冲 辰戌冲 巳亥冲
五行 水火 土土 金木 金木 土土 水火

冲的影响

情况 断法
月破（月建冲爻） 爻的力量被强行打断，极衰
日冲 旺爻被冲散，衰爻被冲垮
用神被冲 好事被冲散，成不了
忌神被冲 坏事被冲散，好事来了
世应相冲 双方对立，不合作，离婚/分手信号

六合（地支相合）

六合 = 暗中合作，结果是"合、成、聚"。

合 含义
子丑合 水土相合，变得滋润
寅亥合 木水相合，生发之象
卯戌合 木土相合，结果之象
辰酉合 土金相合，财气之象
巳申合 火金相合，克中有合
午未合 火土相合，热烈之象

合的影响

情况 断法
用神得合 有贵人相助，事可成
世应相合 双方融洽，合作愉快（感情大吉）
元神合忌神 好事被拖累
合而化 两爻合在一起→力量集中，效果加倍

六合卦与六冲卦

整个卦的结构也有合冲关系：

六合卦（上下卦对应爻阴阳完全相反→相应相合）： ䷬ 泽地萃、䷊ 地天泰、䷩ 风雷益、䷮ 泽水困、䷻ 水泽节……

六冲卦（上下卦对应爻阴阳完全相同→对立对冲）： ䷀ 乾为天、䷁ 坤为地、䷜ 坎为水、䷝ 离为火、䷲ 震为雷、䷳ 艮为山、䷸ 巽为风、䷹ 兑为泽 + ䷮ 泽水困（注：困在结构上是合，实际要具体分析）

关系口诀： 六冲主散，六合主成； 用神冲则凶，忌神冲则吉； 用神合则吉，忌神合则凶； 世应冲必有变，世应合必成功。

四、动爻与变爻

动爻 = 起卦时摇出的老阳（○ 或9）/老阴（× 或8）。动爻会"变"——老阳变阴，老阴变阳，得到变卦。

动爻的三大意义

  1. 事情的关键：动爻所在的爻位就是事情发展的重点所在
  2. 信息量最大：一动"泄露天机"，动爻比静爻的判断权重高10倍
  3. 方向指示：看它变成了什么，就知道事情往哪个方向发展

动爻的断法

  • 用神动 → 事有转机，积极
  • 忌神动 → 麻烦要来了
  • 世爻动 → 你会主动去做
  • 应爻动 → 对方/事情先有动作
  • 独静（五爻动唯一不动）→ 这个不动爻反而是答案
  • 独发（唯一一爻动）→ 这个动爻信息最大

五、完整断卦流程（最终版）

第一步：起卦
摇6次铜钱，记下结果 → 得本卦、变爻 → 得变卦

第二步：装卦
① 定八宫（查表）
② 安世应（口诀）
③ 纳天干地支（按宫位）
④ 标五行 → 给每爻定六亲

第三步：找用神
根据所问之事选六亲：
· 财=妻财、事业=官鬼、文书=父母
· 兄弟=兄弟、福气=子孙、自己=世爻、对方=应爻

第四步：查日月建
· 月建 = 当月地支 → 看各爻旺衰
· 日建 = 当日地支 → 看各爻即时状态
· 查空亡（日柱→旬→空亡地支）

第五步：分析关键爻
① 用神：旺还是衰？空亡？被冲被合？
② 元神：有助力吗？
③ 忌神：有阻碍吗？
④ 动爻：哪一爻动了？变成什么？
⑤ 世应关系：冲还是合？

第六步：综合结论
用神旺 + 元神有力 + 无冲克 = ✅ 吉
用神衰 + 忌神旺动 = ❌ 凶
用神空亡但不久 = ⏳ 待时
世应冲 + 用神衰 = 💀 不宜妄动

第七步：提建议（最关键的一步）
不只是说吉凶——要给出方向建议：
· 什么时间（出空/合日）去做
· 什么方向（方位）去做
· 需要注意什么（克冲点）

六、完整实战案例

背景

2026年5月11日农历三月廿五，午时。老公问："今天谈的合作项目能成吗？"

摇钱结果： | 次 | 结果 | 爻 | 数字 | |:-:|:----|:--:|:---:| | 1 | 两字一背 | ⚋ (少阴) | 6 | | 2 | 两背一字 | ⚊ (少阳) | 7 | | 3 | 两字一背 | ⚋ (少阴) | 6 | | 4 | 三枚字面 | ⚋变⚊ (老阴×) | 8 → 动 | | 5 | 两背一字 | ⚊ (少阳) | 7 | | 6 | 两背一字 | ⚊ (少阳) | 7 |

本卦：上坤☷下震☳ → ䷗ 地雷复 动爻：四爻老阴变阳 → 变卦：上震☳下震☳ → ䷲ 震为雷

第一步：装卦

䷗ 地雷复（坤宫一世卦）→ 世在初爻，应在四爻

癸酉   上六  --  (金) → 子孙（金主坤土→我生）
癸亥   六五  --  (水) → 妻财（土克水）
癸丑   六四  --  (土) → 兄弟  ☜ 应爻 → **动爻**
庚辰   六三  --  (土) → 兄弟
庚寅   六二  --  (木) → 官鬼（木克土）
庚子   初九  —   (水) → 妻财  ☜ 世爻

第二步：断日月建

2026年5月11日 → 农历三月廿五，午时

月建：农历三月 → 辰月（辰土）

  • 辰土 → 旺土的月份
  • 土爻（兄弟）→ 临月建，极旺
  • 金爻（子孙）→ 土生金 → 旺
  • 水爻（妻财）→ 土克水 → 衰
  • 木爻（官鬼）→ 木克土、土泄木 → 被耗，偏衰

日建计算：2026年5月11日

让我算出日柱——2026年5月11日。记忆中有个在线计算器之前用过。

从2026年1月1日（甲寅日）开始推算： - 1月有31天，2月有28天（2026不是闰年），3月31天，4月30天，5月11天 - 总天数 = 0（1月1日当天）+ 30(1月剩余) + 28(2月) + 31(3月) + 30(4月) + 11(5月) = 130天 - 甲寅日 + 130天 → 130 mod 60 = 10 → 甲寅(51) + 10 = 61 → 61 mod 60 = 1 → 甲子日 - 甲子旬 → 空亡 = 戌、亥

日建：甲子日 → 子水

  • 子水 → 水旺的一天
  • 水爻（妻财）→ 临日建 → 今天旺！
  • 木爻（官鬼）→ 水生木 → 旺
  • 土爻（兄弟）→ 土克水 → 但在月建辰土，仍然旺

空亡：甲子旬 → 戌、亥 - 卦中上六=癸酉（金）→ 不是空亡 - 六五=癸亥（水）→ 亥空亡！ → 妻财爻空亡 - 但这个妻财六五被日建子水所旺 → 假空 → 出空就有

第三步：分析用神

问合作项目 → 用神 = 妻财（看收益）

用神在哪？ - 初九庚子水（世爻）→ 妻财 - 六五癸亥水 → 妻财（已空亡，但假空）

用神分析： - 初九妻财（世爻）= 临日建子水 → 极旺 - 六五妻财（应爻位）= 亥水空亡但临日建 → 待时而发 - 月建辰土克水 → 但日建子水救场 → 用神得日建之力，旺

第四步：分析其他爻

元神（生用神）：水生用神？不对，用神是水，生水的是金。

卦中金爻：上六癸酉（金）→ 子孙 → 元神！

上六酉金→月建辰土生金（旺）→ 元神有力！但日建子水泄金→稍有减弱，但综合看还是旺。

忌神（克用神）：克水的是土。

土爻：六四癸丑、六三庚辰 → 两土夹击

忌神也旺（月建辰土）→ 但动爻四爻要看变了什么。

动爻分析：六四（应爻）动 → 老阴变阳

六四兄弟（土）→ 动变阳 → 变卦中上卦成震☳

看它变成了什么：复卦六四土爻动变阳后，上卦坤☷→震☳ → 变卦䷲ 震为雷

六四爻变后对应震卦的九四：庚午火

土（六四）→ 变 → 火（九四）→ 土生火，泄了忌神的力量 → 好！

第五步：世应关系

  • 世爻（初九妻财）：你自己，临日建子水 → 你状态很好，自信
  • 应爻（六四兄弟→变九四火）：合作方，本来是耗财的兄弟，但变火泄土 → 对方也是想成的

世应关系：初九与六四 → 初阳四阴，相应（本应为吉）→ 合作有基础

第六步：综合结论

✅ 用神（妻财）= 旺（临日建+有力元神）
✅ 元神（酉金）= 旺（月建生）
⚠️ 忌神（土）= 也旺但动而泄气
✅ 世应 = 相应（有共同目标）
⚠️ 空亡 = 六五妻财空亡但不真

→ 合作能成！收益可期。
→ 但要注意：忌神土旺，中间可能有反复/竞争
→ 出空之日（亥时/亥日）= 关键节点
