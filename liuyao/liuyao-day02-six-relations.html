六爻纳甲 · Day 02 · 六亲体系 · 用神元神忌神仇神飞伏

Day01学会了装卦——把六爻填上天干地支五行。今天是六爻断卦的核心引擎：六亲。

六亲不是说"六种亲戚"，而是六种符号关系——每一爻根据它的五行与你（宫位五行）的关系，被赋予一个身份。这个身份决定了它在卦里扮演什么角色。

一、什么是六亲

六爻里 "我" = 该卦所属宫位的五行。

以"我"为参照，万物关系只有五种：

             生我者 ─── 父母
             同我者 ─── 兄弟
             我生者 ─── 子孙
             我克者 ─── 妻财
             克我者 ─── 官鬼

再加一个自身（也称世爻所在），合称六亲。

五行生克关系图

           生我（父母）
            ↑
 我 ←—— 克我（官鬼）
 的 ─→ 我克（妻财）
 五 ─→ 我生（子孙）
 行 ─→ 同我（兄弟）

真实含义对照表

六亲 五行关系 代表的事物 代表的六亲人物
官鬼 克我者 事业、官职、灾祸、压力、病痛、小人 丈夫（女占）、上司
父母 生我者 长辈、学业、文书、契约、房屋、车辆 父母、老师、保护者
兄弟 同我者 竞争、花费、破财、同伴、手气 兄弟朋友、同事
妻财 我克者 钱财、资产、物资、收益 妻子（男占）、女伴
子孙 我生者 福神、解忧、快乐、投资、创意、顾客 孩子、晚辈、下属
自身 世爻 问卦人自己 本人

注意：官鬼对女（问婚姻）= 丈夫，但官鬼本身也是"管我的力量"——压力、上司、官司全在这里看。妻财对男（问婚姻）= 妻子，但妻财本身也是"我控制的东西"——钱、物资。

这是六爻最核心的翻译表。学完这张表，你已经看懂六爻八成的内容了。

二、按五行定六亲的实战操作

每个宫有自己固定的六亲排列方式。

五行的六亲归属（对应当宫五行）

宫五行 金(木) 木(木) 水(水) 火(火) 土(土)
官鬼 (克我) 火克金 金克木 土克水 水克火 木克土
父母 (生我) 土生金 水生木 金生水 木生火 火生土
兄弟 (同我) 金 木 水 火 土
妻财 (我克) 金克木 木克土 水克火 火克金 土克水
子孙 (我生) 金生水 木生火 水生木 火生土 土生金

三个规律记住就不用背八张表： 1. 兄弟 = 宫五行（同我为兄弟） 2. 子孙 = 我生之五行（此生彼） 3. 妻财 = 我克之五行（我制彼） 4. 官鬼 = 克我之五行（彼制我） 5. 父母 = 生我之五行（彼生我）

翻译成人话就是：记住自己是什么五行，顺藤摸瓜推出其余四个。

比如坎宫水 → 生水的是金（父母）→ 水生的是木（子孙）→ 克水的是土（官鬼）→ 水克的是火（妻财）→ 同水的是水（兄弟）。

完整示例：䷂ 水雷屯 + 六亲

坎宫水 → 六亲归属：

金 = 父母（生我水生）
水 = 兄弟（同我水）
木 = 子孙（我生木）
火 = 妻财（我克火）
土 = 官鬼（克我土）

代入Day01的完整装卦：

䷂ 水雷屯（坎宫二世卦）    世在二爻，应在五爻

戊子 上六  --  (水) → 兄弟
戊戌 九五  —   (土) → 官鬼  ☜ 应爻
戊申 六四  --  (金) → 父母
戊午 六三  --  (火) → 妻财
戊辰 六二  --  (土) → 官鬼  ☜ 世爻
戊寅 初九  —   (木) → 子孙

断卦入门： - 世爻（自己）在二爻，临官鬼（土）→ 你现在压力大，处在"被管"的状态 - 应爻（事情）在五爻，也是官鬼 → 事情本身也是一股压力 - 问事业的话：官鬼旺相 → 事业有转机；官鬼休囚 → 麻烦缠身 - 问财运的话：妻财在六三（火）→ 火临月建则财旺

别急，具体的断法Day03讲。今天先把六亲体系练熟。

三、用神、元神、忌神、仇神

六亲是"身份"，用神是"目标"。断卦的第一步：找到用神。

用神（你要问的目标）

问事 取用神
问财运、投资、生意 妻财
问事业、升职、官司、婚姻（女） 官鬼
问婚姻（男） 妻财
问父母、文书、房产、考试 父母
问兄弟、朋友、合作、竞争 兄弟
问子女、投资（从子孙角度）、快乐 子孙
问自己吉凶 世爻
问对方/事情状态 应爻

注：问"涨工资"→用神妻财（看钱）；问"提不提拔"→用神官鬼（看事业）；问"能不能考过"→用神父母（看文书学业）；问"投资项目赔赚"→用神也是妻财，但兼看子孙（生财）或官鬼（破财）。

元神（生用神的爻）

元神 = 父母（生我者），但是生的是"用神"而非"我"

准确定义：生用神的那一爻。具体关系：

  • 如果用神是妻财（火），那生火的是木 → 这个木爻就是元神
  • 如果用神是官鬼（水），那生水的是金 → 这个金爻就是元神

元神旺相 → 用神有靠山，事情顺利。 元神空亡 → 用神无根，事情虚浮。

忌神（克用神的爻）

忌神 = 克用神的那一爻

  • 用神是妻财（火），克火的是水 → 水爻就是忌神
  • 用神是官鬼（水），克水的是土 → 土爻就是忌神

忌神旺动 → 用神受伤，事情受阻。

仇神（生忌神的爻）

仇神 = 生忌神的那一爻

  • 如果用神妻财（火），忌神是水 → 生水的是金 → 金爻就是仇神
  • 如果用神官鬼（水），忌神是土 → 生土的是火 → 火爻就是仇神

仇神旺 → 忌神有根，更加凶险。

四者关系图

         仇神             元神
          │                │
          ▼                ▼
  仇神生忌神 ←  ╋  → 元神生用神
                  │
                  ▼
               用 神
                  │
              我克=妻财
              生我=父母
              克我=官鬼
              同我=兄弟
              我生=子孙

实战口诀

用神为主看吉凶，元神生用喜相逢；
忌神克用多阻滞，仇神助忌祸不轻；
世应定我与他事，日月建上定旺衰。

四、飞伏

飞神 = 当前爻位的六亲（看得见的） 伏神 = 因该爻不是本宫之爻而"藏起来"的六亲（看不见的）

什么时候有伏神？

六十四卦中，只有八纯卦的六个爻全部是本宫之爻。其余卦中，有些爻不属于本宫五行→该爻位上本应存在的六亲就成了伏神。

实际遇到的最常见情况：找出卦中缺少用神时。

比如：问财运（用神=妻财），但整个卦翻遍找不到妻财爻 → 说明用神伏藏，伏在本宫对应的位置上。

找伏神的方法

  1. 找出本宫（纯卦）的六个爻的六亲
  2. 看你要找的六亲在本宫纯卦的哪个爻位
  3. 这个爻位在当前卦对应的爻上，用神就是飞神还是伏神？

看一个例子：

䷂ 水雷屯（坎宫）
┌─────────┬──────────┐
│ 本卦爻位 │ 本宫坎卦䷜  │
├─────────┼──────────┤
│ 上六子水 │ 上六子水 → 兄弟 │
│ 九五戌土 │ 九五戌土 → 官鬼 │
│ 六四申金 │ 六四申金 → 父母 │
│ 六三午火 │ 六三午金 → 父母（不对，这里是午火）│
│ 六二辰土 │ 六二辰土 → 官鬼 │
│ 初九寅木 │ 初九寅木 → 子孙 │
└─────────┴──────────┘

等等，上面的说法不太对——坎宫本宫是䷜（坎为水），其六亲为： - 上六 戊子水 → 兄弟 - 九五 戊戌土 → 官鬼 - 六四 戊申金 → 父母 - 六三 戊午火 → 妻财（水克火=财） - 六二 戊辰土 → 官鬼 - 初六 戊寅木 → 子孙（水生木=子）

而䷂水雷屯的六三爻是戊午火（妻财）——跟本宫的六三是相同的（都是午火，都是妻财）。

实际上在真实操作中，飞伏主要用于当本卦的某个爻位上缺失了用神时。比如有的卦中某爻地支与本宫不同，导致该爻的六亲不同，相应的"本宫应有的六亲"就伏藏了。

简化处理：初学者先不用深究飞伏，知道"卦中缺用神时，去本宫找"就够了。实战中大部分情况直接看飞神就能判断。

五、完整示例：用六亲断一件事

案例：问财运 → 用神 = 妻财

䷂ 水雷屯（坎宫二世卦）

戊子   上六  --  (水) → 兄弟
戊戌   九五  —   (土) → 官鬼  ☜ 应爻  ✦ 忌神（土克火）
戊申   六四  --  (金) → 父母  ✦ 仇神（金生水→水生木←不对）
                                           ✦ 仇神土克火，金生水→水克火，不对。
                                           ✦ 重新算：忌神克用神，仇神生忌神。
                                           ✦ 用神妻财(火)，忌神=克火=水，仇神=生水=金
                                           ✦ 所以这里的金(父母)=仇神
                                           ✦ 但注意，实际要看这个爻是否动了
戊午   六三  --  (火) → 妻财  ✦ 用神（你要的结果）
戊辰   六二  --  (土) → 官鬼  ☜ 世爻  ✦ 问财运世临官鬼=破财信号
戊寅   初九  —   (木) → 子孙  ✦ 元神（木生火）

分析： - 用神在六三（妻财火）→ 有财 - 元神（初九木）→ 木生火旺，财源好 - 世爻（六二官鬼）→ 但你目前"手紧"，鬼压身，缺钱状态 - 应爻（九五官鬼）→ 事情本身有压力 - 兄弟（上六）→ 有竞争/合伙破财的可能 - 结论：有财运（用神+元神旺），但当前你自己手头紧（世临官鬼），而且有兄弟劫财的隐患。建议最近不要跟人合伙投资。

这不是完整断法（少了日月建、空亡等Day03内容），但光用六亲已经能看出大致走向了。

练习2

👆 先想再看 ䷀ 乾为天（乾宫纯卦）——六爻全部是本宫：

壬申 — 兄弟 (金)

甲子 — 子孙 (水) ☜ 世爻
**用神妻财**在**甲寅（二爻）**。 **元神（生妻财）** = 水（生木）→ 甲子（子孙），在一爻。 **月建亥水（金生水）** → 亥水是元神位置（子孙），水旺生木 = **用神更旺** → 反而对财运有利！ 等等——月建亥水克火，妻财属木，水不生木吗？不对，水生木，所以亥水旺反而生妻财。 **结论**：月建亥水不生火，但水旺生妻财木 → 财运反而提升。 这里要注意：月建的作用不能只看"克"，要看生克关系具体落在哪个五行上。
