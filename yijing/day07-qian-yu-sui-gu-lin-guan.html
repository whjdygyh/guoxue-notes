第七天 · 六十四卦精读（四）：谦豫随蛊临观

一、䷎ 谦卦 — 地山谦（上坤下艮）

卦象： 上☷地 + 下☶山 → 高山藏于大地之下——有本事却低调

这是周易唯一一个全吉的卦。六爻爻辞全部吉利或无害。

卦辞： 谦，亨，君子有终。

白话： 谦卦，亨通，君子有好的结局。

核心： 真正的谦虚——不是装出来的，是有实力但选择低调 - 山（艮）在下 → 有实力、有高度 - 地（坤）在上 → 包容、放下 - 山本来应该高出地面，却甘心藏在地下面

《大象传》： 地中有山，谦。君子以裒多益寡，称物平施。

大地中蕴藏着高山就是谦卦，君子因此减多增少、公平施与。

六爻全吉解析： | 爻 | 爻辞 | 解读 | |----|------|------| | 初六 | 谦谦君子，用涉大川，吉 | 谦虚到极致，吉祥 | | 六二 | 鸣谦，贞吉 | 名声在外仍谦虚 | | 九三 | 劳谦君子，有终吉 | 最核心一爻——有功而谦，结果最好 | | 六四 | 无不利，㧑谦 | 发挥谦虚美德 | | 六五 | 不富以其邻，利用侵伐，无不利 | 谦虚不代表软弱——该强硬时强硬 | | 上六 | 鸣谦，利用行师，征邑国 | 谦虚之名在外，可以率军出征 |

谦卦的核心智慧： 真正有本事的人不需要炫耀。山不在地面上，而是在地里，更显其高大。

二、䷏ 豫卦 — 雷地豫（上震下坤）

卦象： 上☳雷 + 下☷地 → 雷出地奋、万物喜悦

卦辞： 豫，利建侯行师。

白话： 豫卦，利于建立诸侯、出兵征战。

核心： 安乐和预备 - 豫 = 愉悦（快乐）+ 预备（"凡事豫则立"） - 雷（震）出地 → 春天来了，万物欢欣 - 但乐极容易生悲 → 需要"预备"

《大象传》： 雷出地奋，豫。先王以作乐崇德，殷荐之上帝，以配祖考。

雷从大地奋出就是豫卦，先王因此制作音乐、崇尚德行，隆重地祭祀上帝和祖先。

关键爻（六二）： "介于石，不终日，贞吉。"

坚如磐石，不等一天过完就发现吉凶。在安乐中保持清醒，像石头一样坚定。

三、䷐ 随卦 — 泽雷随（上兑下震）

卦象： 上☱泽 + 下☳雷 → 雷在泽下、随时而动

卦辞： 随，元亨利贞，无咎。

白话： 随卦，创始通达和谐正固，没有灾祸。

核心： 随从、跟随——但不是盲从 - 震（雷）在下 → 行动 - 兑（泽）在上 → 喜悦 - 行动使人喜悦 = 随从

《大象传》： 泽中有雷，随。君子以向晦入宴息。

泽中响雷就是随卦，君子因此到了傍晚就回家休息（顺应天时）。

关键爻（初九）： "官有渝，贞吉。出门交有功。"

官位有变动，守正则吉。出门与人交往会有成果。随不是消极跟随别人，而是主动选择和谁随从。

四、䷑ 蛊卦 — 山风蛊（上艮下巽）

卦象： 上☶山 + 下☴风 → 山下有风、腐败滋生

卦辞： 蛊，元亨。利涉大川。先甲三日，后甲三日。

白话： 蛊卦，创始亨通。利于渡过大河。做事前要考虑前三天，后也要观察后三天。

核心： 整治腐败、拨乱反正 - 随卦之后必生弊端（随从久了就会懈怠） - 风（巽）被山（艮）挡住了 → 不通畅 → 腐败 - "先甲三日后甲三日" = 做事要考虑前后因果

《大象传》： 山下有风，蛊。君子以振民育德。

山下有风就是蛊卦，君子因此振奋人民、培育品德。

蛊卦的核心思想： 腐败不可怕——可怕的是不去整治。"蛊"本身就是"治蛊"。

五、䷒ 临卦 — 地泽临（上坤下兑）

卦象： 上☷地 + 下☱泽 → 地在泽上、居高临下

卦辞： 临，元亨利贞。至于八月有凶。

白话： 临卦，创始通达和谐正固。到了八月会有凶险。

核心： 居高临下、监督管理 - 地（坤）在上 → 高 - 泽（兑）在下 → 低 - 居高临下地接近、管理

《大象传》： 泽上有地，临。君子以教思无穷，容保民无疆。

泽上有大地就是临卦，君子因此以无穷的思虑教导人民，以无边的包容保护人民。

"八月有凶"——盛极必衰，任何好的状态都有期限。

六、䷓ 观卦 — 风地观（上巽下坤）

卦象： 上☴风 + 下☷地 → 风行地上、遍观万物

卦辞： 观，盥而不荐，有孚颙若。

白话： 观卦，祭祀前洗手但未进献祭品，诚信之心已显。

核心： 观察和省察 - 临卦和观卦是互相对照的：临是向下看（管理），观是向上看（观察） - 风（巽）行于地（坤） → 无处不到、无处不察

《大象传》： 风行地上，观。先王以省方观民设教。

风行大地上就是观卦，先王因此巡视四方、观察民情、施行教化。

关键爻（九五）： "观我生，君子无咎。"

观察我的一生（自我省察），君子没有灾祸。最好的观察是反观自身。

七、六卦串联

谦（谦虚）→ 豫（安乐）→ 随（随从）→ 蛊（腐败）→ 临（管理）→ 观（观察）

低调成功 → 享受生活 → 跟错人 → 出问题 → 管理整顿 → 反思观察

谦卦全吉——周易给我们的信号是：什么都可以不记住，但谦卦的智慧必须记住。
