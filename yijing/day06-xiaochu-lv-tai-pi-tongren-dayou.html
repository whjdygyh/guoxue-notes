第六天 · 六十四卦精读（三）：小畜履泰否同人大有

一、䷈ 小畜卦 — 风天小畜（上巽下乾）

卦象： 上☴风 + 下☰天 → 风行天上、小有积蓄

卦辞： 小畜，亨。密云不雨，自我西郊。

白话： 小畜卦，亨通。乌云密布却还没下雨，来自我们的西郊。

核心： 小有积蓄、蓄势待发 - 五阳一阴 —— 阴（六四）用柔顺的力量蓄止了阳的冲动 - "密云不雨" = 条件快够了，但还差一点

《大象传》： 风行天上，小畜。君子以懿文德。

风行于天上就是小畜卦，君子因此要美化自己的文采和品德（积蓄内在）。

二、䷉ 履卦 — 天泽履（上乾下兑）

卦象： 上☰天 + 下☱泽 → 天在上泽在下、踩着走

卦辞： 履虎尾，不咥人，亨。

白话： 踩到了老虎尾巴，老虎不咬人，亨通。

核心： 践行礼仪、如履薄冰 - 乾（刚健）在上，兑（悦）在下 → 用柔悦的态度去执行刚健的事 - "履虎尾不咥人" = 在危险中因为态度谦恭而得免

《大象传》： 上天下泽，履。君子以辨上下，定民志。

天在上泽在下就是履卦，君子因此辨别上下尊卑，安定民心。

小畜讲"积蓄"，履卦讲"行动"。先有积蓄，然后才有资格行动。

三、䷊ 泰卦 — 地天泰（上坤下乾）

卦象： 上☷地 + 下☰天 → 地在天上——天地交融、万物通泰

这是周易中最好的卦之一。

卦辞： 泰，小往大来，吉亨。

白话： 泰卦，阴去阳来，吉祥亨通。

核心： 通泰、和谐、上下交流顺畅 - 乾（天）在下 → 阳气上升 - 坤（地）在上 → 阴气下降 - 阴阳交合 = 通泰

《大象传》： 天地交，泰。后以财成天地之道，辅相天地之宜，以左右民。

天地互相交融就是泰卦，君主因此裁成天地之道、辅助天地之宜，来治理人民。

关键提醒： 泰卦看似天地颠倒（天在下地在上），实际上是最好的状态——因为只有地在上天在下，阴阳才能交合。如果乾在上坤在下反而成了否卦。

四、䷋ 否卦 — 天地否（上乾下坤）

卦象： 上☰天 + 下☷地 → 天在上地在下——天地隔绝、万物不通

这是周易中最好的卦...的反面——最闭塞的卦。

卦辞： 否之匪人，不利君子贞，大往小来。

白话： 否卦，天地不交，万物不通。不利君子守正。阳去阴来。

核心： 闭塞、不通、上下离心 - 乾（天）在上 → 阳气不下降 - 坤（地）在下 → 阴气不上升 - 阴阳不交 = 闭塞不通

《大象传》： 天地不交，否。君子以俭德辟难，不可荣以禄。

天地不交就是否卦，君子因此收敛自己的德行来避免灾难，不可追求荣华富贵。

泰否的对比（最经典的对比之一）：

对比 泰卦（䷊） 否卦（䷋）
卦象 地在上，天在下 天在上，地在下
阴阳 阴阳交合 阴阳隔绝
吉凶 大吉 大凶
处世 积极作为 隐忍等待
名言 天地交而万物通 天地不交而万物不通

关键理解： 泰卦之所以好，不是因为"天在上"——而是因为"通"。君子之交、上下级沟通、夫妻和谐...全部都是"泰"的道理。而否卦恰恰相反，表面上"天在上看起来很对"，实际上是死路。

泰卦的警示： 泰极否来——最通泰的时候恰恰要警惕下滑。 否卦的安慰： 否极泰来——最坏的时候恰恰是转机的开始。

五、䷌ 同人卦 — 天火同人（上乾下离）

卦象： 上☰天 + 下☲火 → 火在天上、光明照耀、天下大同

卦辞： 同人于野，亨。利涉大川，利君子贞。

白话： 在旷野中与人和同，亨通。利于渡大河，利于君子守正。

核心： 团结众人、天下大同 - 离（火）在下 → 光明 - 乾（天）在上 → 刚健 - 光明照耀天下 = 与天下人同心

《大象传》： 天与火，同人。君子以类族辨物。

天与火在一起就是同人卦，君子因此分类族群、辨别事物（求同存异）。

关键爻（九五）： "同人先号咷而后笑，大师克相遇。"

同心的人先哭后笑，大军攻克后得以相遇。经历磨难后的团结更加珍贵。

六、䷍ 大有卦 — 火天大有（上离下乾）

卦象： 上☲火 + 下☰天 → 火在天上、光明普照、大丰收

卦辞： 大有，元亨。

白话： 大有卦，创始亨通。

核心： 大丰收、大富有 - 同人之后 = 团结众人之后自然大有收获 - 离（火）在上照耀乾（天）在下 → 光明照耀世界

《大象传》： 火在天上，大有。君子以遏恶扬善，顺天休命。

火在天上就是大有卦，君子因此遏制邪恶、弘扬善行，顺应天道、美好生命。

大有卦的告诫： 富有了怎么办？"遏恶扬善"——富有的时候要行善、要节制。

七、六卦串联

小畜（积累）→ 履（践行）→ 泰（通泰）→ 否（闭塞）→ 同人（团结）→ 大有（丰收）

攒钱 → 做事 → 順利 → 碰壁 → 找朋友 → 发达

❗特别记住「泰否」这一对——它们是周易最重要的两个对比卦。 泰极否来、否极泰来——循环往复，这是周易最核心的思维。
