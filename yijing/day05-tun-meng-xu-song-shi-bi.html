第五天 · 六十四卦精读（二）：屯蒙需讼师比

这六卦讲的是事物初生后经历的六个阶段——从艰难诞生到解决纷争。

一、䷂ 屯卦 — 水雷屯（上坎下震）

卦象： 上☵水 + 下☳雷 → 云雷交加、万物初生之象

卦辞： 屯，元亨利贞。勿用有攸往，利建侯。

白话： 屯卦，创始通达和谐正固。不宜远行，利于建立诸侯（安定根基）。

核心： 万事开头难——但难中有生机。 - 雷（震）象征行动，水（坎）象征险陷 - 行动遇到险陷 = 初创阶段的困难 - 但"利建侯"——先打好基础，不要急着扩张

《大象传》： 云雷，屯。君子以经纶。

云雷交加就是屯卦，君子因此要治理天下事务（在混乱中建立秩序）。

关键爻（初九）： "磐桓，利居贞，利建侯。"

徘徊难进，利于安居守正，利于建立根基。创业第一步不要急，打地基最重要。

二、䷃ 蒙卦 — 山水蒙（上艮下坎）

卦象： 上☶山 + 下☵水 → 山下有水、迷雾笼罩之象

卦辞： 蒙，亨。匪我求童蒙，童蒙求我。初筮告，再三渎，渎则不告。利贞。

白话： 蒙卦，亨通。不是我去求蒙昧的人，而是蒙昧的人来求我。初次占卜告诉他，再三地来问就亵渎了，亵渎就不再告诉他。利于守正。

核心： 启蒙和教育 - 山（艮）在上，水（坎）在下 → 山下有泉水，被山挡住看不清 = 蒙昧状态 - "匪我求童蒙，童蒙求我" → 学习的主动性最关键。老师不会求着学生学

《大象传》： 山下出泉，蒙。君子以果行育德。

山下涌出泉水就是蒙卦，君子因此以果敢的行动培育品德。

人生启示： 不懂就问是好事，但问一次认真记，反复来问同一个问题就是态度问题了。

三、䷄ 需卦 — 水天需（上坎下乾）

卦象： 上☵水 + 下☰天 → 云在天上、等待降雨之象

卦辞： 需，有孚，光亨，贞吉。利涉大川。

白话： 需卦，有诚信，光明亨通，守正则吉。利于渡过大河（克服大困难）。

核心： 耐心等待 - 乾（天）在下：有能力和志向 - 坎（水）在上：外面有险陷 - 有能力但时机未到 = 等待

《大象传》： 云上于天，需。君子以饮食宴乐。

云升到天上就是需卦，君子因此饮食宴乐（耐心等待时机的过程中保持从容）。

关键提醒： 等待不是干着急，而是养精蓄锐、充实自己。

四、䷅ 讼卦 — 天水讼（上乾下坎）

卦象： 上☰天 + 下☵水 → 天在上水流下、方向相反→冲突

卦辞： 讼，有孚窒惕，中吉，终凶。利见大人，不利涉大川。

白话： 讼卦，虽有诚信但被窒塞，要警惕，中途停止则吉，坚持到底则凶。利于见大人裁决，不利于渡大河。

核心： 争讼和冲突 - 乾（天）在上：刚健向上 - 坎（水）在下：险陷向下 - 一个向上一个向下 = 方向不一致 → 矛盾产生

《大象传》： 天与水违行，讼。君子以作事谋始。

天和水运行方向相反就是讼卦，君子因此做事一开始就要谋划周全（防范于未然）。

关键教训： 打官司不是好事，能和解就和解。"中吉终凶"——见好就收，打到低没有好结果。

五、䷆ 师卦 — 地水师（上坤下坎）

卦象： 上☷地 + 下☵水 → 地中有水、隐含军队之象

卦辞： 师，贞，丈人吉，无咎。

白话： 师卦，守持正固，由德高望重的人（丈人）统率则吉，没有灾祸。

核心： 统率和战争 - 坤（地）：大众 - 坎（水）：险陷 - 带众人入险境 = 军事行动

《大象传》： 地中有水，师。君子以容民畜众。

地中蕴藏着水就是师卦，君子因此要容纳和保护人民（平时养民，战时才有兵）。

关键爻（九二）： "在师中，吉无咎，王三锡命。"

身在军中，吉祥无灾。统帅受到君主的多次褒命。将帅在外要有君主信任。

六、䷇ 比卦 — 水地比（上坎下坤）

卦象： 上☵水 + 下☷地 → 水在地上、亲密依附之象

卦辞： 比，吉。原筮元永贞，无咎。不宁方来，后夫凶。

白话： 比卦，吉祥。初次占问，永远守正则无灾。不安宁的人会来归附，迟疑落后则凶。

核心： 亲附和团结 - 师卦之后是比卦（战争之后需要团结） - 水在地上流动，滋润万物 = 亲比关系

《大象传》： 地上有水，比。先王以建万国，亲诸侯。

大地上有水就是比卦，先王因此建立万国、亲近诸侯。

关键教训： 亲附要主动、要真诚。落后者（后夫）有凶——机不可失。

七、六卦串联记忆法

这六卦讲的是一个完整的社会发展故事：

屯（创）→ 蒙（教）→ 需（等）→ 讼（争）→ 师（战）→ 比（和）

创业 → 教育 → 等待时机 → 产生矛盾 → 矛盾激化 → 和解团结
